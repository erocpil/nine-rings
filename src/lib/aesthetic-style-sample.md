# 物哀、幽玄与侘寂：Nine Rings 风格设计

这份内置文档位于 ideas，用于比较不同风格在真实阅读与编辑中的效果。可以编辑、移动或删除，后续启动不会覆盖修改。

## 理解与边界

物哀关注对事物短暂、流转的感受；幽玄强调含蓄、未尽与深远；侘寂珍视朴素、岁月感与不完满。“侘寂”的“侘”并非“诧”。这些概念具有丰富历史，下文是面向软件界面的设计转译，而不是对传统美学的完整定义。

参考：[斯坦福哲学百科：Japanese Aesthetics](https://plato.stanford.edu/archives/spr2024/entries/japanese-aesthetics/)。

## 物哀：阅读的节奏

物哀的界面温柔而轻盈，章节之间留有停顿，辅助信息轻一些。淡粉仅用于少量强调，正文保持清楚的墨色。

- 浅色：樱灰白、淡藕灰、枯玫瑰强调色。
- 深色：暖炭灰、灰紫、柔和玫瑰色。
- 排版：衬线正文、轻一些的标题、舒展行距。
- 控件：小圆角、轻边框、柔和但明确的选中状态。

> 阅读的余韵来自段落之间的停顿，而不是让文字变得难以辨认。

## 幽玄：视线的集中

幽玄强调沉静、深邃和含蓄的层次。当前文档和当前操作清晰，周围界面安静；深色版本尤其适合表现墨蓝与烟青的关系。

- 浅色：雾灰白、青灰、墨蓝强调色。
- 深色：深墨蓝、烟青、月白文字。
- 排版：无衬线正文，集中阅读列，以字号和留白建立章节层级。
- 控件：弱化闲置工具，以可见焦点和明确选中状态突出当前操作。

> 含蓄可以留给装饰，操作反馈必须清楚。

## 侘寂：材料般的朴素

侘寂通过纸、石、土的配色与简洁边界呈现安定感，不使用影响阅读的噪点、裂纹或做旧纹理，也不人为打乱控件对齐。

- 浅色：米灰、砂岩、苔绿强调色。
- 深色：深褐灰、灰橄榄、暖米色文字。
- 排版：朴素衬线正文、中等字重标题、左对齐和适度留白。
- 控件：接近直角、少阴影，用细线区分区域。

> 朴素意味着去除多余装饰，同时保留内容的结构与操作的确定性。

## 三种风格对照

| 设计维度 | 物哀 | 幽玄 | 侘寂 |
| --- | --- | --- | --- |
| 整体感受 | 温柔、轻盈、余韵 | 沉静、深邃、含蓄 | 质朴、安定、自然 |
| 字体 | 衬线正文，轻标题 | 无衬线正文，层级分明 | 衬线正文，中等标题 |
| 阅读节奏 | 舒展，章节留白较多 | 集中，正文与周边区分清楚 | 适度留白，强调结构 |
| 引用 | 淡藕色侧线 | 烟青色侧线 | 苔色侧线 |
| 代码 | 低饱和底色 | 通过明度区分 | 暖石灰底色 |

## 共同规则

1. 三种风格均支持浅色、深色与跟随系统。
2. 风格切换只改变界面，不改写文档内容或经典外观设置。
3. 按钮位置、键盘焦点与选中状态保持明确，手机保留触控空间。
4. 源码行号和代码使用等宽字体；文档中明确设置的文字格式予以保留。
5. Mermaid 内部图形样式由源码与渲染逻辑管理，不因新风格重写节点颜色。

### 代码与混排样例

下面的代码用于检查等宽字体、语法高亮、换行和代码块工具栏：

```typescript
const styles = ["物哀", "幽玄", "侘寂"];
for (const style of styles) {
  console.log(`${style}：清晰的文字，安静的界面。`);
}
```

普通文本、**粗体强调**、*轻微强调*、`inline code` 和 [链接](https://plato.stanford.edu/entries/japanese-aesthetics/) 应在明暗背景下保持可辨。English text and 中文混排，数字 0123456789，标点：，。！？也应保持自然的阅读节奏。

### 验证方法

- 在同一窗口与同一篇文档上切换风格，分别检查浅色和深色。
- 同时打开目录、书签与阅读分栏，检查实际窄栏下的标题换行和工具栏。
- 比较编辑、只读与源码视图；折叠引用和代码后再展开。
- 手机检查目录、设置卡片、块弹层、触控空间和正文横向溢出。
- 检查正文、辅助文字、选中行、链接及焦点，而不仅仅看整页颜色。
