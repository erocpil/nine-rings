| P1 | 明确重载磁盘版本后，旧渲染实例卸载时可能冲刷尚未转换的编辑，覆盖重载结果 | 替换来源和实例前先完成待转换编辑，再明确选择磁盘文本；新增同一任务内编辑后重载回归 |
| P2 | 下载副本的浏览器回退仍捕获旧 React 源码闭包 | 冲刷后冻结当前源码，文件选择与下载回退使用同一快照；读取实际下载文件验证最新正文 |
| P2 | 旧书签的移动端延迟定位覆盖新脚注导航 | 导航代次区分新旧请求，新的导航、指针或滚轮操作取消过期定位；WebKit 手机连续跳转与模式往返验证 |
| P2 | 标题抽象遗漏只读“文档属性”的可访问名称，且完整标题预览与信息卡可能重复 | 恢复只读属性入口名称；移动预览与桌面信息卡分别遵守交互规则；数据库属性、手机标题及本地只读信息卡回归 |

## 核对边界

- **编辑权威：** 两类普通渲染只有一套 TipTap 工作区；磁盘适配器仅在真实正文编辑后序列化。元数据、折叠、选择和纯模式切换不改写原文，完整撤销可恢复初始写法。
- **源码能力：** 两类来源共享 CodeMirror 和源码界面组合；磁盘的 BOM、换行、撤销会话、初始位置恢复及文件修订校验继续使用原适配器。源码与渲染撤销栈仍独立。
- **保存及恢复：** 关闭、重命名、保存与切换视图先处理待转换内容。文件保存仍通过原服务的修订检查和原子写入；陈旧轮询回调不能替换新基线。
- **资源：** 授权根内相对图片通过显示上下文解析，不把解析结果写回 Markdown。粘贴图片采用能随文件保存的 data URL，不引用数据库专属图片身份。
- **权限及命令：** 本地文件不进入数据库保护、版本与同步流程，不伪造数据库文档 ID；引用、标注和文档导航历史按宿主能力关闭。通用块操作、工具栏和菜单直接复用公共工作区。
- **标题及路径：** 重命名先经过脏状态／草稿检查；成功后迁移书签、阅读状态、源码位置、内存会话、tab 和最近打开。信息卡不虚构文件系统未提供的创建／访问时间。
- **布局：** 布局策略决定浮层或停靠位置，不决定编辑内核。样式对照覆盖八种风格及桌面／手机宽度；本地不再使用专属普通正文间距补丁。

## 验证范围

前端检查、针对性 Chromium/WebKit、完整默认 E2E、生产/PWA 和 macOS ARM64 构建分别记录结果，不合并重复用例数量。完整运行的失败和主动中止保留原始记录；针对性复跑不改写整轮结果。

原生文件选择、目录权限续期、IME 和真实系统剪贴板仍需对应平台交互验收。远端 CI 必须绑定实际推送的 SHA；本地构建成功不能代替远端结果。当前不存在跨源码／渲染共享撤销，也不声称本次重构已经降低大文档内存或首屏时间。
