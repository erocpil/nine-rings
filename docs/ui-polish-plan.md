# UI 统一与交互打磨计划

更新：2026-09-07

## 目标与范围

以设置（含子页面）、文档目录和书签为视觉基准：安静的背景、细边框、清晰的文字层级，强调色用于选中状态和主要操作。沿用现有主题变量，不改变正文排版、阅读器画布或数据格式。

每批独立实现、验证、提交；完成后在本文更新结果。先完成第一批，再推进后续批次。

## 第一批：确认弹窗与操作反馈

状态：实现完成，自动化验证通过；Windows Tauri 和手机安装版仍待真机验收。

- 提供共用确认弹窗，替换版本恢复、回收站永久删除/清理、同步覆盖/保存凭据、外部 Markdown 更新/解除关联中的系统确认框。
- 展示操作名称、影响范围和可恢复性；危险操作使用明确的动作按钮。初始焦点放在取消，支持 Esc 取消、Tab 焦点约束和关闭后焦点归还。
- 确认期间阻止背景交互；重复点击不重复执行，所属页面关闭时取消待确认操作。
- 共用错误反馈：长错误换行、复制详情、复制失败提示；读取失败可重试。写入失败由用户重新发起并再次确认，不自动重试危险操作。
- 优先覆盖同步预检错误、版本历史与回收站的失败提示。

验收：上述入口不再使用系统确认框；取消不写数据，确认仅执行一次；键盘可完整操作；深浅主题和窄屏布局可用；复制错误详情不丢失设备、文档与路径信息。

### 第一批交付记录（2026-09-07）

- 新增 `ConfirmationDialog` / `useConfirmation`，接入上述 7 个确认入口。使用浏览器模态 dialog 的背景隔离能力，并处理焦点、取消、重复请求和所属文档/页面失效。
- 新增 `OperationError`，用于同步、版本历史、回收站。同步失败信息保留到下一次操作，不再定时消失；复制详情明确报告失败。
- 扩展剪贴板工具的可选失败上报，保留原调用方的兼容行为；降级复制后恢复焦点。
- Chromium：12 个相关浏览器用例通过，覆盖删除、版本恢复、外部来源、同步提示、键盘交互、复制及卸载取消。
- WebKit：4 个关键用例通过，覆盖 Token 确认、卸载取消、1280px/390px 下的键盘交互。
- 1280px/390px 的深浅主题截图已生成，390px 深浅主题截图已人工复核；模拟宽度不等同于手机安装版实测。
- 100 项单元测试、lint（零 error / warning）、项目类型检查及格式检查通过。
- 后续从第二批开始；本批未调整正文和阅读器画布。

## 第二批：高频列表与表单

状态：实现完成，自动化验证通过。

- 搜索结果、快速切换统一标题、路径、摘要及辅助信息层级。
- 新建文档、移动文档表单统一标签、帮助说明、校验提示与按钮排列。
- 整理共用列表行、空状态、加载状态；处理长标题、长路径和无结果状态。
- 统一图标尺寸、选中/悬停/键盘焦点状态，不改变现有快捷键含义。

验收：常见宽度下内容不溢出；路径可辨认；键盘导航与触屏操作保持可用；空、加载、错误状态能够区分。

### 第二批交付记录（2026-09-07）

- 搜索与快速切换共用 `DocumentListContent`：标题、路径、辅助信息分层，长文本限制显示行数并保留完整 title 文本，摘要高亮保持不变。
- 共用 `ListState` 区分加载、空列表和失败；快速切换和移动目录增加重试入口，重试后焦点回到搜索框。
- 新建/移动共用 `PathPreview`，长路径可换行；表单校验与输入关联，失败可见并可复制详情。
- 新建文档增加路径校验与提交互斥；添加概念标签的 Enter 不再继续触发表单提交。概念建议支持键盘点击，模板及类型选择具有明确焦点状态。
- 14 个相关 Chromium 用例通过（搜索定位/快速切换 9 个，新建/移动/失败重试 5 个）；lint、类型和格式检查通过。
- 跨设备截图与键盘空间复核在第三批执行。
