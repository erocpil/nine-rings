# Web / PWA 优化计划

> 建立时间：2026-08-21  
> 目标：在保持 Tauri / Web 核心数据语义一致的前提下，将 Web 版本建设为可靠、清晰且适合移动设备的本地优先 PWA。

## 1. 产品原则

1. Web 与 Tauri 保持笔记、版本、导入导出和备份语义一致，但界面按平台能力分别优化，不追求像素级相同。
2. 手机采用单任务布局；目录、属性和低频操作使用抽屉或弹窗，不压缩正文。
3. 本地数据可靠性优先于新增功能。任何升级、刷新或导入都不能静默丢失编辑内容。
4. GitHub 功能定位为版本化备份与恢复；在具备冲突合并能力前不称为实时同步。
5. Web 专属能力必须在真实生产构建、离线环境和 WebKit 移动视口中验证。

## 2. 分阶段路线

### P0 — 可靠性与安全

| 项目 | 实施内容 | 验收标准 | 状态 |
|---|---|---|---|
| PWA 缓存 | 构建时生成带哈希的 precache；清理旧缓存 | 首次在线加载后可离线冷启动；升级后无旧 HTML/新 JS 混用 | 已完成 |
| 安全更新 | 新版本就绪时提示用户；存在编辑内容时不自动刷新 | 更新由用户确认，确认前页面不自动重载 | 已完成 |
| 存储持久化 | 请求 persistent storage，并显示容量/授权状态 | 支持的浏览器可查看配额；拒绝授权不影响编辑 | 已完成 |
| 数据风险提示 | 离线状态、存储压力和保存失败提供可恢复提示 | 状态可见且不会遮挡正文；错误有重试或备份出口 | 已完成（含未落盘编辑的紧急恢复导出） |
| Web 安全头 | 部署 CSP、nosniff、Referrer-Policy、Permissions-Policy | 生产部署响应包含安全头，应用主要流程不被 CSP 阻断 | 已完成 |
| GitHub Token | 默认支持仅会话保存；持久保存明确提示风险 | 未授权持久化时关闭页面不保留 Token | 已完成 |

### P1 — 移动体验、性能与可访问性

| 项目 | 实施内容 | 验收标准 | 状态 |
|---|---|---|---|
| 响应式信息架构 | 桌面三栏、平板双栏、手机单任务；删除重复底栏 | 390px 宽度下正文不被工具栏/属性栏挤压 | 已完成基础修复 |
| 软键盘适配 | 使用 Visual Viewport 处理 iOS/Android 可视高度 | 键盘弹出时光标和主要操作仍可见 | 已完成（修复键盘高度重复扣减并加入回归测试） |
| 编辑器工具栏 | 高频操作直达，低频操作进入更多菜单 | 手机端无多行工具栏堆叠，触摸目标约 44px | 已完成（小屏单行工具栏、更多菜单及横屏回归测试） |
| 启动与包体 | 懒加载设置、同步、版本历史等低频模块；配置 Vite 入口/低频模块分包；CI 记录主入口 gzip | 主入口 gzip 设定预算并在 CI 记录变化 | 已实施 |
| 大数据性能 | 搜索、导入导出和 Markdown 转换逐步迁入 Worker | 大型笔记/文档树操作不明显阻塞输入 | 进行中（搜索防抖/取消、分片扫描、结果渐进展示及 Markdown 批量导入进度已实现） |
| 可访问性 | 允许页面缩放、焦点管理、对比度、reduced motion | 键盘可完成主要流程；axe 无严重问题 | 计划中 |

### P2 — 同步能力与工程收敛

| 项目 | 实施内容 | 验收标准 | 状态 |
|---|---|---|---|
| 备份恢复预检 | Pull 前展示远端/本地版本和覆盖摘要，自动建恢复点 | 用户确认前不覆盖；失败后可恢复 | 已完成（Web 确认 Pull 时自动下载本地完整恢复文件） |
| 多标签页协调 | BroadcastChannel 通知写入、刷新与冲突 | 两个标签页编辑同一笔记时不会静默互相覆盖 | 计划中 |
| 搜索索引 | Worker 中建立可重建的增量索引，改善中文检索 | 索引损坏不影响原数据，可一键重建 | 计划中 |
| 存储抽象 | 模板系统纳入 StorageAdapter，扩展跨端对拍测试 | Web/Tauri 对相同输入输出满足同一契约 | 计划中 |
| 大模块拆分 | 拆分 App、NoteEditor 和全局 CSS | 模块职责清晰且不改变用户行为 | 计划中 |
| 可观测性 | 本地诊断页、可选匿名错误上报、数据健康检查 | 用户可导出不含正文/Token 的诊断信息 | 计划中 |

## 3. 测试矩阵

- 浏览器：Chromium、WebKit、Firefox。
- 视口：桌面、iPhone 390px、Android 常用宽度、小高度和横屏。
- PWA：首次安装、离线冷启动、旧版本升级、更新时存在未保存编辑。
- 数据：IndexedDB schema 升级、配额不足、导入中断、备份恢复回滚。
- 并发：多标签页打开、同时编辑、后台标签页恢复。
- 跨端：核心 StorageAdapter 操作在 Web 和 Tauri 上执行相同契约。
