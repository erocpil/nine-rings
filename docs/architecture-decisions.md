## 2026-11-15：共享文件传输进度通道

背景：串行操作队列已有项数、耗时及停止等待状态，但原生复制仅整项结束才返回，目录内部处理不可见。

选择：在 local_files_transfer 增加可选 JavaScriptChannelId，由已验证的调用窗口绑定为私有 Channel。原生复制树通过回调报告当前路径与完整文件的实测字节，100ms节流及结束补报；前端通过共享服务和执行器传递给队列。旧调用可不传参数；两宿主继续共用一份实现。不使用全局广播，避免不同请求混流或泄露其它授权路径。

备选：改写为分块复制可提供单文件内部百分比，但会改变 Windows 数据流、权限和系统复制行为；预先扫描目录会额外消耗时间和I/O。因此本批保留 fs::copy，明确展示完整文件粒度，不估算总量或承诺实时单文件进度。

约束与验证：进度不确认发布、不取消原生写入、不触发重试。授权变化停止发送；旧请求完成后忽略迟到消息；消费者抛错不改变写入结果。Rust实文件测试验证二进制/空文件字节和发布前计量，前端测试验证请求隔离、单调计数及生命周期；两个宿主编译和 Chromium/WebKit 交互分别验证。后续按通知频率、目录处理可见性及单文件长时间无计数更新评估进一步需求。

传输不带进度参数时保持原字符串返回；带进度参数时返回 node 与最终 progress，避免通道通知晚于 invoke 结果而丢失最终计数。前端兼容旧端字符串结果；最终计数仅更新展示，写入成功仍由命令返回确认。Rust 序列化测试固定两种返回形式及 camelCase 字段。

## 2026-11-15：双栏快捷键由共享命令表驱动

浏览命令元数据、规范化、冲突校验与匹配集中在 browser-shortcuts；宿主仅提供持久化和可选的保留键清单。采用共享工具栏配置入口，不将 File Workbench 的配置接到 Nine Rings 数据库或应用单例。保留已有列表导航及操作能力检查，避免重绑定扩大文件写权限。配置验证失败不写入，持久化成功后通知已挂载目录栏；运行时检查宿主保留键，处理应用配置后续变化。针对错误存储、平台修饰键、重复与保留键、禁用／恢复及两个宿主实际交互验证；已知限制为无法发现操作系统或第三方软件全部全局快捷键。

## 2026-11-16：File Workbench 独立编辑器窗口第一阶段

在现有一个主浏览窗口之外，由 Rust 创建带单调实例编号的 workbench-editor-N 可信本地 WebView，复用原 SourceView／Markdown 工作区和独立草稿库。单个编辑器窗口保留多标签会话，打开相同规范化路径时激活已有标签；浏览窗口不再因文本编辑而隐藏。网页环境继续使用原单窗口工作区。

文件服务默认仍只允许 main。仅工作台逐实例注册的编辑器可调用读取／保存／导出等白名单命令，不授予目录授权管理、批量目录操作或程序执行能力。浏览窗口与编辑器之间通过后端持有的请求状态、版本与定向事件通信，事件只作通知；不能通过前端传入标签授权。Tauri能力文件只匹配编辑器命名空间，文件命令仍检查具体实例注册；销毁窗口后撤销该实例，重新创建使用新编号，防止旧窗口迟到调用复活。跨窗口首次采用保守保护：编辑器存在时阻止主窗口的目录写操作和撤权；原生写操作进行中也不创建编辑器。后续再按文件身份缩小保护范围。

关闭编辑标签与窗口经过每个会话已有保存／草稿／取消门禁，关闭浏览窗口仍隐藏到托盘。退出应用由主窗口先检查操作队列，再请求编辑器逐一确认，只有所有会话确认且工具任务结束才真正退出。取消不授权退出，迟到确认须匹配当前关闭请求。窗口创建失败撤回授权且浏览继续可用。可选多编辑器窗口与同一文件多可写会话不在第一阶段范围。


窗口创建通过异步命令的后台线程执行，并由独立创建锁串行化；Tauri当前本地依赖源码明确提示Windows同步命令中创建WebView会死锁。请求状态持有文件完整授权路径身份、当前项、打开定位序号及单调修订。关闭使用专属请求编号，拒绝旧确认及尚有文件的最终确认；首次读取前窗口尚不能编辑，允许启动失败时直接关闭。保存通知只刷新目录元信息，不把通知失败当作磁盘写入失败；草稿事务通过共享IndexedDB和轻量storage通知更新浏览窗口入口。

## 2026-11-16：File Workbench 路径级编辑保护

背景：独立编辑器存在或任意恢复草稿存在时，整个浏览工作台禁止目录写入，妨碍同时浏览和编辑。仅在前端取消禁用会绕过原生全局窗口保护，也无法覆盖窗口间的打开／写入竞争。

选择：在可选 FileWindowAccess 中登记各受信编辑器当前文件的规范路径，目录写入与保存取得覆盖实际来源／目标的原生路径租约；路径相同或父子重叠时拒绝并发操作。编辑器新增文件须与租约原子互斥，关闭文件后撤销相应保护；目录写入租约由后台工作线程持有至真实操作结束。其它宿主不安装该可选状态，保持现有权限模型。根撤权和根重命名保留全局保护。路径比较保守忽略大小写以覆盖常见不区分大小写文件系统，宁可多阻止也不漏阻止。

前端按草稿身份解析授权根，再以根的规范路径与相对路径比较关联范围；未知、失效授权或无效旧身份无法证明不相关时仍阻止，且不移动或删除草稿。已打开文件无论是否已保存均保护，暂不自动迁移会话身份与书签。备选的仅保护脏文件方案要求跨窗口脏状态和移动事务，本批不采用。

验证要求：原生路径重叠、跨授权根别名、编辑器打开与租约竞争、关闭后释放、后台调用持续持有租约；前端无关草稿可继续、相关草稿及目标草稿受阻、存储异常保守失败。实机多窗口验收仍由用户执行，不能用浏览器模拟替代。

影响审查结论：SAFE（上述自动化验证范围），未将编译成功单独作为安全结论。`native/file-host/src/window_access.rs:52` 的 `protect_editor_path` 与 `:77` 的 `begin_paths` 使用同一互斥状态，创建／保存／目录写入的来源与目标均由 `local_files.rs` 的可信规范路径构造；后台闭包持有租约，已关闭窗口迟到调用仍不能取得新窗口授权。`src/apps/file-workbench/operations.ts:13` 的 `clean` 在来源、持锁复核和目标写入前读取草稿，路径别名通过规范根比较。`src/lib/local-files/browser-operation-core.ts:83` 仅将明确前缀的原生保护错误判为未写入，普通磁盘错误即使包含同名字样仍保留需核对状态。未改动 IPC 字段、磁盘编码或既有持久化草稿格式。尚未执行本机 GUI 多窗口实测，Windows／Linux 实机语义也未据此宣称验收。

## 2026-11-16：纯文本快速浏览复用源码查看器

当前完整文件编辑器已有只读源码、搜索／跳转、折叠、书签与符号导航；空格快速预览仍是静态pre，重复实现搜索且切换文件丢失位置。选择只替换非Markdown文本的快速浏览投影：通过只读DocumentSourceSurface和DocumentNavigationWorkspace装配现有能力，不引入文件写入或数据库，也不复制另一套解析／格式工具。Markdown渲染及源码预览保留现有字符位置映射，图片与PDF组件不改动。

新增按宿主隔离的有限阅读状态存储，仅保存文件身份、内容指纹和位置／选区／折叠／书签，不保存正文。相同内容恢复，不同内容不复用旧偏移；存储异常不阻止阅读。保留现有快速预览大小预算、截断提示、取消及迟到结果隔离，通过显式入口打开完整文件，不能把截断正文作为可写源。阅读界面沿用公共源码工具和只读权限，不向文件内容写回。后续PDF／EPUB仅复用宿主状态存储与工具入口的边界，不强行共用文本位置模型。

## 2026-11-16：磁盘 PDF／EPUB 使用只读阅读投影

选择为已有FileBrowserQuickPreview增加EPUB分支，并扩展PDF单页投影，继续共享两宿主的目录读取与预览端口，不将磁盘书籍导入数据库，也不装配整个资料库UI。EPUB复用解析、章节安全呈现与资源注册函数，新增可选取消信号／解压预算及关闭桥接脚本的参数；既有阅读器调用保持默认行为。原生read_asset仅增加epub扩展名，保持路径授权、文件类型、32MiB预算和分段边界。

阅读状态按宿主、授权根、路径和内容指纹核验，最多32份，不保存书籍正文。PDF按页渲染、按需扫描文本，EPUB按章节展示；关闭时释放任务、worker、iframe和URL。未选择将数据库PDF/EPUB阅读器整体搬入独立工作台，避免带入资料库身份及批注写入生命周期。后续如需分享批注，应先制定可迁移的外部书籍身份与存储协议。

影响结论：新增端口可选，旧宿主不支持时明确拒绝；两宿主共用文件服务，Rust命令名与IPC字段不变。既有资料库解析函数调用保留默认预算与桥接；新磁盘阅读入口使用较小预算和无脚本sandbox。验证覆盖原生读取扩展、取消与超时、内容变化失效、真实PDF/EPUB及原有工作台回归；浏览器测试不替代安装版实机验证。

## 2026-11-16：阅读导航与双模式 PDF 视口

交互参考[macOS Preview](https://support.apple.com/en-mide/guide/preview/prvw11470/mac)的单页／连续滚动、缩略图和页码导航，以及[calibre 阅读器](https://manual.calibre-ebook.com/en/viewer.html)的目录、全书搜索、书签和排版分工。采用紧凑工具、按需缩略图及独立设置，不引入书籍批注写入。

PDF保留现有单页投影，新增按需加载的PDF.js PDFViewer适配组件，复用其视口渲染队列、页缓存与内部链接服务；不为连续滚动预绘全书。旋转只作用于视图，适应整页与手动缩放互斥。缩略图每批最多50页，仅进入可视范围的缩略图渲染；关闭释放画布。连续视图保存当前选中页及相对页顶的可视区偏移；整页适配同时显示多页时允许负偏移，避免将显式选中页误改为顶部可见页。正文、缩略图、目录及链接共用跳转历史。

共用ReaderPreviewNavigation维护最多50步的会话前进／后退历史，书签与排版偏好通过宿主隔离的ReaderExtras保存（最多32份文件、每份100个书签、1000章位置、256KiB元数据总预算），以内容指纹校验。不写回PDF／EPUB本身，书签不宣称跨设备同步。旧阅读位置键继续兼容。

EPUB沿用章节呈现与搜索标记代码，新增逐章、可取消的全文文本查找（最多1000项）、行距／页边距／三种配色、章节各自位置和脚注弹层。标准noteref/doc-noteref及footnote/endnote目标显示脚注内容；可以复制、关闭或前往脚注，再通过历史返回。普通章节链接仍跳转，外部链接仍拦截。

WebKit验证发现，仅使用allow-same-origin而禁用iframe脚本，会同时阻止宿主绑定的子文档点击回调。当前磁盘适配器允许宿主事件执行，但章节继续移除脚本／事件属性，首个CSP声明script-src 'none'及default-src 'none'，不加载资料库桥接脚本，不开放顶层导航／弹窗／表单。章节在事件绑定完成前隐藏，避免用户在未就绪内容上触发浏览器默认导航。资料库原有安全呈现默认参数保持兼容。

影响分析：ReaderPreviewState及文件读取端口未改签名；ReaderExtras为新增可选元数据。检查两个宿主的共享预览入口、解析函数调用方、位置保存／取消／销毁路径及Vite分块。连续阅读模块改为懒加载，避免独立工作台PDF块超过500KiB；开发服务器预优化viewer依赖，避免首次进入时重载授权会话。


## 2026-11-19：右键级联菜单的归属与完成边界

背景：正文右键菜单转发工具栏命令后曾立即关闭自身，悬停展开因此丢失父菜单。选择保留已有工具栏命令与弹层实现，补充 DOM 级菜单归属和最终动作完成通知；不复制字号、折叠级别等命令，不重写一套菜单动作模型。owner 按右键菜单实例生成，不使用全局当前菜单单例。

实施：EditorContextMenu 保留父层及分组；BlockActionMenu 和工具栏下拉菜单标记同一 owner，使外部点击、滚动与键盘返回能够识别整条菜单链。叶子动作完成后关闭自身并通知父层；父层不重复切换已关闭的工具栏按钮。原命令接口和文件／数据库写入协议不变。鼠标同级切换、逐层 Esc／Left、Right 重入、外部关闭、单次格式操作与撤销、两宿主及经典／非经典风格均以交互回归核验。
