## 2026-11-15：共享文件传输进度通道

背景：串行操作队列已有项数、耗时及停止等待状态，但原生复制仅整项结束才返回，目录内部处理不可见。

选择：在 local_files_transfer 增加可选 JavaScriptChannelId，由已验证的调用窗口绑定为私有 Channel。原生复制树通过回调报告当前路径与完整文件的实测字节，100ms节流及结束补报；前端通过共享服务和执行器传递给队列。旧调用可不传参数；两宿主继续共用一份实现。不使用全局广播，避免不同请求混流或泄露其它授权路径。

备选：改写为分块复制可提供单文件内部百分比，但会改变 Windows 数据流、权限和系统复制行为；预先扫描目录会额外消耗时间和I/O。因此本批保留 fs::copy，明确展示完整文件粒度，不估算总量或承诺实时单文件进度。

约束与验证：进度不确认发布、不取消原生写入、不触发重试。授权变化停止发送；旧请求完成后忽略迟到消息；消费者抛错不改变写入结果。Rust实文件测试验证二进制/空文件字节和发布前计量，前端测试验证请求隔离、单调计数及生命周期；两个宿主编译和 Chromium/WebKit 交互分别验证。后续按通知频率、目录处理可见性及单文件长时间无计数更新评估进一步需求。

传输不带进度参数时保持原字符串返回；带进度参数时返回 node 与最终 progress，避免通道通知晚于 invoke 结果而丢失最终计数。前端兼容旧端字符串结果；最终计数仅更新展示，写入成功仍由命令返回确认。Rust 序列化测试固定两种返回形式及 camelCase 字段。

## 2026-11-15：双栏快捷键由共享命令表驱动

浏览命令元数据、规范化、冲突校验与匹配集中在 browser-shortcuts；宿主仅提供持久化和可选的保留键清单。采用共享工具栏配置入口，不将 File Workbench 的配置接到 Nine Rings 数据库或应用单例。保留已有列表导航及操作能力检查，避免重绑定扩大文件写权限。配置验证失败不写入，持久化成功后通知已挂载目录栏；运行时检查宿主保留键，处理应用配置后续变化。针对错误存储、平台修饰键、重复与保留键、禁用／恢复及两个宿主实际交互验证；已知限制为无法发现操作系统或第三方软件全部全局快捷键。

## 2026-11-16：File Workbench 独立编辑器窗口第一阶段

在现有一个主浏览窗口之外，由 Rust 创建带单调实例编号的 workbench-editor-N 可信本地 WebView，复用原 SourceView／Markdown 工作区和独立草稿库。单个编辑器窗口保留多标签会话，打开相同规范化路径时激活已有标签；浏览窗口不再因文本编辑而隐藏。网页环境继续使用原单窗口工作区。

文件服务默认仍只允许 main。仅工作台逐实例注册的编辑器可调用读取／保存／导出等白名单命令，不授予目录授权管理、批量目录操作或程序执行能力。浏览窗口与编辑器之间通过后端持有的请求状态、版本与定向事件通信，事件只作通知；不能通过前端传入标签授权。Tauri能力文件只匹配编辑器命名空间，文件命令仍检查具体实例注册；销毁窗口后撤销该实例，重新创建使用新编号，防止旧窗口迟到调用复活。跨窗口首次采用保守保护：编辑器存在时阻止主窗口的目录写操作和撤权；原生写操作进行中也不创建编辑器。后续再按文件身份缩小保护范围。

关闭编辑标签与窗口经过每个会话已有保存／草稿／取消门禁，关闭浏览窗口仍隐藏到托盘。退出应用由主窗口先检查操作队列，再请求编辑器逐一确认，只有所有会话确认且工具任务结束才真正退出。取消不授权退出，迟到确认须匹配当前关闭请求。窗口创建失败撤回授权且浏览继续可用。可选多编辑器窗口与同一文件多可写会话不在第一阶段范围。


窗口创建通过异步命令的后台线程执行，并由独立创建锁串行化；Tauri当前本地依赖源码明确提示Windows同步命令中创建WebView会死锁。请求状态持有文件完整授权路径身份、当前项、打开定位序号及单调修订。关闭使用专属请求编号，拒绝旧确认及尚有文件的最终确认；首次读取前窗口尚不能编辑，允许启动失败时直接关闭。保存通知只刷新目录元信息，不把通知失败当作磁盘写入失败；草稿事务通过共享IndexedDB和轻量storage通知更新浏览窗口入口。
