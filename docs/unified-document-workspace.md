# 统一文档工作区

更新：2026-10-29。

## 目标与当前结构

数据库文档和磁盘文件在相同格式、权限、布局及配置下，使用同一套编辑／阅读工作区。以原数据库实现为基线，磁盘适配器直接接入；不通过逐项补齐另一套渲染器维持表面一致。

- `RenderedDocumentWorkspace`（位于 `NoteEditor.tsx`）是两类普通 Markdown 的公共渲染入口。它统一编号展示、schema、TipTap 会话、批量折叠、手势、目录／书签、块菜单、工具栏、选区弹层、右键菜单、状态栏及标题。
- `DocumentSourceSurface` 是共同源码壳。两类来源注入原始文本、CodeMirror 会话及编辑回调，使用同一工具栏／状态栏和 `MarkdownSourceEditor`。
- `DocumentNavigationWorkspace` 统一源码目录、符号、书签及同词导航；渲染目录使用同一个 `DocumentOutlineList`、导航标题工具、展示插件与布局控制器。两种文本模型分别投影位置，不要求原始行号等于渲染块号。
- `useDocumentPreview`、`DocumentPreviewControls` 和 `MarkdownSplitPreview` 统一源码并排预览、同步滚动及设备偏好。磁盘 Markdown、Mermaid、Flow 不再另写预览逻辑。
- `useMarkdownViewPosition` 统一源码／渲染位置与选区交接；磁盘初次打开与跨文件切换仍使用文件会话的行锚点、滚动快照和恢复门禁。
- `DocumentTitleField` 统一标题命中、信息卡、输入框／完整标题预览及重命名反馈。数据库可即时保存标题草稿；磁盘在 Enter／失焦时执行受保护的重命名。

原本地独立的 `DocumentReadingView` 和 `MarkdownReadingView` 已删除，不再保留第二套只读会话、批量折叠、菜单动作组装和阅读恢复控制器。实验性局部只读渲染默认关闭；它仍只对具备相应能力的数据库宿主开放，不能绕过磁盘适配器。

## 分层与能力

| 层次 | 职责 | 边界 |
| --- | --- | --- |
| 来源适配 | 身份、版本、权限、读写、草稿、书签投影、资源授权、重命名 | 不实现另一套编辑器、菜单或排版规则 |
| 公共工作区 | 标题、编辑／阅读工具、折叠、选择、查找、目录、书签、块操作、状态栏 | 不自行调用文件服务，不猜测数据库身份 |
| 布局策略 | 文档／紧凑、浮层／固定、左右侧、宽度与面板比例 | 不修改正文、选区或撤销历史 |

`RenderedWorkspaceHost` 注入能力：块引用、文档导航历史、标注、标题编辑／提交、原文复制、资源处理、来源状态说明及附加文件命令。`origin` 仅用于选择各来源自己的布局偏好；不能用它决定另一套渲染或菜单实现。

磁盘不进入 `ProtectedNoteEditor`、数据库同步或全局文档位置历史。其设备会话使用 `local-file:` 命名空间，不伪造 `nr-note:` 目标。数据库专属引用／维基候选、标注存储和导航入口按能力关闭；复制、删除、缩进、样式、多块选择等通用操作直接使用公共工作区的动作集合。

## 两类源码入口的核对

源码内核本来就是共同的 `MarkdownSourceEditor`。选择数据库组合为基线不能删除磁盘入口原有的能力：

| 契约 | 数据库适配器 | 磁盘适配器 |
| --- | --- | --- |
| 文本权威 | 源码时为 CodeMirror／`SourceNavigationSession`；保存投影成 Delta | 源码时为 CodeMirror；磁盘快照为写入基线，原始字符串保留 |
| 渲染权威 | 当前 ProseMirror 文档，延迟生成不可变保存投影 | 同一 ProseMirror 文档，由文件适配器延迟生成 Markdown |
| 撤销 | 各视图自己的 ProseMirror／CodeMirror 历史 | 同样使用各自历史，源码会话继续由 `localFileSessions` 保留 |
| 首次位置恢复 | 文档阅读状态与阅读锚点 | 文件身份、行锚点、滚动快照；恢复期间不保存临时位置 |
| 保存 | 自动保存、批次确认、失败保护 | 手动保存、草稿检查点、外部修订检测及原子写入 |
| 格式与权限 | 元数据中的语言及只读查看覆盖 | 文件名检测／查看覆盖，保留 BOM 与换行约定 |
| 书签 | 文档元数据中的模型位置 | 文件行偏移投影，设备状态单独持久化 |

不合并两种文本内核的撤销栈，不承诺跨源码／渲染共享撤销；这与既有数据库行为一致。不能把磁盘恢复替换成数据库导航，也不能因为仅打开文件、切换模式、选区、布局或阅读折叠就重新序列化原文。

## 磁盘 Markdown 渲染编辑

`LocalMarkdownWorkspace` 是公共工作区的文件适配器：

1. 首次解析原文生成编辑投影，保留原始字符串和初始 ProseMirror 快照；打开、关闭、只读阅读及纯元数据更新不生成新 Markdown。
2. 实际正文编辑只登记不可变读取函数，合并 200ms 内的转换；不是每次按键都立即序列化全文。未处理读取函数仍计入未保存状态。
3. 保存、关闭检查点及切换视图先同步冲刷读取函数。转换失败时保留待处理快照，阻止依赖完整源码的操作并显示原因，不以旧字符串覆盖编辑。
4. 撤销到初始模型时恢复逐字相同的初始原文，包括原有空白和 Markdown 写法。已实际修改的正文使用既有 Markdown 序列化器，因此可能规范化列表符号、转义、脚注定义位置等；需要保留所有原始写法时使用源码模式。
5. 只读门禁仍拒绝程序化改文及原生粘贴。只读引用／代码折叠等显示事务只更新阅读状态，不回写文件；书签单独映射至设备存储。
6. 磁盘保存始终经原 `localFileService.write`，保留 UTF-8/BOM、换行、修订校验、外部修改冲突和草稿恢复。保存过程中继续输入不能把新编辑标成已保存。

文件是否实际允许覆盖／重命名仍由授权和服务决定。浏览器目录快照可以编辑为本机草稿并另存为，不能冒充已取得原目录写权限。

## 图片与原文保真

`DocumentResourceContext` 注入资源解析，不替换文档中存储的地址。`ResizableImage`、行内图片和只读并排预览均通过它解析授权目录内的相对图片。复制原文或保存仍包含原相对路径；进入图片查看器时才为本次查看解析图片列表。

磁盘粘贴／拖入的图片使用可随 Markdown 保存的 data URL，不生成只能在数据库中解析的 `nr-image:` 引用。数据库原有图片存储与 URL 生命周期保持不变。地址解析失败保留原地址和文本，不越过授权目录读取资源。

## 位置、折叠与标题

- 视图切换按钮保留正文焦点，防止浏览器先将只读选区滚回旧位置，再记录错误锚点。
- 源码未被操作且正文、宽高与字体未变时，往返恢复原阅读像素位置及引用／代码／表格等内部滚动；否则按文本位置映射。用户真实导航优先，程序恢复不能冒充新导航。
- 启动时恢复持久化源码视口不属于渲染往返，不能复用启动时的顶部像素快照。
- 源码卸载只冲刷源码位置，当前视图偏好由独立提交更新，避免清理函数把已进入渲染模式的偏好改回源码。
- 目录跳转仅展开遮住目标标题的祖先章节，保留目标本身的折叠状态。普通只读章节命中与同步标题锚定使用 `reading-heading-navigation`，不依赖文件路径。
- `DocumentTitleField` 只在实际标题文本范围内显示信息卡，允许移入卡片选取和复制；锁及标题右侧空白不触发卡片。
- 磁盘标题按 Esc 取消时跳过随后的失焦提交，避免正文同步聚焦早于 React 草稿复原而错误改名；源码与渲染遵守相同规则。
- 磁盘重命名先检查未保存编辑／恢复草稿，失败保留文件及输入草稿；成功迁移书签、读写规则、阅读状态、源码选区、tab 和最近打开记录，再打开新身份。不能虚构文件系统未提供的创建／访问时间。

## 验证与保留边界

- 同内容对照：相同格式、权限和配置下比较全部风格的块间距、字体与行高；菜单从同一工作区读取可用命令。
- 内容保护：原文往返无写入、完整撤销恢复原写法、待处理编辑立即保存、相对资源不进入保存内容、只读拒绝改文、外部冲突不覆盖。
- 连续性：布局切换不重建源码视图；手机与桌面模式交接保留视口、当前行／块、折叠及嵌套滚动。重命名后文件树、tab 和视图状态同步。
- 真实文件选择／续期、原生 IME、系统剪贴板授权不能只凭浏览器夹具宣称验收。每批具体测试与未执行项记录在 [E2E 清理进度](e2e-repair-progress.md)。

数据库的同步、版本历史、加密、关系元信息，以及文件系统授权、磁盘冲突与原始字节写入仍属于不同来源能力。这些差异不能通过伪造身份或将磁盘文件隐式导入数据库消除。
