# 单书阅读数据备份（第一阶段）

基线：`ecda772`。入口：设置 → 阅读资料库 → 图书卡片“阅读备份”。

## 范围与使用

- 导出为独立的 `*.reading.json` 文件，包含这一本 PDF/EPUB 的高亮、备注、书签、阅读位置和排版设置；EPUB 还包含文字锚点、每章进度、自定义背景色、智能合并设置和人工断行合并记录。
- 不包含 PDF/EPUB 原文件、封面二进制、笔记正文或凭据，也不修改原文件。
- 新设备先导入同一份原文件，再在目标图书的备份面板选择 JSON。重命名原文件或新设备产生不同资料库 ID 不影响匹配；文件内容变化则拒绝恢复，不能仅凭同名/同大小误配。
- 选择文件仅预检，不写入。用户点击“确认合并阅读数据”才恢复；默认保留当前阅读位置和排版设置，勾选复选框后才覆盖。
- 恢复保留所有本地批注和书签；完全相同的数据跳过，同 ID 不同内容保留独立副本。重复导入不会不断产生副本。没有删除墓碑或三方基线，所以备份中的旧记录可能重新加入本地已删除的项目。
- 请先关闭其他窗口中正在阅读的同一本书，避免其他阅读器继续保存旧位置。当前阶段没有跨窗口阅读会话锁。

## 协议与数据安全

协议标识 `kind: nine-rings-reading-data`、`version: 1`；与应用全量 `notes` JSON 协议分离，不能混用。

文件指纹 `sha256-chunks-v1` 的计算：

1. 顺序读取 4 MiB 分块，每块计算 SHA-256；最后一块保留实际长度。
2. 拼接 UTF-8 前缀 `nine-rings:sha256-chunks-v1:<文件字节数>:` 与各块的原始 32 字节摘要。
3. 对拼接结果计算 SHA-256，输出 64 位小写十六进制。

这不是原文件直接 SHA-256，而是覆盖完整内容、限制读取内存的版本化指纹。需要安全上下文提供 Web Crypto，不使用弱散列降级。

备份最多 20 MiB；单类批注/书签/断行记录最多 10000 条。导入预先校验版本、ID 唯一性、范围、进度、颜色和不安全属性；未知版本或损坏记录拒绝整份备份，不静默跳过。导出也经过同一校验，避免生成无法恢复的文件。

恢复时再次校验文件指纹；密码学散列全部在写事务之前完成。目标文件元数据、批注、书签在**同一个资料库事务**中合并，并等待 transaction complete；中途失败整体回滚。只读快照同样跨该资料库的三个 store 获取，避免进度与批注分别取数。

保留本地记录，通过忽略资料库 ID 和记录 ID 的规范化内容比较实现幂等；ID 冲突副本使用内容摘要派生 ID，不覆盖其他图书的记录。原文件、封面、导入时间和本地名称不被备份字段覆盖。

## 与后续工作的边界

- **未自动纳入 GitHub Push/Pull 或应用全量 JSON**。设置页明确区分两种备份范围。
- 不自动重写既有笔记摘录中的 PDF/EPUB 资料库 ID 链接。单书备份只负责阅读数据，不迁移笔记正文关联。
- 应用 JSON 导入与 GitHub Pull 已补恢复互斥锁和不含内容的中断记录，详见[恢复协调说明](backup-restore-coordination.md)。这并不是跨库原子恢复，也不覆盖单书阅读数据恢复。
- 后续全量备份仍需统一资源清单、跨数据库可恢复事务及失败后重启续作，再接入这份可版本化协议；不能简单地在现有 JSON 写完后附加两个独立数据库写入并宣称全量原子恢复。
- 编辑器拆分仍是后续独立任务，本轮未改变正文折叠、虚拟化或编辑器会话架构。

## 验证

- `tests/unit/reading-backup.test.ts`：14 项，包括跨 ID 恢复、同名同大小异内容拒绝、冲突/重复导入、图形批注、事务失败回滚、损坏输入、分块末尾变化及 EPUB 锚点/章节进度/人工断行数据。
- `e2e/reading-backup.spec.ts`：PDF/EPUB × 390px/1280px，实际导出下载、预检、取消、内容不匹配、显式恢复进度、重复导入及页面重载后持久化；Chromium 首轮 4 项通过。
- Linux Playwright WebKit 的 4 项流程均在原文件导入的既有资料库事务处失败，尚未进入阅读备份操作。独立运行既有 `pdf-reader` 导入用例也显示“PDF 导入失败：PDF 资料库事务失败”，与前次审查记录一致；不能算作本功能 WebKit 已验证。实际 iOS 安装版和 Windows Tauri 仍需真机核对文件选择、下载/保存及恢复。
- 最终 `npm run check` 和生产构建通过，lint 保持 145 个既有警告、0 错误；新增备份与既有 PDF/EPUB 导入阅读、设置导航共 7 项 Chromium 回归通过。
