# 共享源码与导航组件

更新：2026-10-28。

## 边界

数据库文档和磁盘文件使用同一源码编辑器、导航条目和工具控件。共享实现不要求它们使用相同的外壳位置：数据库文档可以悬停弹出目录或固定多个面板；磁盘文件的导航停靠在标题栏下方、文本区右侧，使用本地工作区自己的宽度、展开状态和会话。

正文来源决定读取、保存、权限、身份与持久化，不决定符号标记、同词列表或书签条目的实现。渲染内核的相同分层见[共享文档渲染](document-rendering.md)。

## 职责

| 层 | 组件／模块 | 职责 |
| --- | --- | --- |
| 编辑器 | `MarkdownSourceEditor` | CodeMirror、工具栏、状态栏、只读门禁、行号菜单、源码右键菜单、选区保留；通过回调调用宿主书签能力 |
| 导航投影 | `source-navigation-view` | 为解析结果补充统一符号标记和排序名称；将树折叠投影成可见条目，保留原始索引并支持超过六层的源码嵌套 |
| 导航呈现 | `DocumentOutlineList` | 标题／符号列表、展示插件、虚拟行、当前项跟随；不读取数据库或磁盘 |
| 受控工具 | `DocumentNavigationTools` | 符号搜索、排序、折叠／展开和目录顶中底按钮；宿主传入状态、列表引用与正文滚动能力 |
| 书签呈现 | `DocumentBookmarkRow`、`BookmarkRenameDialog` | 共享跳转、重命名、删除及手机滑动操作；显示层只要求标签和定位信息，不要求数据库创建时间 |
| 同词交互 | `useSourceWordMatches` | 订阅指定编辑器的匹配状态与打开请求，提前处理 Ctrl/Command+单击；宿主决定面板如何打开 |
| 同词呈现 | `SourceWordMatchList` | 一行一个结果，同一行重复匹配加粗行号，定位当前匹配，使用同词展示插件的字体、颜色和行高 |
| 数据库宿主 | `MarkdownDocumentView`、`DocumentNavigationWorkspace` | 源码与模型映射、数据库书签、浮层锚点、多面板固定及尺寸；符号跳转校验当前源码 |
| 文件宿主 | `LocalFileView` | 原文、磁盘权限与保存、源码会话、本地偏移书签、固定右侧停靠区及尺寸 |

## 布局模式

设置 → 外观与布局 → 布局设置提供两种文档工作区布局。数据库文档默认使用“文档布局”，本地文件默认使用“紧凑布局”；两类文档都可单独切换。

- 文档布局沿用悬停预览、多个固定面板、左右侧及面板排列设置。
- 紧凑布局在标题栏下方右侧展示单个目录／符号／书签／同词面板，不通过悬停打开。
- `document-workspace-layout.ts` 保存布局选择及各来源的紧凑面板状态／宽度；已有 `workspace-layout.ts` 保留文档布局状态。切换不覆盖另一种布局，也不重建正文编辑器。
- 首次使用读取旧本地导航状态与宽度，不改写旧键。布局偏好纳入前端设置备份，不携带磁盘路径及授权。
- `DocumentNavigationWorkspace` 同时服务数据库源码及本地源码／渲染导航。宿主只提供原始源码修订、书签投影、跳转、滚动与持久化能力；共享组件负责符号分析、搜索、排序、菜单和面板交互。

## 交互约束

- 源码行菜单和右键菜单只在编辑器内实现一次，不再由数据库外壳重复捕获。可编辑／只读能力由编辑器状态确定；行号点击不修改光标，菜单打开时选区仍可见，Esc 关闭后保留选区。
- 同词事件只订阅对应 EditorView 的 DOM，不监听其它文档冒泡到 window 的请求。缓存的非活动文档不应被当前文档的 Ctrl/Command+单击打开匹配面板。
- 修饰键单击须在 CodeMirror 的平台多选处理之前识别；普通单击和拖选仍由编辑器处理。共享 hook 提供 `onOpen(offset)`，不直接操作停靠布局。
- 目录滚动按钮单击只滚动列表，双击通过宿主回调滚动正文。普通渲染、数据库源码、本地 Markdown 源码／渲染使用相同按钮；按钮是否占位隐藏由宿主决定。
- 符号排序与搜索不改变解析器身份及源码偏移；当前项索引必须相对于过滤后的条目计算，而非过滤前数组。
- 书签的行／块索引由适配器提供。数据库书签仍映射到共享文档模型；本地书签仍是设备本地的源码偏移，不加入数据库同步。共享条目通过 `indexKind` 区分行与块，不伪造创建时间。
- 展示插件控制条目的字体、字号、颜色和行高，不接管文件权限或宿主位置。布局宽度、固定／悬停状态与存储键留在宿主中。

## 验证

`tests/unit/source-navigation-view.test.ts` 验证折叠投影、原始索引、超过六层的源码树，以及符号身份和偏移不变。

`e2e/shared-source-navigation.spec.ts` 通过真实本地文件入口验证共享书签重命名、符号过滤跳转、Esc 仅关闭搜索、Ctrl/Command+单击同词面板、一行多处匹配归并和跳转，并测量面板仍位于编辑器右侧、标题栏下方，且操作不修改源码。

现有本地文件／位置／操作、源码符号、同词匹配、右键菜单、目录连续性与展示插件用例验证数据库和文件入口的交互与布局。浏览器自动化覆盖 Chromium、WebKit；原生磁盘授权、IME 和系统剪贴板权限仍属于对应平台验收。
