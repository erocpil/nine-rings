# 文档双入口体验优化

## 弹层字号统一（2026-09-09）

- 文件列表标题、文档树名称、正文目录和书签正文统一为 13px；辅助信息维持 10–11px，选中项仍用强调色和适度字重区分。
- 目录虚拟列表的文字宽度估算同步按 13px 缩放，两行条目的预留高度从 39px 调整为 42px，避免字号增大后遮挡或重叠。
- 横竖屏 WebKit 回归检查四种手势入口的实际计算字号。

## 本轮交付补充（2026-09-09）

- 右划的两个入口统一 32×40 工具按钮占位，返回按钮不再使用额外的大方框，工作区切换留左、工具靠右。
- 右侧手势改为上半部目录、下半部书签；键盘关闭时抽屉按 100dvh 覆盖，不使用转屏期间可能过期的可视视口缓存；键盘打开时仍跟随 visualViewport。
- 编辑工具栏去除旧分组竖线；链接只保留在更多，块内换行移到固定工具区。设置关闭图标采用原专注退出图标，专注退出改成与 Tauri 退出全屏一致的内收四角。
- 更多菜单新增“复制块”：以光标所在顶层块为单位，整段/整列表/整引用/整表格复制，优先 HTML + 文本，失败时回退纯文本并提示；不移动选区、不修改文档。
- iOS 双空格句号属于系统输入法能力。代码未禁用 autocorrect；WebKit 已有多段落 contenteditable 不触发句号的公开问题（https://bugs.webkit.org/show_bug.cgi?id=248387）。不能仅靠桌面 WebKit 模拟确认真机根因；未加入会误改代码、缩进及 Markdown 空格的全局替换规则。

- 手机普通模式点击目录/书签时，浮层上沿跟随顶部按钮行定位，转屏后重新测量并限制可视高度；左划的阅读侧栏竖屏约 82%（最多 420px）、横屏 78%，保留遮罩收回空间。

- 细节补充：普通模式书签入口与专注模式共用数量角标（零隐藏、超过 99 显示 99+），完整编辑器与只读虚拟渲染同步更新。文档列表类型和修改时间同排，时间右对齐；字段开关继续独立，极窄空间允许换行。
- 排序字段、排序方向与全部路径共用同一全宽控件外观：左侧图标、当前选项文字、右侧箭头，以及一致的高度、圆角、底色和焦点反馈；保留原生 select 操作。

## 查找入口整合（2026-09-09）

- 普通模式左上角的快速切换、全局搜索移入文档列表顶部工具栏；列表元数据查找改用漏斗图标，与全局搜索区分，快捷键保持不变。
- 快速切换/全局搜索打开前收起文档列表，避免叠层遮挡结果；全局搜索进入普通模式，在左侧显示并同步聚焦搜索输入。列表自身查找仍留在列表中，不读取正文。
- Escape 关闭全局搜索时取消尚未执行的输入防抖，避免关闭后旧搜索再次弹出。

## 边缘手势与面板层次补充（2026-09-09）

- 允许从正文的章节折叠、块插入与引用折叠按钮开始边缘滑动；其它按钮、链接、表单输入和已选中文字继续避让。点按保持原操作，滑动不执行折叠。
- 左侧文档列表/目录树与右侧目录/书签抽屉共用较深的主题底色，与正文区分；左侧遮罩加入 4px 背景模糊，不对编辑器本身应用滤镜，不支持模糊时保留遮罩。
- 文档树竖屏宽度改为可视宽度的 82%（最多 420px），横屏保留 70vw；两侧抽屉及遮罩覆盖完整可视高度，底部安全区改为弹层内部 padding，不再露出正文亮条。文档列表弹层同样保留内部底部安全空间。

## 第七批：显示字段与排序方向（2026-09-09）

- 路径、标签、类型、修改时间独立开关；默认显示路径，其余隐藏。标题和收藏操作始终保留。配置在当前应用会话内保存，关闭弹层再打开不丢失。
- 全部文档/收藏支持按标题或修改时间排序，并显式选择升降序；切换排序字段时，标题默认升序、修改时间默认最新在前。最近打开仍严格按真实访问顺序，不显示排序控件。
- 修改时间按时间戳排序，同值以文档 ID 稳定排序。调整排序或显示字段时重置旧滚动位置，避免行高变化后的错位；清除筛选不重置显示配置或排序。
- WebKit 回归覆盖字段互不影响、标题/时间双向排序、重新打开保留及最近打开隐藏排序入口。

## 第六批：列表视觉与条件管理（2026-09-09）

- 之前五批已交付；本批继续收敛列表视觉，不改动正文排版、目录树批量操作和阅读器。
- 页签选中、结果数量、当前文档行采用轻量圆角与主题强调色；列表使用留白分隔，不给每条文档加卡片边框。保留标题两行、靠右数量和深色实心收藏。
- 路径、类型与新增的独立标签筛选采用一致控件。标签精确匹配，可与关键词、路径、类型组合；三个视图共用条件，会话内保留。
- 已应用条件集中展示为可移除的小标签，收起面板仍可清除；提供一键清除全部条件。更改条件继续重置各视图旧滚动位置。
- 焦点轮廓、触摸按下、桌面悬停分别处理；所有颜色沿用主题变量。标签选项仅来自元数据，不读取任何正文。
- 显示字段与排序方向在第七批完成；批量移动/删除仍留在下半部目录树，避免两个入口重复。
- 路径选择弹层改为内容自适应高度，搜索与逐级导航时随结果收缩；最大 520px 且不超过可视区域剩余高度，超出部分仅列表滚动。上沿优先对齐路径筛选入口，横屏或软键盘挤占空间时向上避让；确认/取消及原有焦点归还保持不变。

## 第一批（2026-09-09）


- 上半部右划：快速找回文档；下半部右划：目录树与批量整理。
- 上半部顶部保留文档/阅读切换、搜索、新建和收回；第二行提供最近打开、全部文档、结果数量及筛选。
- 搜索和筛选按需展开；排序仅用于全部文档，最近打开按真实访问顺序排列。
- 复用 `nr:recentNotes` 的最近 20 项访问记录，仅保存 ID，不修改文档的更新时间。
- 标题最多两行，路径显示末两级；指定路径后隐藏重复部分。标签、修改日期默认隐藏，可在筛选区开启。
- 当前应用会话内保留查询、路径、排序、显示选项及滚动位置，重新打开先展示缓存再刷新。不会跨应用重启保存查询。
- 列表缓存不保存正文；选择条目时重新读取完整文档，避免打开过期内容。搜索只匹配元数据，加密文档解锁后亦不搜索正文。
- 保留底部可继续滚动约三分之一屏的空间，以及两个入口一致的收回行为。

## 第二批（2026-09-09）

- 路径筛选替换为独立选择面板：支持搜索完整路径/目录名、逐级进入、返回上级、回到全部路径；只有确认时才修改筛选，取消或 Escape 不影响原列表。
- 搜索结果保留完整路径，层级浏览只显示当前一级名称。空的加密路径仍可选，受保护路径使用锁图标。横竖屏下列表独立滚动，底部确认按钮保持可达。
- 新增“收藏”视图，每条文档右侧可点星标收藏/取消收藏，操作不会打开文档，也不修改正文、修改时间或块级书签。
- 收藏只保存文档 ID 到本机 `nr:documentFavorites`，跨刷新/重启保留，纳入全量备份恢复；不是独立的实时跨设备同步功能。已删除文档不会出现在收藏列表中。
- 路径、搜索及排序同样适用于收藏视图。存储失败会明确提示，不显示虚假的收藏成功状态。

## 回归验证

第三批（2026-09-09）：列表加载失败可在原位置重试；空结果提供清除筛选、浏览全部及沿当前路径新建；主动打开搜索时自动聚焦，重新打开保留现场时不自动唤起键盘。

第四批（2026-09-09）：顶部搜索从按钮所在左侧展开，顶部和文档列表搜索均在点击事件内同步聚焦，避免延迟回调丢失 iOS 的键盘唤起资格。专注模式右侧按钮与普通模式共用宽度、间距，保留横屏触摸高度及原有标题高度。

第五批（2026-09-09）：

- 新增解释、指南、参考、教程类型筛选，与路径和关键词共同生效。筛选面板收起后仍显示类型条件，可单独清除；空结果的“清除筛选”同时清除路径、关键词和类型。
- 搜索支持空格分隔的多关键词，各词可分别命中不同元数据字段，全部匹配才显示；继续不读取正文。
- 最近打开、全部文档、收藏分别保存会话内滚动位置，切换回来恢复；重复点击当前视图不复位。更改筛选或排序会清空各视图旧位置，防止错位。
- 筛选启用时按钮显示强调色；开启详细信息后额外显示文档类型。
