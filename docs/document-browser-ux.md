# 文档双入口体验优化

## 第一批（2026-09-09）

- 上半部右划：快速找回文档；下半部右划：目录树与批量整理。
- 上半部顶部保留文档/阅读切换、搜索、新建和收回；第二行提供最近打开、全部文档、结果数量及筛选。
- 搜索和筛选按需展开；排序仅用于全部文档，最近打开按真实访问顺序排列。
- 复用 `nr:recentNotes` 的最近 20 项访问记录，仅保存 ID，不修改文档的更新时间。
- 标题最多两行，路径显示末两级；指定路径后隐藏重复部分。标签、修改日期默认隐藏，可在筛选区开启。
- 当前应用会话内保留查询、路径、排序、显示选项及滚动位置，重新打开先展示缓存再刷新。不会跨应用重启保存查询。
- 列表缓存不保存正文；选择条目时重新读取完整文档，避免打开过期内容。搜索只匹配元数据，加密文档解锁后亦不搜索正文。
- 保留底部可继续滚动约三分之一屏的空间，以及两个入口一致的收回行为。

## 第二批（2026-09-09）

- 路径筛选替换为独立选择面板：支持搜索完整路径/目录名、逐级进入、返回上级、回到全部路径；只有确认时才修改筛选，取消或 Escape 不影响原列表。
- 搜索结果保留完整路径，层级浏览只显示当前一级名称。空的加密路径仍可选，受保护路径使用锁图标。横竖屏下列表独立滚动，底部确认按钮保持可达。
- 新增“收藏”视图，每条文档右侧可点星标收藏/取消收藏，操作不会打开文档，也不修改正文、修改时间或块级书签。
- 收藏只保存文档 ID 到本机 `nr:documentFavorites`，跨刷新/重启保留，纳入全量备份恢复；不是独立的实时跨设备同步功能。已删除文档不会出现在收藏列表中。
- 路径、搜索及排序同样适用于收藏视图。存储失败会明确提示，不显示虚假的收藏成功状态。
