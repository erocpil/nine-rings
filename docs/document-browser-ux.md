# 文档双入口体验优化

## 第一批（2026-09-09）

- 上半部右划：快速找回文档；下半部右划：目录树与批量整理。
- 上半部顶部保留文档/阅读切换、搜索、新建和收回；第二行提供最近打开、全部文档、结果数量及筛选。
- 搜索和筛选按需展开；排序仅用于全部文档，最近打开按真实访问顺序排列。
- 复用 `nr:recentNotes` 的最近 20 项访问记录，仅保存 ID，不修改文档的更新时间。
- 标题最多两行，路径显示末两级；指定路径后隐藏重复部分。标签、修改日期默认隐藏，可在筛选区开启。
- 当前应用会话内保留查询、路径、排序、显示选项及滚动位置，重新打开先展示缓存再刷新。不会跨应用重启保存查询。
- 列表缓存不保存正文；选择条目时重新读取完整文档，避免打开过期内容。搜索只匹配元数据，加密文档解锁后亦不搜索正文。
- 保留底部可继续滚动约三分之一屏的空间，以及两个入口一致的收回行为。
