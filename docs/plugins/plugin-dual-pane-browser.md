# 双栏文件浏览插件

## 目标与边界

采用 Total Commander 的两个独立目录列表、活动栏与源/目标概念，结合 Finder 的面包屑、详情列表和多选。作为现有「本地文件」可信内置插件的主区域浏览视图交付，共享授权而不覆盖左侧树的导航状态。不是可安装的第三方脚本插件，不开放任意 React/DOM 或文件系统访问。

## 三批计划

1. **双栏浏览**：独立目录、前后/上级导航、面包屑与根内路径输入、名称/类型排序、多选、隐藏文件、按名称定位、手动刷新及分页；每栏保留位置和选择，双栏比例与活动栏设备本地记忆。打开文本使用现有本地编辑器，图片复用现有图片查看器，返回恢复浏览状态。所有类型均可列出，超大/二进制文本明确拒绝打开。PDF/EPUB 不自动导入阅读库；额外的非导入式二进制查看适配另行接入。手机改为活动栏显示，可切左右栏。
2. **双栏操作**：复制/移动到另一栏、重命名、新建、系统回收站、冲突决策、进度与取消。跨授权根需单独建立服务契约；首批不显示可执行的占位操作。
3. **效率增强**：目录标签页、快速预览/非活动栏预览、目录比较、批量重命名、搜索及按需求引入其它文件提供者。

## 首批宿主能力

- **目录服务**：复用授权根 ID、相对节点、分页和 stat；不受 UTF-8 文本打开的 4 MiB 限制。每次异步结果验证授权代次；页面取消与请求代次阻止迟到结果覆盖新目录。仅对可视项按需读取属性，限制并发和 DOM 数量，不为目录浏览读取正文。
- **主区域贡献**：添加受限 `file-browser` renderer，只接受授权根身份，不接受路径逃逸或外部组件。注册和打开均检查当前激活的 `views.present`、`filesystem.files.read`。宿主仍负责保存门禁、暂停、返回和插件撤销。
- **浏览会话**：两栏与本地文件树独立；在查看器往返中保留浏览组件及状态。根路径、选择、历史、宽度与滚动仅保存在设备本地，不加入共享备份。Web 临时授权丢失时要求重新选择，不伪称已经恢复权限。

## 插件职责

双栏呈现、活动栏、排序/选择、键盘和菜单属于插件。目录授权、读取、文件打开和编辑保存属于宿主。键盘只在浏览视图内处理，Tab 在两个列表间切换；输入框保留原生键盘行为，不注册全局 Vim 按键。第一批通过本地文件树工具栏的“双栏浏览”进入。

## 状态与生命周期

新的主区域请求先 pending，保存成功后才接受；失败保留原视图。浏览器打开文件后保留返回目标，返回也经过同一保存门禁。浏览器停用、授权撤销或切到无关文档后取消读取，不允许迟到响应重新打开视图。历史长度、选中项与目录条目均有预算；空目录、权限失效、路径消失和本地存储不可写必须有可恢复状态。

## 验证

单测覆盖状态规范化、历史分支、范围选择、分页及旧请求拒绝；注册器覆盖权限、不可变数据、保存期间原视图与停用清理。浏览器测试覆盖两栏互不影响、多选、分页、路径输入、隐藏文件、打开/返回保持滚动和选择、刷新恢复、插件关闭及手机布局。保留已有本地文件、主区域、保存失败和插件安装回归。原生授权及大目录磁盘性能单独验收，不以模拟句柄替代。

## 首批交付状态（2026-11-06）

入口：启用插件及「本地文件」，点击文件树工具栏的「双栏浏览」。两栏复用已经授权的目录，也可分别添加根目录；双击或 Enter 打开选中项，查看器的「返回原视图」返回双栏。单击选择，Command/Ctrl 多选、Shift 范围选择，Tab 在两栏间切换。手机使用左栏／右栏切换。

采用每页 200 条、目录总预算 10,000 条的既有目录服务，列表固定行高并虚拟化，仅对可见文件以最多 4 个并发读取属性。每栏历史最多 40 项、选择最多 2,000 项；设备状态上限 512 KiB。取消阻止接受迟到结果和后续读取，不宣称能中断已经发出的原生 IPC。排序和过滤不扫描文件正文。浏览图片不会向背后的数据库文档提供插入操作。

本地完整前端检查、生产构建通过；双栏及既有本地文件定向 Chromium 8 项通过。WebKit 首轮 7 通过、1 项在创建页面阶段进程关闭；该既有用例单独复验通过，双栏 3 项首轮均通过。没有执行完整 E2E 或原生 GUI 验收。第二、三批后续实现见下文。

## 第二批实施契约

双栏以活动栏的选中项为源，另一栏当前目录为目标，执行前显示来源、目标、数量并确认。复制/移动仅在 Tauri 提供跨根接口，分别核验两个授权；Web 暂不假定 File System Access 具有排他创建或可靠跨根移动能力，仍可使用现有目录内操作。目录快照保持只读。新建、重命名和系统回收站复用已有服务能力。

不自动覆盖或合并目录。同名冲突逐项选择跳过、输入其它名称重试，或停止；已完成项不回滚且明确汇总。取消在当前项结束后停止后续项，不宣称能中断正在运行的原生复制。原生复制先在目标目录创建独占临时目录，复制完成后使用不覆盖的原子改名发布，失败清理自己创建的临时内容。拒绝链接、特殊文件、目录递归环；移动只使用排他改名，跨设备失败保留源文件，不偷偷切换为复制后删除。

所有源路径先检查未保存编辑/恢复草稿；复制明确针对磁盘内容。移动和重命名迁移会话、书签、位置、最近打开和 tab 身份，删除清理已打开身份但不永久删除。目录服务与浏览会话独立：操作冻结捕获的源/目标，不随用户切换活动栏改变；视图暂停/停用阻止启动下一项，正在进行的一项可能已经完成，返回后刷新列表。第二批不改变备份格式。

## 第二批交付与限制（2026-11-06）

双栏上方新增操作条，明确标识来源与目标。复制/移动支持批量确认、同名冲突改名或跳过、逐项进度、停止后续项和部分成功汇总；重命名、新建文件/目录、移入系统回收站复用已有服务。操作完成刷新两栏与本地文件树，移动目录同步修正另一栏位于该目录内的历史与路径。没有自动覆盖、目录合并或失败后自动重试。

原生新增 `local_files_transfer`，保留两个授权根、相对节点与单个名称的契约，不允许前端传入任意绝对路径。复制普通文件字节和目录结构，最多 10,000 项、深度 64，不承诺 Finder 的 ACL/扩展属性完整复制。取消为选中项边界；一个目录的内部复制尚无实时字节进度。跨设备移动明确拒绝，用户可先复制、核验后自行决定是否移入回收站。复制中进程崩溃可能留下 `.nine-rings-copy-*` 临时目录，当前不会在启动时猜测删除这些目录。

Web 复制和跨根移动按钮禁用并提示需要桌面版；可写授权目录允许新建和重命名，目录快照保持只读，系统回收站仍仅原生支持。浏览器不是以读入文本再写出来的方式复制二进制文件。

验证：完整前端检查（Vitest 223 文件、2483 项）通过，之后补充的迁移/部分失败断言定向 15 项通过；生产构建、Rust 文件服务 4 项和全目标全特性 Clippy 通过。Chromium/WebKit 双栏及既有文件操作各 7 项通过。未运行完整默认 E2E；跨磁盘错误、真实系统回收站和 Windows/Linux 原生 GUI 仍待现场验证。

## 第三批实施契约

- 目录标签页：每栏最多 16 页，每页独立历史、排序、隐藏项、选择与滚动；使用版本化设备状态恢复，原两栏状态迁移为各一个标签。不增加共享备份字段。移动/删除修正所有标签的历史。
- 快速预览：在另一栏显示选中文件的只读磁盘预览，不替换主区域文件会话；保留原目录，关闭即恢复。文本预读前检查 1 MiB 预算、仅显示前 64 KiB 字符；图片预检 8 MiB，拒绝其它二进制，切换/隐藏/停用丢弃迟到结果。手机以预览暂代当前列表，关闭后返回。
- 目录比较：只读比较两栏当前层级，完整分页收集后按同名匹配，对文件读取大小/修改时间；“元信息一致”不等于正文相同，目录内部不递归比较。结果分页展示，读取失败明确为未知，取消/切走终止后续扫描。
- 批量重命名：`{name}`（不含扩展名）、`{ext}`（含点的扩展名）、`{n}`（起始编号）模板，按选中顺序预览。拒绝重复目标和选中项间交换/占用，跳过未变化项，执行复用第二批脏草稿检查、冲突决策和路径迁移；不做自动循环改名或覆盖。
- 正文搜索：复用既有 Worker 搜索与预算，默认活动目录，可取消，结果打开时携带匹配位置及修订；不另写解析器。没有明确来源需求时不添加其它文件提供者。

## 第三批交付（2026-11-06）

上述五项已接入双栏浏览。每栏顶部的 `＋` 创建当前目录的新标签，关闭按钮只关闭标签，至少保留一个；切换或重新进入恢复各自位置。快速预览保留另一栏原目录，关闭预览即可恢复；手机预览暂时代替列表。比较目录、搜索正文使用居中工具弹层，比较结果每页 200 项，并支持过滤及从左/右侧打开。批量重命名的模板和编号输入先生成最多 100 行的预览，确认后冻结计划并执行，未变化项不写磁盘。

目录标签状态使用同一设备键的版本 2 格式，迁移旧两栏状态，不写入共享备份。标签页切换依赖稳定 ID 重新建立可视列表并按保存位置加载分页，不能将两个相同路径标签的滚动位置混在一起。移动/删除作用于所有标签；删除历史条目后保留当前条目的索引，避免误跳到前进分支。原生接口及第二批排他写入规则未改变。
