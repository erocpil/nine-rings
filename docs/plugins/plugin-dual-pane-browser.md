# 双栏文件浏览插件

## 目标与边界

采用 Total Commander 的两个独立目录列表、活动栏与源/目标概念，结合 Finder 的面包屑、详情列表和多选。作为现有「本地文件」可信内置插件的主区域浏览视图交付，共享授权而不覆盖左侧树的导航状态。不是可安装的第三方脚本插件，不开放任意 React/DOM 或文件系统访问。

## 三批计划

1. **双栏浏览**：独立目录、前后/上级导航、面包屑与根内路径输入、名称/类型排序、多选、隐藏文件、按名称定位、手动刷新及分页；每栏保留位置和选择，双栏比例与活动栏设备本地记忆。打开文本使用现有本地编辑器，图片复用现有图片查看器，返回恢复浏览状态。所有类型均可列出，超大/二进制文本明确拒绝打开。PDF/EPUB 不自动导入阅读库；额外的非导入式二进制查看适配另行接入。手机改为活动栏显示，可切左右栏。
2. **双栏操作**：复制/移动到另一栏、重命名、新建、系统回收站、冲突决策、进度与取消。跨授权根需单独建立服务契约；首批不显示可执行的占位操作。
3. **效率增强**：目录标签页、快速预览/非活动栏预览、目录比较、批量重命名、搜索及按需求引入其它文件提供者。

## 首批宿主能力

- **目录服务**：复用授权根 ID、相对节点、分页和 stat；不受 UTF-8 文本打开的 4 MiB 限制。每次异步结果验证授权代次；页面取消与请求代次阻止迟到结果覆盖新目录。仅对可视项按需读取属性，限制并发和 DOM 数量，不为目录浏览读取正文。
- **主区域贡献**：添加受限 `file-browser` renderer，只接受授权根身份，不接受路径逃逸或外部组件。注册和打开均检查当前激活的 `views.present`、`filesystem.files.read`。宿主仍负责保存门禁、暂停、返回和插件撤销。
- **浏览会话**：两栏与本地文件树独立；在查看器往返中保留浏览组件及状态。根路径、选择、历史、宽度与滚动仅保存在设备本地，不加入共享备份。Web 临时授权丢失时要求重新选择，不伪称已经恢复权限。

## 插件职责

双栏呈现、活动栏、排序/选择、键盘和菜单属于插件。目录授权、读取、文件打开和编辑保存属于宿主。键盘只在浏览视图内处理，Tab 在两个列表间切换；输入框保留原生键盘行为，不注册全局 Vim 按键。第一批通过本地文件树工具栏的“双栏浏览”进入。

## 状态与生命周期

新的主区域请求先 pending，保存成功后才接受；失败保留原视图。浏览器打开文件后保留返回目标，返回也经过同一保存门禁。浏览器停用、授权撤销或切到无关文档后取消读取，不允许迟到响应重新打开视图。历史长度、选中项与目录条目均有预算；空目录、权限失效、路径消失和本地存储不可写必须有可恢复状态。

## 验证

单测覆盖状态规范化、历史分支、范围选择、分页及旧请求拒绝；注册器覆盖权限、不可变数据、保存期间原视图与停用清理。浏览器测试覆盖两栏互不影响、多选、分页、路径输入、隐藏文件、打开/返回保持滚动和选择、刷新恢复、插件关闭及手机布局。保留已有本地文件、主区域、保存失败和插件安装回归。原生授权及大目录磁盘性能单独验收，不以模拟句柄替代。

## 首批交付状态（2026-11-06）

入口：启用插件及「本地文件」，点击文件树工具栏的「双栏浏览」。两栏复用已经授权的目录，也可分别添加根目录；双击或 Enter 打开选中项，查看器的「返回原视图」返回双栏。单击选择，Command/Ctrl 多选、Shift 范围选择，Tab 在两栏间切换。手机使用左栏／右栏切换。

采用每页 200 条、目录总预算 10,000 条的既有目录服务，列表固定行高并虚拟化，仅对可见文件以最多 4 个并发读取属性。每栏历史最多 40 项、选择最多 2,000 项；设备状态上限 512 KiB。取消阻止接受迟到结果和后续读取，不宣称能中断已经发出的原生 IPC。排序和过滤不扫描文件正文。浏览图片不会向背后的数据库文档提供插入操作。

本地完整前端检查、生产构建通过；双栏及既有本地文件定向 Chromium 8 项通过。WebKit 首轮 7 通过、1 项在创建页面阶段进程关闭；该既有用例单独复验通过，双栏 3 项首轮均通过。没有执行完整 E2E 或原生 GUI 验收。第二、三批尚未实现。

## 影响分析

- **SAFE（已验证范围）**：`src/lib/plugin-system/main-view-registry.ts:246` 的 `accept` 与 `close` 保留单层浏览返回目标；审查了 App 的工作区导航、图片关闭/插入、本地文件关闭及激活清理调用方。显式查看器返回重新经过 pending 保存门禁，无参数关闭清除整段会话，旧请求不能恢复已停用视图。注册器单测及双浏览器交互验证上述路径。
- **SAFE（已验证范围）**：`src/App.tsx:235` 的主视图保存门禁先调用 `checkpointLocalFile`，避免文件编辑器卸载前遗漏恢复草稿；`src/lib/local-files/browser-provider.ts:16` 在异步前后校验权限和取消信号，目录列表不读取正文。沿用原来的根授权、stat/list IPC 与序列化契约，未修改 Rust 命令及持久文档格式。
- **SAFE（已验证范围）**：`src/lib/local-files/browser-state.ts:21` 使用独立设备键，检查了共享备份的显式设置白名单，未将根授权与浏览历史加入同步。
- **UNCERTAIN（现场边界）**：真实磁盘数万项枚举耗时、原生目录授权重启续期及系统文件选择器需三平台现场验证；模拟目录与定向 E2E 不足以证明这些行为。WebKit 启动中断也保留观察，不能仅凭复跑通过认定环境问题已消除。
