## 第一批交付与边界

- PDF：共享快速预览及独立工作台全视图支持分页、页码、适宽／75%～200%缩放和文本选择；逐页渲染，显示倍率与画布像素密度分离，按屏幕DPR（最高2.5倍）绘制且画布最多1200万像素。使用独立 Worker 与本地 CMap，直接传入二进制数据以兼容 tauri 自定义协议，不将文件导入 Nine Rings PDF 库。
- PDF读取：授权根内按段读取，读取前后核验大小／修改时间，取消及撤权后丢弃迟到结果；浏览器与原生端均限制32 MiB。超过预算时显示文件信息并建议系统应用；图片不受此新预算影响。
- Markdown：快速预览和独立全视图默认渲染；上方单图标按钮切换渲染／源码，图标和悬停提示表示目标模式；一次预览内按源码字符与渲染内容边界映射位置，切换时跟随同一段内容，不再只恢复两种模式各自的旧像素位置。快速预览查找切到原文；内置编辑器解除只读后可直接编辑渲染正文，并可切换源码；切换不改写原文，原保存／草稿／未保存离开保护继续生效。带搜索定位打开时仍直接进入源码。
- 独立预览禁用数据库 nr-image 图片解析；本地相对链接暂不直接跳转，以免绕过保存确认。相对图片暂保留替代文本，不擅自扩大目录授权；远程资源仍受宿主 CSP 限制。
- 密码 PDF 暂提示使用系统应用；PDF全文查找、目录、相对图片／链接的授权解析、页位置记忆属于后续可选扩展，本批未声称已支持。

验证记录见[共享工作台决策](../decisions/003-shared-file-workbench.md)与[验证进度](../validation/e2e-repair-progress.md)。

## Markdown 渲染编辑实施约束

先复用 Nine Rings 已有渲染编辑器，检查并拆出必要的编辑器宿主接口，不能为复用引入独立工作台不需要的数据库、同步或应用单例。

- 源码保真：仅打开、预览或切换模式不得重排、转义或改写原始 Markdown；明确渲染编辑对复杂语法的支持范围及不支持时的源码入口。
- 单一正文权威：渲染与源码为同一编辑会话的两种视图，不建立互相覆盖的可写副本。明确切换交接与版本核验，避免晚到解析覆盖更新。
- 编辑连续性：保留位置、选区、撤销历史、脏状态及恢复草稿；不能因切换视图清空撤销或误判为已保存。
- 磁盘安全：沿用原文件修订核验、外部修改检测、保存及离开确认；只读／无写权限文件继续只读，导出副本不等于保存原文件。
- 分批实施：先基础正文与块编辑，再按实测结果扩展特殊块；回归覆盖编辑后往返切换、撤销重做、外部冲突、保存失败、取消离开及异常恢复。


## 独立编辑器窗口：同一应用、两个工作区

目标不是再发布一个编辑器 App，而是在同一 File Workbench 应用内提供可独立移动、缩放、最小化的文件浏览窗口与编辑器窗口。浏览其他文件不必关闭当前编辑器或重新加载其会话。各 WebView 的状态不天然共享，应通过受信任的宿主接口协调，不能假定两个窗口能直接访问彼此的 React 状态。

### 第一阶段：一个浏览窗口＋一个多标签编辑器窗口

- [ ] 使用内置编辑器打开文件时，复用编辑器窗口并新增／激活标签，保留浏览窗口的双栏路径、标签、选择与滚动。
- [ ] 同一文件默认定位已有编辑会话；以授权根与文件身份识别，不只按文件名去重，不建立两个互相覆盖的可写副本。
- [ ] 编辑标签保留未保存正文、位置、选区、撤销历史和折叠状态；窗口间切换不触发保存或丢弃确认，不卸载有效编辑会话。
- [ ] 提供“在文件浏览中显示”与重新唤起编辑器入口；程序启动参数／Finder打开入口之后复用相同路由。
- [ ] 区分关闭标签、关闭编辑器窗口、关闭浏览窗口及退出整个应用；关闭浏览窗口不关闭编辑器，编辑器关闭仍有保存／草稿保护，应用退出核验全部窗口及运行任务。明确最后一个窗口关闭后的托盘行为与召回目标。
- [ ] 扩展目前只允许main的IPC与事件路由：由后端注册可信编辑器窗口身份，逐命令配置权限与目标，不简单删除main校验或使用任意窗口通配授权。授权撤销、文件移动／改名、外部修改和操作队列状态广播到相关会话。
- [ ] 共享文件读取／保存、授权、修订核验、操作队列与草稿服务；窗口只持有自己的界面状态，保存按当前文件身份及修订协调。第二窗口启动／加载失败时浏览窗口继续可用。
- [ ] 验证同时浏览与编辑、跨窗口重复打开、只读／无权限、保存失败、外部变更、关闭与取消、托盘召回、退出时多窗口确认，防止迟到事件覆盖新会话。

### 后续扩展：多编辑器窗口与可选侧面板

- [ ] 增加“在新编辑器窗口打开”；先保持同一文件默认单可写会话，多窗口编辑同一文件另行设计同步与冲突协议。
- [ ] 预留编辑器侧面板插槽、宽度／显隐／固定偏好、当前文档身份、定位与选择通知接口；不把面板实现绑定到浏览窗口或数据库文档ID。
- [ ] Markdown按适用类型接目录、书签及渲染／源码切换；C/C++等源码接符号大纲、书签、同词匹配与跳转；普通文本保留查找、书签和行号导航。
- [ ] 优先复用Nine Rings现有目录、符号、书签、同词组件及展示插件端口；按文件类型自动提供适用功能，隐藏、固定和拖宽行为统一。面板缓存属于当前文件会话，切换文件不能使用过期偏移跳转。

## Markdown 渲染能力分批与历史缺口

历史基线（237df662，现已补齐）：WorkbenchSourceView的锁只控制源码编辑权限；渲染分支一直装配FileBrowserPreviewMarkdown／MarkdownSplitPreview只读投影，没有传入编辑回写能力。因此当时解除只读后返回渲染仍不能修改正文；本批已经补齐该能力。之前的“编辑预览”仅表示渲染当前源码的未保存修改，不表示可在渲染结果直接输入。

### 第一批：正文渲染编辑

- [x] 将文档权威／渲染编辑与文件存储宿主分开，复用现有Nine Rings渲染编辑能力；不直接把依赖数据库或应用单例的整个编辑页面装入工作台。
- [x] 源码、渲染共用一个文件编辑会话；渲染修改能产生脏状态、撤销／重做、草稿和保存结果，保存时仍执行磁盘修订核验。
- [x] 已解除只读时渲染正文可编辑；只读、无写权限或草稿保护失败时明确保持只读。快速预览继续只读，不把它升级为另一个可写会话。
- [x] 不通过浏览／切换模式改写原文。先验证支持范围与序列化差异；无法无损处理的语法明确回到源码编辑，不能静默丢失扩展内容。
- [x] 回归源码／渲染往返定位、编辑与撤销连续性、标题／列表／引用／表格／待办、未保存预览、保存失败与外部冲突，区分“只读预览”与“渲染编辑”。

### 第二批：块号、块菜单与块模式

- [x] 渲染编辑器接入块号、当前块与折叠，以及对应的显示设置；尽量复用编号展示插件和既有块级交互，不另造编号／折叠算法。
- [x] 接块菜单、复制／剪切／移动／删除、多块选择等适用操作；文件来源不适用的数据库操作不显示。只读时只开放允许的查看与复制。
- [x] 接代码／引用／Mermaid／flow等块的放大块模式及编辑回写，继续使用同一正文、撤销和保存边界；不产生独立未协调的正文副本。
- [x] 验证块号与正文定位、折叠恢复、块模式关闭／Esc优先级、源码切换与特殊块；复制粘贴继续走已有公共动作与单元测试。本批复用同一工作区交付；不需要等待独立窗口，双栏快速预览仍只读。

两个工作流可分别推进，但独立窗口与渲染编辑都必须以同一文件会话／宿主边界为基础；实施前在共享工作台决策中确认具体接口与验收范围。


本批实现边界：首次访问某模式才加载，访问后保留其编辑实例；仅活动视图可写。两个文本引擎仍有各自原生撤销栈，保留历史不等于建立单一跨模式撤销协议。源码变化在进入渲染时投影，保留原始字符串直到实际正文编辑；仅显示属性变化不改写Markdown。独立窗口、持久侧面板及相对资源授权扩展继续属于后续任务。


后续专项：超大Markdown的渲染性能和完整原生剪贴板／实机操作验收。独立工作台尚无原生PDF打印宿主，隐藏PDF导出入口，Markdown导出改走现有文件宿主，避免调用Nine Rings专用命令。
