# File Workbench 后续产品优化待办

更新：2026-11-13

按收益及依赖顺序推进，双栏插件与独立产品共用核心和预览组件：

- [x] 第一批：扩展预览，先接 PDF 的分页／缩放和 Markdown 渲染／原文切换；保持只读、授权范围及关闭资源释放，不引入 Nine Rings 数据库。
- [ ] 第二批：完善文件操作进度，显示当前文件、已处理数量／字节、速度及取消状态；未知写入结果继续要求人工核对。
- [ ] 第三批：整理并开放快捷键设置，集中展示浏览、预览与文件操作命令及冲突提示。
- [ ] 按需统计目录大小：手动触发、可取消、缓存结果，进入目录不自动递归扫描。
- [ ] 列表展示设置：字号、行高、显示列及日期格式，保留用户列宽与排序。
- [ ] 完善重名冲突界面：并排展示大小／修改时间，提供保留双方及适用的批量决策。
- [ ] 独立交付：Windows／Linux 构建、安装及更新通道，与 Nine Rings 产物和数据隔离。
- [ ] 草稿路径保护细化：从存在任意草稿即保守阻止，逐步改为只阻止相关路径；先解决持久身份、移动改名与草稿迁移。

扩展预览约束：PDF 复用 PDF.js 与既有 CMap 静态资产，不直接装配依赖数据库的 PdfReader；Markdown 复用已有解析及只读块渲染，保留原文查看。快速预览预算、取消和不支持时的文件详情回退仍有效，图片不新增大小限制。

## 第一批交付与边界

- PDF：共享快速预览及独立工作台全视图支持分页、页码、适宽／75%～200%缩放和文本选择；逐页渲染，显示倍率与画布像素密度分离，按屏幕DPR（最高2.5倍）绘制且画布最多1200万像素。使用独立 Worker 与本地 CMap，直接传入二进制数据以兼容 tauri 自定义协议，不将文件导入 Nine Rings PDF 库。
- PDF读取：授权根内按段读取，读取前后核验大小／修改时间，取消及撤权后丢弃迟到结果；浏览器与原生端均限制32 MiB。超过预算时显示文件信息并建议系统应用；图片不受此新预算影响。
- Markdown：快速预览和独立全视图默认渲染；上方单图标按钮切换渲染／源码，图标和悬停提示表示目标模式；一次预览内按源码字符与渲染内容边界映射位置，切换时跟随同一段内容，不再只恢复两种模式各自的旧像素位置。查找切到原文，允许编辑后进入原有源码编辑器；切换不改写原文，原保存／草稿／未保存离开保护继续生效。带搜索定位打开时仍直接进入源码。
- 独立预览禁用数据库 nr-image 图片解析；本地相对链接暂不直接跳转，以免绕过保存确认。相对图片暂保留替代文本，不擅自扩大目录授权；远程资源仍受宿主 CSP 限制。
- 密码 PDF 暂提示使用系统应用；PDF全文查找、目录、相对图片／链接的授权解析、页位置记忆属于后续可选扩展，本批未声称已支持。
