# 状态栏展示插件

内置开关位于「设置 → 编辑器 → 专注模式状态栏」，默认显示，且仍受「编辑器状态栏」总开关控制。偏好随已有前端显示设置备份。

设置 → 高级 → 启用插件功能，在插件列表启用「状态栏展示」，点击名称配置。渲染、Markdown 源码和局部只读共用同一个宿主组件；新建导航、保存、统计或诊断系统不属于插件职责。

## 配置与回退

- 显示状态栏、是否在专注模式显示；默认显示，且默认在专注模式显示。
- 字体、9～20px 字号、粗体、斜体、0～12px 上下留白、2～24px 信息项间距。
- 文字和背景的语义色，或独立浅深 `#rrggbb` 颜色对。不接受 CSS、HTML、URL、网络字体或脚本。
- 信息项显示与顺序：位置历史导航、本机保存、块号、阅读/光标位置、字符数、词数、调试日志和版本历史。各视图只展示自己能提供的数据；源码不虚构词数或块号，局部只读不假装提供完整编辑器的光标统计。

启用后禁用对应内置「编辑器状态栏」「专注模式状态栏」「状态栏块号」设置，原值保留；停用、卸载或关闭总开关恢复。历史和日志仍由宿主实现，插件不能替换按钮行为。保存失败不受单独隐藏保存项影响，错误不只靠颜色表达。

导航项通常位于状态栏右侧、日志左边；展示插件仍可显式配置不同的信息项顺序。关闭状态栏、专注模式隐藏状态栏或插件去掉导航项时，箭头回到标题区原入口，避免因为展示选择失去导航能力。源码并排预览的状态栏在分栏容器之外，保持与上方标题/工具栏同宽。

## 声明式贡献

`contributes.statusBar` 是单个配置对象，以下字段全部必填。每次激活只能由一个提供者接管；冲突明确失败，先停用旧插件再启用新插件。资源与插件代次一同撤销，不授予正文、文件或网络权限。

| 字段 | 取值 |
| --- | --- |
| `visible`, `showInFocus`, `bold`, `italic` | 布尔值 |
| `font` | `inherit`、`mono`、`sans`、`serif` |
| `fontSize` | 9～20 |
| `paddingY` | 0～12 |
| `gap` | 2～24 |
| `color`, `background` | `text`、`secondary`、`accent`、`transparent`、`surface`、`active`，或 `{light,dark}` 六位十六进制配色 |
| `items` | 无重复的数组，成员只能是 `navigation`、`save`、`block`、`position`、`characters`、`words`、`diagnostics`、`history` |

[acme.status 示例](../schema/plugin/examples/acme.status/manifest.json)可用现有打包器生成本机安装包：

```sh
node --import tsx scripts/pack-plugin.ts schema/plugin/examples/acme.status /tmp/acme.status.nrplugin.zip
```

原生插件结果通知仍复用原有结果展示配置；本贡献只定制宿主状态栏，不向插件暴露任意自定义控件或命令执行槽。

## 配置页布局

状态栏配置按“显示与排版”和“配色与信息项”分组；文档树、目录、书签与随记展示按“文字与行距”和“信息与工具”分组。它们和编号展示共用响应式配置网格：视口宽度至少 760px 时采用两栏并适度加宽弹层，窄屏使用单栏。说明、运行权限和恢复默认按钮不拆入多列，内容超高仍在弹层内滚动；配置顺序与保存方式不变。
