- `markdown-import.md` 描述应用导入、来源和内容契约；`md-import.md` 是 CLI 使用手册。名称近似但职责不同，应互链而非合并。
- `current-design.md` 是系统入口，`features.md` 是产品能力清单；插件总体、准备门禁、分栏展示和发布计划分别承担设计、实施、贡献点和交付职责。保持专题文档，当前未完成任务以 `plugin-readiness-todo.md` 为入口。
- E2E 的基线、失败清单、修复进度和日期审计属于证据快照。不可将历史失败或跳过直接当作当前缺陷，也不可丢弃快照后宣称全量通过。
- 内容相同的 Flutter 构建配置、图标尺寸变体和 Tauri 平台 schema 具有平台约定路径；保留。生成物修改应经过生成器及一致性检查，不能凭哈希相同删除。
- Markdown 链接扫描中的 `url` 是语法示例占位符；全景 demo 的 `guide.md`/`overview.md` 是相对链接示例，不能作为真实文件缺失直接删除。普通相对文档链接未发现缺失目标；此检查未验证片段锚点或外部网址。
- `pdf-print.ts` 是 HTML 入口，两个 worker 由 URL 装载；`idb-driver.test.ts` 和 `ops-validation.ts` 是独立测试/验证入口，不因没有静态导入而删除。
