# 独立词库与文章关联接口

## 数据分层

词汇插件同时支持普通 Markdown 文档和独立词库。旧文档不自动转换、删除或隐藏。独立词库不是普通文档，不产生文档历史、搜索派生正文或每词一份备份文件。

1. **词库资料**：导入的只读来源资料，按词条 ID 更新。当前正文保留 Markdown，因此沿用 GFM 学习结构及选择、复制、例句/译文折叠。
2. **个人数据**：阅读位置及折叠继续为本机状态；未来笔记、复习记录和文章关联是独立实体，不写入词库包。
3. **展示投影**：索引 → 虚拟分组/单词树；按需正文 → 学习视图。导航与数据持久化不依赖 React 节点、标题或数组位置。

Web/PWA 和 Tauri 使用独立 IndexedDB `nine-rings-vocabulary`，保存于当前应用/Web origin，不使用临时目录。Tauri 当前未改为 SQLite，此资源库不进入现有文档数据库。Flutter 尚未接入插件学习视图。

## 身份与接口

`VocabularyResourceRef` 为互斥联合：

- `{ kind: "document", documentId }`
- `{ kind: "corpus", corpusId, entryId }`

`VocabularyResourceService.list()` 只给摘要，`read(key)` 按需提供正文和明确的资源身份。现有 `vocabularyDocuments` 是兼容别名；视图 `documentId` 暂保留旧名称，但实际为导航键，独立词条使用 `vocab:<corpusId>:<entryId>`。它不能传给文档删除、编辑等接口。独立词条不展示“普通文档”入口。

改名、调整分组不能改变词条 ID；库 ID 和词条 ID 与 revision 分离。目录 `词库-<id>` 是展示分组，不是文档路径，不继承该路径的加密。词库内容当前不加密；导入界面明确说明此边界。

## 文件格式

输入接受 UTF-8 JSON 或 gzip 压缩 JSON；按文件头判断压缩，不依赖扩展名。建议 `.nrvocab.json.gz`。

```json
{
  "format": "nine-rings-vocabulary",
  "version": 1,
  "id": "awl",
  "revision": 1,
  "name": "AWL 学术词汇",
  "entries": [
    {
      "id": "sample",
      "word": "sample",
      "group": "unit1",
      "source": "# sample\n\n## 剑桥词典\n...",
      "addedAt": "2026-10-16T00:00:00Z"
    }
  ]
}
```

库 ID 最多 40 个 ASCII 字母/数字/下划线/连字符；词条 ID 最多 64 个。同库不允许重复 ID，允许不同身份同名词。正文每词最多 250000 UTF-16 单元，包最多 50000 词、解压最多 64 MiB。校验未知字段、版本、分组路径、日期和大小；解压过程中计数，超过上限终止。

包版本较旧，或同一 revision 但内容不同，拒绝覆盖。相同 revision、相同内容可重复导入。按稳定字段顺序与 ASCII ID 顺序计算 SHA-256，不依赖 JSON 输入字段顺序或系统排序语言。

## 生成与使用

```sh
python3 scripts/pack-vocabulary.py vocabulary/awl \
  .local-tools/vocabulary/awl.nrvocab.json.gz \
  --id awl --name 'AWL 学术词汇' --revision 1
```

脚本不联网、不修改输入。第一次按词头的规范化拼写生成 ID，目录/文件改名不影响 ID；词头本身更名需要在包中显式保留原 ID。同名词头必须先合并资料或手动给出不同 ID。更新同一输出文件时必须提高 revision，并保留原添加时间。

在“设置 → 高级 → 词汇学习配置 → 独立词库”导入；左侧仍使用现有单词树。配置页可以导出完整 JSON 包，桌面使用原生保存对话框，Web 下载文件。导出不改变本机资料。

## 存储、缓存与更新

- 仅摘要进入索引，不为每个词构建普通文档/全文搜索记录。
- 按词条 ID 的 SHA-256 第一个十六进制字符划分至最多 16 个稳定桶。桶正文压缩保存，兼容无压缩流环境。
- 所有新分片与索引在一个事务中发布；校验/压缩失败不动原库，事务失败不留下半更新。
- 读取核对索引与分片摘要，再核对解压内容摘要；导出还核对整个包摘要。
- 解压缓存最多四片，超过一百万字符的单片不缓存，避免无限保留大正文。
- 更新包不改变词条身份；变化正文沿用指纹机制重置失效的阅读布局。当前词库视图在包更新后关闭，避免继续展示旧正文。其它窗口通过存储通知重新读索引。
- 本阶段不提供删除原词汇文档的自动迁移，也不删除已有个人阅读记录。

## 同步边界

当前文档 JSON/GitHub 备份**不包含独立词库**。导入时明确提示保留原始包或专门导出。浏览器清除站点数据会清除本机库；跨端目前显式导入同一包。不能把成功的文档备份当成词库备份。

分片及索引已经提供稳定摘要，但尚未把它们写入未上线的增量协议。后续应注册独立资源类型、认证格式和能力，上传有变化的不可变分片，最后原子发布索引；不能每次上传整个 SQLite 文件，也不能绕过现有恢复/发布屏障。

原始资料可重复安装；个人数据必须单独同步并处理多端冲突。现行普通备份本身为整包快照，“一词一文档”并不等于当前已有逐词网络请求；本次收益主要是减少编辑器模型、搜索数据和历史的冗余，并为后续同步定义正确边界。

## 文章关联预留

`VocabularyArticleLink` 包含独立关联 ID、词条 resource、文章 documentId、可选 anchorId、原表达 expression、摘录 quote、可选词典来源/词义 ID 和创建时间。

`VocabularyArticleLinkService` 预留按词条/文章双向查询、写入和删除。后续实现须验证文章访问权限、保留被删文章的失效引用提示，并让一个词对应多篇文章、一篇文章对应多个词。词库升级不能改写关联或个人笔记；显示分组、内容散列、释义在列表中的位置均不能代替持久身份。

目前只定义接口，未实现文章关联界面、关系持久化、个人练习或复习调度。
