# 窗口全屏与阅读全屏

标题栏按钮和系统快捷键控制原生窗口全屏。PDF/EPUB 与右侧文档同时打开时，
进入和退出窗口全屏均保持两栏的宽度比例，不切换阅读模式。
阅读分栏保存 `nr:readerSidebarRatio`，兼容旧的 `nr:readerSidebarW` 像素偏好；
窗口动画中的临时尺寸、最小宽度限制不会覆盖用户选择的比例。

PDF 的“全屏阅读”和 EPUB 的“专注模式”只铺满应用工作区，隐藏右侧文档和
分栏工具，保留 Tauri 标题栏。退出时显示同一个文档实例并恢复分栏比例。
Web、macOS、Windows 和移动端均不通过阅读器调用原生或浏览器全屏 API。

## macOS 最大化恢复

无边框窗口进入原生全屏时，Tao 临时添加系统标题栏样式。退出时，其异步
样式恢复与 zoom 处理可能留下标题栏空白，并覆盖普通窗口的还原边界。

`macos_window.rs` 分别保存双击放大前的边界、进入全屏前的边界及样式。
双击在当前显示器的可用区域与普通窗口边界间切换；原生全屏仍走 Tauri。
收到 `NSWindowDidExitFullScreenNotification` 后，经过主队列屏障等待 Tao 的
样式恢复，再恢复窗口的完整边界和内容视图响应者。未完成退出时忽略双击，
避免把 Space 动画的中间尺寸当作普通窗口尺寸。

回归覆盖：窗口几何状态的 Rust 测试，Web/模拟 macOS/模拟 Windows 的
PDF/EPUB 分栏比例与阅读全屏测试，标题栏双击及全屏往返测试。
浏览器模拟不能替代 AppKit 实机验证；macOS 验收应重复“双击放大 → 全屏 →
退出 → 双击还原”，同时检查顶部无空白、多显示器位置、原始尺寸和键盘输入。
