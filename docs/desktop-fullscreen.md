# 窗口全屏与阅读全屏

标题栏按钮和系统快捷键控制原生窗口全屏。PDF/EPUB 与右侧文档同时打开时，
进入和退出窗口全屏均保持两栏的宽度比例，不切换阅读模式。
阅读分栏保存 `nr:readerSidebarRatio`，兼容旧的 `nr:readerSidebarW` 像素偏好；
窗口动画中的临时尺寸、最小宽度限制不会覆盖用户选择的比例。

PDF 的“全屏阅读”和 EPUB 的“专注模式”只铺满应用工作区，隐藏右侧文档和
分栏工具，保留 Tauri 标题栏。退出时显示同一个文档实例并恢复分栏比例。
Web、macOS、Windows 和移动端均不通过阅读器调用原生或浏览器全屏 API。

## macOS 最大化恢复

无边框窗口进入原生全屏时，Tao 临时添加系统标题栏样式。退出时，其异步
样式恢复与 zoom 处理可能留下标题栏空白，并覆盖普通窗口的还原边界。

`macos_window.rs` 分别保存双击放大前的边界、进入全屏前的边界及样式。
双击在当前显示器的可用区域与普通窗口边界间切换；原生全屏仍走 Tauri。
收到 `NSWindowDidExitFullScreenNotification` 后，经过主队列屏障等待 Tao 的
样式恢复，再恢复窗口的完整边界和内容视图响应者。未完成退出时忽略双击，
避免把 Space 动画的中间尺寸当作普通窗口尺寸。

回归覆盖：窗口几何状态的 Rust 测试，Web/模拟 macOS/模拟 Windows 的
PDF/EPUB 分栏比例与阅读全屏测试，标题栏双击及全屏往返测试。
浏览器模拟不能替代 AppKit 实机验证；macOS 验收应重复“双击放大 → 全屏 →
退出 → 双击还原”，同时检查顶部无空白、多显示器位置、原始尺寸和键盘输入。

## 普通窗口尺寸持久化

桌面主窗口的普通宽高保存在应用数据目录的 `window-geometry.json`，使用逻辑像素，
与文档、主题配置分开。启动时按当前显示器工作区裁剪并居中恢复；没有有效记录时
继续使用 Tauri 配置的 1020×640 默认尺寸。调整普通窗口时及时保存，关闭窗口
转入托盘前也保存最终尺寸。最大化、原生全屏及临时纵向扩展期间不写入，避免
把临时展示尺寸误当作下一次启动的普通尺寸。窗口双击放大/还原仍使用原来的平台
实现，macOS zoom 的普通窗口还原边界仍由 `WindowPlacement` 在进程内管理。

## 托盘召回与显隐

托盘左键按下时分别查询可见、最小化及焦点状态，只有确认窗口可见、未最小化且已获焦点时隐藏；后台窗口、最小化或隐藏窗口复用显示主窗口路径，显示、取消最小化并聚焦。状态查询失败时优先召回，避免误隐藏。Option+Y（macOS）/Alt+Y（Windows、Linux）使用同样的判断；启动日志记录本次状态与 hide/recall 决策，便于原生平台验收。

## Escape 与窗口全屏

应用不使用 Escape 退出窗口全屏；使用标题栏全屏按钮或原有全屏快捷键退出。设置页及其查找/重命名输入取消默认行为，先关闭当前层级。主窗口在应用菜单处理 Escape 后取消 WebView 默认行为，不阻止事件传播、不提前设置 defaultPrevented，也不抢占输入法取消键。后打开的插件结果和菜单仍可优先处理 Escape。

Web 页面会对可取消的默认行为采用同样策略，但浏览器保留的强制退出全屏键可能不会交给 DOM，不能保证由网页禁用。PDF/EPUB 的内部阅读模式独立于窗口全屏，不修改其现有退出约定。
