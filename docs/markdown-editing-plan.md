# Markdown 编辑优化建议

状态：第一阶段已实现；并排预览与 Live Preview 留待后续。

## 当前基础

源码界面使用独立 CodeMirror 6 实例；通过 SourceNavigationSession 保留源码版本、解析结果和导航映射，已有自动保存、目录/书签、视图切换位置恢复和底部滚动留白。代码块工作区已使用 CodeMirror。富文本持久化为 Delta，源码还保存在 metadata.markdownSource；二者的切换与失效规则必须明确，不能让两个版本互相覆盖。

## 参考

- [VS Code Markdown](https://code.visualstudio.com/docs/languages/markdown)：源码与预览并排、实时更新及可关闭的滚动同步。
- [VS Code 基础编辑](https://code.visualstudio.com/docs/editing/codebasics)：查找替换、匹配符号补全和语法折叠。
- [Obsidian 视图与编辑模式](https://obsidian.md/help/edit-and-read)：区分阅读、源码编辑和 Live Preview。
- [CodeMirror 基础配置](https://codemirror.net/examples/basic/)：可组合的编辑器能力，适合沿用项目已有依赖。

以下优先级是针对 Nine Rings 的建议，不代表上述产品全部采用相同架构。

## 第一阶段：可靠的源码编辑

1. 审计并固化内容契约：源码会话以内存中的 Markdown 文本为当前编辑依据，解析结果为派生投影，通过现有保存入口写回。仅切换视图不得改写空行、列表标记、围栏和转义；富文本实际编辑后应明确使旧源码缓存失效。格式无损范围需要用测试定义，不承诺任意富文本都能映射到 Markdown。
2. 用独立 CodeMirror Markdown 实例替换 textarea，保留现有自动保存、敏感文档规则、目录/书签与位置历史。不要直接复用代码块工作区的写回逻辑，两者目标模型不同。
3. 提供 Markdown/围栏内代码高亮、可选行号、当前行提示、软换行、行列状态、查找替换及跳转行。字体、Tab 长度、主题从已有设置读取。
4. 支持列表/引用自动续写、空项回车退出、Tab/Shift+Tab 缩进、选中文本包裹为粗体/链接/行内代码。智能补全不得在中文输入法组合期间触发；代码围栏内保持代码自身的 Enter/Tab 规则。
5. 源码会话保持独立、稳定的撤销历史；自动保存和目录刷新不重建整个编辑器状态。切换模式后的撤销边界单独设计，不能承诺两个不同编辑器的历史自动互通。

## 第二阶段：导航和预览

- 从渲染块定位到源码范围，反向定位到对应正文块；尽量保留选区和视口内偏移，减少整页跳动。
- 加入标题、代码围栏和列表折叠；目录与书签沿用现有入口。
- 桌面可选并排预览，默认保留当前单区切换；手机优先单区切换。滚动同步提供开关，仅响应用户正在操作的一侧，避免两侧相互拉动。
- 预览合并连续输入更新；不因缩放、拖动或光标移动重新绘制 Mermaid。保留上一次成功预览并提示当前语法错误，不修改源码。

## 第三阶段：按需增强

图片粘贴及相对链接辅助、表格编辑、可选格式整理；类似 Obsidian 的 Live Preview 放在后期。隐藏 Markdown 标记会显著增加跨块选区、输入法、列表和手机键盘处理复杂度，应先通过源码模式的稳定性验收。

## 验收门槛

- 最近约 1000 块、5000 行文档：冷打开、连续输入、搜索、大段粘贴、源码切换分别记录耗时，并与当前版本同设备对比；不预先宣称性能提升。
- 中文输入法、iOS 虚拟键盘收起后重新点按、反向拖选、全文选择、原生 macOS 文本按键。
- 多层列表、两位数编号、代码/引用内嵌、空项退出、撤销重做和保存后重载。
- 无修改切换/刷新保持源码；输入期间异步保存或预览结果不能覆盖新输入。
- 新编辑器保留末行滚至顶部、固定导航布局与只读行为。

## 第一阶段实现边界

- CodeMirror 只保存当前源码会话的编辑状态；SourceNavigationSession 仍负责解析、导航映射和写回，未新增第二条保存通道。
- 原始 Markdown 不因仅切换视图而格式化。源码未变化时恢复该会话的撤销历史；正文实际修改后重新创建源码状态，不混合两个编辑器的历史。
- 行号、软换行和 Tab 长度复用块工作区偏好。支持 Markdown/围栏语言高亮、搜索替换、跳转行、折叠和选区格式标记。
- 空列表项回车退出，嵌套列表按层退出；输入法组合期间不执行 Markdown 回车命令。源码按钮插入 Markdown 标记，不经过富文本转换。
- 大文档由 CodeMirror 按视口挂载；末行可滚至顶部。保留固定目录、书签、阅读位置和只读限制。
- 自动化浏览器测试不能代替 macOS 原生输入法和 iOS 真机键盘验收；性能收益需在同一设备与旧版对照，尚未宣称量化提升。
