# macOS 系统菜单

macOS Tauri 保留原有应用、File、编辑、视图和窗口菜单，将文档操作并入 File，增加工作区、格式与界面菜单；Help 保持在最右侧。Web、手机及其他桌面平台保留现有界面入口，不安装此菜单。软件内按钮继续可用，专注模式可直接从系统菜单访问支持的命令。

## 操作范围

- 工作区：首页与返回文档、新建、全局搜索、快速切换、回收站、设置；文档树、文档列表、随记、阅读资料库，以及启用后的图片和词汇分栏；概览和最近打开、收藏、今日修改。
- File：保存、正文撤销/重做、源码模式、只读、属性、查找替换、跳转、目录、书签、版本历史、日志、导出，以及标题折叠与源码显示设置。
- 格式：粗体、斜体、删除线、行内代码、H1–H6、正文、列表、待办、引用、代码块与清除文字格式。源码根据 CodeMirror Markdown 语法树识别光标及选区的格式，支持标题与正文切换；转义标记、代码内的 Markdown 和混合选区不会误勾选。
- 界面：专注模式、风格、浅深配色、正文宽度、密度和布局。受当前风格和布局限制的设置禁用，例如经典风格不切换展陈布局。

菜单依照当前呈现能力启用；不是所有场景都支持每个操作。例如，局部只读视图不提供编辑操作，源码视图不提供渲染编辑器独有的操作。概览本身沿用现有展陈布局的可见性规则。

## 命令与状态的权威

`src/lib/native-menu-catalog.json` 仅定义菜单结构、稳定命令 ID、名称及原生快捷键；由 Rust 编译进 macOS 应用。它不保存文档或排版状态，不执行插件脚本。

React 活动视图向 `native-menu-registry.ts` 注册现有回调及 enabled/checked 状态。菜单执行的是同一个保存、导航或编辑函数，而不是模拟键盘、匹配按钮文案或复制一套文档实现。格式操作进入原编辑器的撤销和保存链路。分栏菜单与活动栏共用 `activateSidebarPanel`，保留首页快照、悬停/固定模式和插件主视图的挂起/恢复。

保留的后台文档，包括源码编辑器，只在文档激活时注册命令。离开或卸载后撤回；弹层打开期间禁止背景命令，执行时再次检查门禁。切换模式后原视图独有的操作会立即禁用。注册更新替换回调，不先注销再注册，避免短时禁用。

懒加载的 `native-menu-service.ts` 只在 macOS Tauri 主视图启动。它将状态同步至受主窗口标签保护的 `update_native_menu` IPC；Rust 只更新编译期清单中的项目，不接受新增任意菜单。状态签名相同时不重复 IPC，异步更新串行合并，避免输入时持续刷新整组菜单。原生勾选项会在命令发出前自行翻转，因此每次命令结束都会重新核对宿主状态，即使命令没有改变内容。主窗口失焦时禁用自定义菜单；Rust 发出命令前也确认主窗口焦点，打印预览等窗口不能误操作背后的文档。

## 原生行为与快捷键

保留 Cocoa 标准编辑响应、窗口管理和已经实现的全屏及退出确认。系统编辑菜单服务于当前原生响应者；正文自己的撤销和重做另外列在 File 菜单，明确使用 ProseMirror/CodeMirror 历史。快捷键由同一命令表供原生菜单、两种编辑模式和按钮提示使用。macOS 使用 Command，Windows/Linux 使用 Ctrl；原生 Edit 菜单的撤销、重做、剪切、复制和粘贴继续交给当前响应者，不额外注册重复的加速键。网页中浏览器保留的快捷键能否覆盖取决于浏览器；无法覆盖时仍可用工具栏和原有入口。

常用分配参考 [Notion 官方快捷键](https://www.notion.com/help/keyboard-shortcuts)，结合编辑器已有操作：

| 操作 | macOS | Windows/Linux |
| --- | --- | --- |
| 粗体／斜体／行内代码 | ⌘B / ⌘I / ⌘E | Ctrl+B / Ctrl+I / Ctrl+E |
| 删除线／引用 | ⇧⌘X / ⇧⌘B | Ctrl+Shift+X / Ctrl+Shift+B |
| 链接 | ⌘K | Ctrl+K |
| 无序／有序／待办列表 | ⇧⌘8 / ⇧⌘7 / ⇧⌘9 | Ctrl+Shift+8 / Ctrl+Shift+7 / Ctrl+Shift+9 |
| 正文／H1–H6 | ⌥⌘0 / ⌥⌘1–6 | Ctrl+Alt+0 / Ctrl+Alt+1–6 |
| 代码块／清除文字格式 | ⌥⌘C / ⌘\ | Ctrl+Alt+C / Ctrl+\ |
| 查找／替换／跳转行或块 | ⌘F / ⌥⌘F / ⌘G | Ctrl+F / Ctrl+Alt+F / Ctrl+G |
| 全局搜索／快速切换 | ⇧⌘F / ⌘P | Ctrl+Shift+F / Ctrl+P |
| 新建／保存 | ⌘N / ⌘S | Ctrl+N / Ctrl+S |
| 设置 | ⌘, | Ctrl+, |
| 源码／专注／更多编辑工具 | ⌥⌘S / ⇧⌘↩ / ⌥⌘T | Ctrl+Alt+S / Ctrl+Shift+Enter / Ctrl+Alt+T |
| 属性／目录／书签 | ⌥⌘↩ / ⌥⌘O / ⌥⌘B | Ctrl+Alt+Enter / Ctrl+Alt+O / Ctrl+Alt+B |
| 导出 Markdown／PDF | ⇧⌘E / ⌥⌘P | Ctrl+Shift+E / Ctrl+Alt+P |
| 工作区首页／返回文档 | ⇧⌘H | Ctrl+Shift+H |

格式命令只作用于活动编辑器，普通输入框和可见模态弹层不被截获；输入法组合及 AltGr 输入不被当作编辑命令。渲染 Vim 的 normal/visual 状态不启用这些原生格式加速键，菜单点击仍可使用。源码内已有的行内代码键统一为 ⌘E / Ctrl+E。

源码取消行内格式时删除实际包围当前光标或选区的语法标记，支持下划线粗斜体和多反引号；部分选中时取消整个包围范围，保留内容和内部其他格式，不重序列化文档。标题转换保留引用/列表前缀，支持常见两行 Setext 标题；代码块内禁用标题转换。

专注模式源码也提供更多编辑工具；展开状态与渲染模式共用，在文档切换及模式往返后保持。只隐藏工具栏容器，不卸载 CodeMirror、历史或已打开的搜索/跳转面板。

菜单初始化/同步异常不阻止应用启动。操作失败交给现有应用错误提示；界面中的原入口仍可使用。此命令注册器是宿主内部接口，当前不作为第三方插件的权限或菜单贡献 API。

## 验证边界

单元测试覆盖门禁、未知 ID、最新回调、过期清理、状态签名去重与焦点隔离。浏览器回归通过同一注册器验证编辑、模式切换、只读、设置、风格配色和隐藏源码文档隔离，并回归原有工作区菜单与首页往返。IPC 检查包含菜单服务。Rust 编译及测试覆盖原生侧的编译集成。

浏览器模拟不能证明 macOS 顶部菜单的实际位置、系统快捷键截获或 Cocoa 焦点通知；发布前需要在重新构建的 macOS 应用中做原生菜单冒烟验证，特别是设置输入框、打印预览、退出确认及专注模式。
