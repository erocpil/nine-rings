# 本机图片分栏与查看器

状态：2026-10-12，可信内置插件首版已实现。启用「设置 → 高级 → 启用插件功能」，在插件列表开启「图片查看」。桌面活动栏出现图片入口；手机从文档树上方图片按钮进入，沿用现有抽屉，不增加边缘手势区。

## 结构与归属

图片和目录名称不参与浏览器文本选择。右键图片提供查看图片、复制名称、复制根目录内相对路径；右键目录提供展开/收起及复制操作。应用菜单替代系统菜单，支持方向键、Home/End、Esc 与点击外部关闭；不提供原文件删除或重命名。

实现采用「宿主分栏注册 + 宿主图片目录服务 + 内置插件展示」。`WorkspacePanelRegistry` 接受受限声明（id、名称、图标、宿主 renderer），复用固定/悬停、顺序和宽度管理；激活所有权自动撤销贡献。当前只允许 images/image-library 模板，不接受插件 React、DOM 或任意新 renderer。后续目录、随记可增加宿主认可的模板和数据源，不需要各自复制分栏生命周期。

权限是内部 `panels.present` 与 `filesystem.images.read`，尚未成为公开第三方 SDK。读取每次检查激活身份，异步结果再次检查代次；停用释放浏览器临时来源、查看器和 Object URL。目录授权保存仍保留，重新开启可继续浏览。

目录/查看实现位于 `src/lib/image-library/`、`ImageLibraryPanel`、`ImageViewerDialog`；桌面文件服务位于 `src-tauri/src/commands/image_library.rs`。

## 平台授权与数据边界

- Tauri macOS/Windows/Linux：Rust 系统目录选择器授予根 ID；后续命令只接受根 ID 与相对节点，不接受任意磁盘路径。校验规范路径与根边界，拒绝符号链接；Windows 同时过滤 reparse point。仅主窗口调用，目录扫描及图片读取在后台线程。
- Web：支持 `showDirectoryPicker` 时将句柄保存在设备本地独立 IndexedDB，展开时检查/重新请求权限。否则使用目录或图片文件选择，形成会话内快照，停用或刷新后需重新选择。
- 手机：使用浏览器/系统文件选择能力。图片按钮接入既有抽屉；目录能力受实际浏览器限制。Flutter/iOS Tauri 不在此次范围。

Tauri 授权记录是应用数据目录的 `image-library-roots.json`；Web 是 `nine-rings-image-library` 数据库。两者不写入共享文档或 GitHub 备份。撤销授权不删除原文件。没有目录监听，文件变化后手动刷新。节点 ID 为根内相对路径；移动/重命名后需刷新，不承诺 inode 级持久身份。

文件系统校验不能消除其它进程在校验与打开之间恶意替换路径的竞争；当前可信内置服务不是为不可信本机文件系统设计的沙箱。原生系统目录选择、持久授权和 Windows/Linux GUI 仍需真机验收。

## 查看与插入

参考 [digiKam 的目录、缩略图和预览分层](https://docs.digikam.org/en/main_window/interface_layout.html)，图片树负责导航，中央文档区域显示大图；正文图片默认使用居中弹层，可转到主区域。工具栏与文件名保持固定，提供上一张/下一张、适宽、原图、缩放、平移、预览旋转、复制与插入当前文档。上一张/下一张仅遍历当前已加载目录页或当前文档图片，不扫描整个磁盘。

文档中的图片增加「查看图片」弹层入口及「在主区域打开」按钮；可编辑图片沿用调整尺寸操作。文档图库从实时结构化内容提取，包含未在可视区渲染的图片；同一资源去重。只读文档允许查看和复制，禁止插入。

本机图片插入经现有图片插入工具复制为 `nr-image://`，随文档保存和备份，并可单步撤销；不插入 `file://`。文档内既有应用资源可复用引用。复制的是当前预览，跨域网络图片复制受浏览器安全限制。

## 预算与资源

- PNG/JPEG/GIF/WebP/AVIF/BMP；不读取 SVG 或任意文本文件。
- 每张图片最多 256 MiB；文件快照一次最多 5000 项。
- 单目录最多 10000 项，每页 200 项，按目录优先、名称排序；按需展开，不递归扫描整盘。
- 缩略图靠近可视区才请求；读取/解码并发最多 2，显式查看优先。
- 支持的浏览器生成最大边 128/2048 的缩略图/预览，原图按需读取；Bitmap 与 Object URL 随取消、关闭、切图和停用释放。浏览器解码能力仍决定瞬时内存，不能保证恶意超大像素图的峰值内存。
- GIF 降采样预览可能显示静态帧；查看原图保持浏览器原生动画。当前没有跨页面磁盘缩略图缓存或大目录虚拟树。

## 后续图片处理契约

本轮已将预览变换提取为 `ImageTransformRecipe`（version 1、quarterTurns、flipHorizontal、flipVertical）及纯操作函数。宿主图片 renderer 使用该配方生成 CSS 预览，复制 PNG 通过相同配方生成独立结果；缩放和平移是查看状态，不进入输出像素。输入源保持不可变，插入文档仍使用原资源。当前配方不是公开 SDK，也不接受第三方任意处理代码；未来裁剪/尺寸调整应添加版本化参数校验、输出预算、取消信号和宿主提交事务。

图片树与查看器共用按需缩略图组件和既有解码队列。查看器缩略图带使用覆盖整个当前图库的横向虚拟列表，只挂载可视范围及少量缓冲项，不扫描全盘。细滚动条默认透明，悬停或键盘操作时显现；触控板横向或纵向双指滚动均映射为横向浏览。固定缩略图高度并将名称单独布局，避免竖图覆盖名称。开关和主题/深色/浅色/透明棋盘格背景保存在本机；未进入共享文档或备份协议。适窗按旋转后的尺寸计算，不放大小图；原始尺寸按原图像素100%显示，双击切换适窗/原始尺寸。水平/垂直翻转和复位仅影响预览，复制结果保留旋转与翻转。

图片树在插件启用期间保持实例，切换分栏或收起只隐藏并暂停缩略图可视区观察，保留已展开目录、滚动位置及当前可视缩略图；正常滚动离开可视区仍释放缩略图，停用插件卸载全部实例及资源。手动刷新继续重新读取目录。

图片平移在每个轴上保留至少24px可见部分（小于24px的图片保留其完整边长），阻止继续移出；旧的越界状态仍可逐步往回拖。Mermaid 独立预览沿用更严格的内容溢出范围，并使用相同方向判断；正文内 Mermaid 由原生滚动范围限制，边界时允许滚动正文。

当前旋转仅影响查看状态，不修改源文件。未来图片处理应使用独立操作声明：操作 ID、参数 schema、不可变输入资源 ID、取消信号、输出资源及诊断，不直接给插件裸路径。

处理流程为「读取 → 预览结果 → 明确确认 → 保存副本/替换文档资源」。默认另存副本；写本机文件需新增独立权限、显式目标授权及冲突检查，不能复用只读权限。替换文档图片必须经过宿主编辑事务，与文档撤销和保存协调器共享边界。源文件、处理结果和预览状态分开管理，避免旋转/裁剪预览悄悄覆盖图片。

可优先加入裁剪、旋转导出、尺寸调整和格式转换；批处理、OCR、滤镜及远程处理另行评估性能与权限。第三方加载器、任意 renderer 和写盘接口均未开放。

主区域展示是独立插件贡献能力，保存门禁、原视图保留和首页返回规则见[主区域视图贡献](plugin-main-area-views.md)。

## 图片交互与属性（2026-10-12）

图片树展开路径保存在本机，重新启动后按已授权目录恢复；已加载页/滚动位置保存在插件本次会话中，分栏隐藏或切换不清空；停用插件释放。当前图片独立于树 DOM，点击和上一张/下一张都会同步选中高亮；主区域活动时方向键跨分栏焦点可用，输入框、设置/菜单等弹层保留自身按键优先级。图库仍只包含已加载的目录页或当前文档图片。

Mac Safari/WKWebView 额外接收 gesturestart/change/end，缩放取相对手势起点的累计 scale、围绕手势位置缩放，阻止页面缩放；与 Ctrl/Command+wheel 和触屏双指流去重。原生触控板实际手势需真机验收，合成 GestureEvent 回归不能替代硬件输入。

标题右侧提供缩略图开关，其后依次为属性、返回/关闭、专注。主区域图片和文档共享工作区专注状态及本机偏好，切换分栏或返回文档不重置。专注隐藏工作区装饰，保留活动栏、分栏及分隔条，沿用当前固定/悬停和收起状态。正文图片弹层专注仅控制弹层占满窗口。Esc 先关闭属性，再退出专注，最后返回/关闭查看器。

属性默认悬浮在预览右侧，可固定为右侧栏；固定后图片仍在剩余空间适窗显示。切图、包括再次点击树节点，都保留属性开关/固定状态并更新内容；关闭/停用释放读取任务。手机采用覆盖式固定，避免把图片挤成窄条。

属性包括名称、来源/目录/相对路径/附件 ID 或 URL、字节大小与 MIME、原图与解码/预览像素、像素数、宽高比、方向、修改/创建时间（平台提供时）、格式/位深/颜色类型/ICC/sRGB/动画标志，以及可解析的相机品牌型号、镜头、拍摄时间、ISO、曝光、光圈、焦距等常用 EXIF。元信息读取限制为前 2 MiB、最多 256 个 IFD 条目，校验偏移与长度，损坏/未知标签不影响看图；当前不承诺解析完整 EXIF/XMP/IPTC、所有 AVIF/WebP 元信息或 GPS 坐标。跨域网络图片不为属性另行下载，仍提供已加载图片尺寸和查看信息；不会猜测缺失的创建时间或拍摄数据。

Tauri 增加只读 image_library_stat，沿用主窗口/授权根/相对路径/符号链接边界和后台线程，补充文件时间与大小。没有增加写盘或图片处理权限。

缩略图与最近大图预览共用会话 LRU 缓存，按资源身份和预览尺寸分开，合并同一资源的进行中请求。未使用项按估算64 MiB/192项预算淘汰；仍被显示的资源不强行撤销，实际内存仍由浏览器解码决定。取消单个请求不影响其它使用者，刷新目录、撤销授权或停用插件清空缓存；原始尺寸资源不长期缓存。加载提示位于预览区右下角，不遮挡图片中心。当前缓存不跨应用重启。

## 大图与桌面紧凑浏览（2026-10-13）

原生图片读取使用二进制 IPC，避免大图转换为 JSON 数字数组；读取前检查文件大小，并在读取过程中限制增长。预览按原图宽高比例将最长边限制为2048像素，缩略图为128像素，支持EXIF方向交换；原文件保持不变。授权撤销仍使进行中的读取失效。

桌面缩略图带默认收回，不显示固定按钮、不预留布局空间，仅通过透明底部感应区唤出；悬停展开，可固定为常驻导航带，手机保持直接显示。标题显示原图尺寸，所有查看按钮使用图标并保留提示和可访问名称。属性面板默认260像素，可拖动左边界调整至200～480像素，宽度在本机保存；手机覆盖显示。图片树目录展开状态按根目录ID与相对路径在本机保存，目录页与缩略图缓存仍仅存在于会话中；临时文件选择不恢复跨会话授权。

## 目录变化自动检测（2026-10-13）

- Tauri通过notify 8.2的系统后端非递归监听已展开目录，读取类事件不触发刷新；同一目录由树和查看器共享监听，最多256个原生监听，超过或后端不可用时在可见期间定期检查。只向主窗口发送监听ID，不传播绝对路径或内容；每次重读仍检查授权目录和符号链接边界。移除根目录会释放该根监听，停用插件会释放全部监听、事件订阅和计时器。
- Web持久化目录句柄每10秒检查一次，限于可见分栏的已展开目录或当前正在查看的目录；文档隐藏时暂停定时检查，恢复焦点/可见时检查一次。后台只查询已有权限，不自动弹出授权请求。临时文件快照不具备持续目录访问能力，需重新选择。
- 通知在250毫秒窗口内合并，同一目录不并发重读。保留已经加载的分页范围、展开状态和滚动位置，不重建整棵树；Web只读取返回页的文件元信息，避免为未加载项目逐个getFile。分页移动不直接视为删除，需检查旧路径是否仍存在。
- 文件大小/修改时间变化时只淘汰对应图片的缩略图及预览缓存，保留其它图片缓存和正在使用的资源租约；查看器和属性会刷新，当前图片、缩放和预览变换不因其它文件变化而重置。缩略图导航集合也随当前目录更新。
- 当前图片被删除、改名或暂不可访问时，保留已加载的预览与选中条目并提示，禁用从不可访问文件插入正文/重新加载原图；用户主动选择其它图片后才切换。原路径重新出现时清除提示并读取新预览。目录被移除导致原监听失效时，改为可见期间的检查以便恢复。

插件列表把开启/关闭、类型及运行状态集中在同一元信息行，名称独占一行作为配置入口，简介在下方。窄屏空间不足时元信息可自然换行。
