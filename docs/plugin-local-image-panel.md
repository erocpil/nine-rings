# 本机图片树分栏：插件设计建议

状态：设计评估，尚未实现。与文档内图片插入分开：插入会复制资源并参与文档备份；本机图片分栏仅浏览明确授权的目录，默认不复制文件。

## 结构与归属

适合采用“宿主数据服务 + 插件展示”的结构，复用[分栏展示贡献](plugin-panel-presentation.md)。宿主拥有分栏开关、固定/悬停状态、宽度、文件授权、目录扫描和资源生命周期；插件提供树节点展示、排序、过滤、提示与工具栏声明。不要让插件直接读取磁盘或操纵分栏 DOM。

现有文档树展示槽位只支持文档树配置，并不具备新建任意分栏能力。因此需要新增受限 `panel` 贡献点，以及 `local-image-library` 数据源，而非伪装成文档路径。

## 平台授权

- Tauri macOS/Windows/Linux：用户选择一个或多个根目录，宿主保存设备本地授权根；命令只接受根 ID 和相对节点 ID，规范化、校验真实路径及边界，拒绝跨根访问。首版不跟随符号链接，防止逃逸与循环。原生 sandbox/bookmark 的持久授权需按实际打包方式验证。
- Web：支持目录授权 API 的浏览器可保存授权句柄，重启时检查并提示重新授权；能力不足时使用目录文件选择作为会话内快照。不能承诺任意浏览器都能持续读取本机目录，也不能暴露完整磁盘路径。
- 手机：沿用系统文件选择的可用能力，首版不承诺目录监听。Flutter 暂不设计。

路径、句柄和目录授权都是设备本地数据，不随 GitHub 备份扩散。删除/断开授权只关闭浏览来源，不删除磁盘文件。

## 数据与查看行为

宿主分页返回摘要：根 ID、稳定节点 ID、父 ID、显示名、目录/图片类型、大小、修改时间和加载状态。按需展开目录，限制扫描数量，不递归扫描整盘。节点身份要处理重命名与移动，不能仅靠显示名。

树中选中图片后，在已有阅读区或图片查看区显示适宽预览，支持上一张/下一张、缩放、双指平移、打开所在目录、复制图片及插入当前文档。缩略图按可视区域请求，缓存有内存/磁盘预算，释放 Object URL；大图按尺寸降采样，原图只在用户明确请求时解码。

“插入当前文档”经过宿主附件导入，复制图片并生成 `nr-image://` 引用，不能直接插入不稳定的 `file://` 路径。删除、移动、重命名磁盘文件暂不开放，避免把图片浏览器首版变为文件管理器。

## 权限与命令

拟新增独立权限 `filesystem.images.read`、`panels.localImages.present`；写入文档另需既有编辑权限。读权限只覆盖用户授权根中的受支持图片和必要目录摘要，不能据此读取任意文本文件或上传数据。宿主签发短期预览资源，不向第三方插件返回裸路径、文件句柄或任意调用 Tauri 的入口。

建议命令：选择/撤销根、列子节点、读取缩略图、请求预览、上一张/下一张、复制、插入。每个命令校验授权、节点归属、当前代次、取消信号和资源预算；权限撤销或文件消失时清空预览并显示可恢复错误。权限名称是设计提议，不代表公开 SDK 已开放。

## 实施顺序与验收

1. 宿主图片目录服务及跨平台能力检测，路径逃逸、符号链接与撤销授权测试。
2. 新分栏贡献及默认可信图片树插件，复用固定/悬停/宽度状态。
3. 预览、缩略图、键盘/触控及插入当前文档。
4. 授权持久化、按需更新；大目录、文件移动/删除、离线/权限失效、多窗口和内存预算回归。

先交付可信内置插件，再考虑第三方复用。验证包括原生三平台路径规则、Web 目录能力差异及真实大图片性能，不能仅用浏览器 mock 宣称完整磁盘支持。
