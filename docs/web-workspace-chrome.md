# 桌面 Web 工作区顶部简化

## 范围

- 仅桌面 Web 移除 `app-header` 和重复的侧栏显隐箭头。左侧分栏按钮保持可见：点击当前分栏收起，再点恢复；宽度记忆、拖动隐藏及阅读冻结逻辑保持不变。
- Tauri 自定义窗口标题栏、原有文档顶栏和手机 PWA 文档顶栏不在此次移除范围内。
- 专注模式保留：快捷键、状态栏显示策略、只读标题折叠等不变。桌面 Web 共用普通模式文本区标题行，不使用额外的吸顶标题副本或独立专注标题条；点击专注标题仍切换属性页。
- 完整编辑器和实验性的只读局部阅读均适用。复制块、目录、书签、退出专注模式和展开编辑工具仍可用。

## 搜索

全局搜索使用独立不透明弹层，包含输入框、筛选和可滚动结果；打开时聚焦，支持关闭按钮、Esc 和焦点恢复。桌面左侧按钮栏及文档列表均有入口，手机使用文档列表工具栏入口。关键词和筛选保留于当前运行会话，关闭时取消待执行查询，重开时重新查询。正文不因搜索卸载，专注模式也不会被强制退出。

继续使用原有搜索索引和加密隔离：已经解锁的文档也不会暴露加密正文；非加密标题仍可检索。文档列表筛选、全局搜索、正文查找仍是不同的功能。

## 标题状态及恢复

- 加密正文以标题前的盾牌图标表示，与只读锁区分。点击盾牌先保存，再锁定正文；设置/解除密码仍在属性页。
- 当前文档保存失败：标题红色加删除线；失败后的待保存/重试阶段使用黄色加删除线，成功后恢复。不是对文档内容加删除线，不改变标题字符串。
- 标题旁的警告按钮和左侧警告入口可打开错误详情，状态栏可见时也提供入口。首次出现新的错误会打开详情，同一错误不会因关闭弹层而反复弹出。
- 详情包含重试保存、导出恢复文件、复制错误信息。关闭详情不清除错误或未保存内容。加密文档的恢复导出仍走已有密文保护流程。

## 验证

重点覆盖 `workspace-chrome`、`desktop-navigation`、`platform-presentation`、`encrypted-header`、`search-navigation` 和 `reader-sidebar-resize` E2E；手机入口使用 `pwa-layout` 中的「文档列表工具栏承接查找入口且全局搜索立即聚焦」。Windows Tauri 的原生外观和 iOS 虚拟键盘仍需实机验收。
