# 阅读展示：可安装的声明式插件包

插件 ID：`erocpil.reading-display`；版本：`1.0.0`。支持 Nine Rings `0.3.x` 与插件 API `0.1.x`，Web 和 Tauri 桌面版使用同一包。

## 提供的功能

- 渲染块号及源码行号：13px 等宽、当前编号加粗并使用主题强调色，背景透明，折叠符号为 `▸` / `▾`。相对编号默认关闭；开启后的当前项对齐沿用块号右对齐、行号左对齐的配置。
- 状态栏：12px、语义色、透明背景，普通及专注模式均显示；保留保存、块号、位置、字符/词数、导航、日志和历史。导航位于右侧日志之前。
- 不修改正文、文档折叠状态和保存机制，不访问本机文件或网络，不执行插件代码。停用或卸载后恢复宿主原有展示设置。

## 构建安装包

源文件：[manifest.json](../schema/plugin/examples/erocpil.reading-display/manifest.json)。打包工具补齐完整性声明并校验，不会修改源文件；目标已存在时拒绝覆盖。

```sh
bash scripts/with-local-tools.sh node --import tsx scripts/pack-plugin.ts \
  schema/plugin/examples/erocpil.reading-display \
  /tmp/erocpil.reading-display-1.0.0.nrplugin.zip
```

## 安装与启用

1. 打开「设置 → 高级」，开启「启用插件功能」。
2. 如果内置「编号展示」「状态栏展示」或其它同类声明式包正在运行，先停用，避免多个 provider 争用同一展示区域。
3. 在「已安装声明式插件」选择 `.nrplugin.zip`，审查名称、版本、指纹和三个展示贡献，勾选确认后安装。
4. 安装后默认停用；开启「阅读展示」后生效。配置保存在本机，重启恢复启用状态；迁移设备需重新安装。
5. 停用或卸载只撤销展示资源，不删除文档或原有宿主偏好。内置设置在被接管期间不可编辑。

这是固定声明的展示预设，当前不为已安装包生成可编辑配置表单。如需定制，可修改清单、提升包版本、重新打包并审查更新；不能同版本替换不同内容。修改平台范围使用 `web` / `desktop`，不要使用宿主内部名称 `tauri`。

文档树、目录、书签和随记目前通过可信内置展示插件配置；此包仅使用已开放安装的编号与状态栏贡献，不宣称安装第三方任意分栏 renderer。完整安装和预算边界见[声明式插件安装](plugin-package-installation.md)。
