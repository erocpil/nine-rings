# 文档内目录与标题跳转

## 自动目录

在可编辑渲染视图的独立空段落输入 `/toc`，再按空格或 Enter，插入自动目录并将光标放到下一段。默认显示 H1、H2、H3；目录上方的六个复选项分别控制 H1～H6，至少保留一种级别。修改标题文字、级别或顺序后，目录随正文模型更新，不需要手动维护链接列表。级别修改可撤销，保存和刷新后保留。

编辑、完整只读、局部只读和源码并排预览共用目录列表与标题解析。只读目录仍可跳转；调整展示级别需回到可编辑视图，或修改源码中的配置。

自动目录保存为 Nine Rings 扩展的 `toc` 围栏块：

````markdown
```toc
levels: 1,2,3
```
````

只保存展示级别，不把生成的标题列表写回正文。其它 Markdown 阅读器可能将这个扩展显示为普通代码；`/toc` 本身不是 CommonMark 标准语法。复制或导入这个围栏块，也可创建自动目录。每个目录块独立保存级别设置。

自动目录用当前文档的位置标识导航，避免超长标题形成巨大链接。该标识是渲染时生成的内部链接，不适合手动写入 Markdown 或用于其它文档。

## 手写 Markdown 目录

支持 `[目录项](#标题锚点)`，例如：

```markdown
[网卡接收](#3-网卡接收rx-ring-与-dma)

## 3. 网卡接收、RX ring 与 DMA
```

标题锚点采用 GitHub 风格：英文小写、空格转换为 `-`、删除标点、保留中文及 `_`/`-`；格式以标题的实际文字为准。重复锚点依次附加 `-1`、`-2`，并避开已有同名锚点。支持百分号编码的中文锚点。跳转使用当前文档模型定位，不改变浏览器 URL、不创建另一个页面；编辑/完整只读沿用现有标题导航，局部只读先挂载目标位置，源码预览定位对应预览块并同步源码滚动。

这种链接语法属于普通 Markdown 链接；自动生成标题 ID 是渲染平台的规则，CommonMark 没有统一规定其算法。参考 [GitHub 章节链接规则](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#section-links)。修改标题或重复标题顺序后，手写链接仍需更新；自动目录无需更新。

## 超长标题

自动目录与目录面板的标签统一最多显示 80 个 Unicode 字符，超出后加省略号；自动目录另按实际宽度单行省略。悬停提示最多显示 500 个字符。原始标题、文档内容和手写锚点均不截断，缩短显示不会影响跳转。目录面板的行高估算也使用缩短后的标签，避免误将整段正文设为标题时撑高目录。

### 目录层级展示

文档内自动目录与侧边目录使用真实 H1～H6 级别；`levels: 2,3` 只显示 H2、H3，不补出被筛掉的 H1。条目展示 Hn 标记，并沿用目录层次配色设置，标题文字保持链接样式。缩进以实际可见的最浅标题为基准，深一级增加 14px；跳级保留真实层级差，不因配置勾选了不存在的 H1 而整体右移。条目字体和行距与正文列表样式隔离，超长标题仍只截断显示，不改变目标。

源码预览复用相同目录组件；富文本复制保留相对缩进，普通文本复制只输出标题。PDF 自动目录采用同样的可见层级基准，不把 flow、引用、details、列表和表格内部的标题当作文档级标题。选择级别仍通过块菜单完成，不改动文档标题或源配置。
