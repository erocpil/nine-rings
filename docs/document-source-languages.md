# 文档文件格式与源码语法

状态栏右侧提供“文件格式”选择，macOS Tauri 的“格式 → 文件格式”提供相同选项和勾选状态。类型列表与代码块语言共用 `src/lib/code-language-options.ts`，默认 Markdown；原有纯文本导入默认显示 text。

这项选择控制整份文档在源码视图中的语法高亮，不改写正文、文件名、扩展名或 Markdown 的存储与渲染规则。普通渲染和源码状态栏共用每份文档的选择；文档只读时显示当前值并禁止修改。更改格式不进入正文撤销历史，源码选区和既有撤销/重做历史保留。

## 数据与兼容

设置保存到 `DocumentMetadata.sourceLanguage`。未设置时由 `sourceFormat` 推导：text 对应纯文本，其余对应 Markdown。`sourceFormat` 继续表示既有导入/解析约定；发布元信息中的 `language` 继续表示文档自然语言，三者不能混用。

保存前先刷新正文，再通过现有 metadataOnly 保存边界写入。源码修订的延迟读取会捕获该次修订的语言值，避免旧保存任务读取后续变化的可变状态。源码与渲染模式后续编辑继续保留设置。增量正文元数据认证允许代码块语言列表中的值，未知值保持门禁。

现有纯文本导入仍使用原有纯文本呈现；PDF/EPUB 摘录等没有源码入口的视图不会因此增加源码编辑能力。格式选择不承担将普通 Markdown 转换为独立代码文件的功能。

## 语法加载

CodeMirror 使用单独的 Compartment 切换语法，不重建 EditorView、文档或 history。Markdown 使用现有解析器、围栏语言支持和微渲染；其它代码语言由已有 `@codemirror/language-data` 按需加载。text 不安装解析器。Flow 和 Mermaid 当前沿用代码块源码的普通文字高亮策略，图形展示继续由文档中的对应块负责。

切换时立即撤下旧解析器，并在异步加载完成后确认请求仍有效，防止快速连续选择让旧语法覆盖新选择。高亮加载失败不修改正文，状态提示重新选择文件格式。微渲染只在 Markdown 语法下生效，避免把代码中的符号当成 Markdown 标题。

语言枚举拆到轻量模块，状态栏和同步门禁不会因此导入整个 highlight.js。原 `code-highlight.ts` 保留枚举的兼容导出，已有代码块消费者继续工作。

## 验证

单元测试检查旧文档默认值、菜单与代码块枚举一致性，以及同步元数据认证。浏览器回归检查实际 Python 高亮、纯文本取消高亮、正文/选区不变、撤销/重做、重开恢复、只读门禁，以及标题操作按钮在桌面和手机宽度下等宽。

原生菜单结构编译进 Tauri，需要重新构建后才能看到新增子菜单；浏览器测试通过宿主命令注册器检查同一动作与状态。
