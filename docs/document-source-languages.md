# 文档类型、源码权威与预览

2026-10-20。文件格式已经具有实际的视图与保存语义，不再仅是源码高亮偏好。

## 视图能力

| 类型 | 渲染 | 源码 | 并排预览 |
| --- | --- | --- | --- |
| Markdown | 普通文档渲染 | Markdown 编辑与微渲染 | 支持 |
| Flow | 整份源码的流程展示 | Markdown 形式的 Flow 源码 | 支持 |
| Mermaid | 整份源码的图表 | Mermaid 源码与基础高亮 | 支持 |
| Text、C、Python、JSON 等 | 不提供 | 纯文本或对应语言高亮 | 不提供 |

独立 Flow、Mermaid 文档无需外层代码围栏；嵌入 Markdown 时继续使用原有 Flow、Mermaid 代码块。预览是只读投影，修改正文需要回到源码；文档本身仍可设置只读，禁止源码编辑和持久化格式更改。只读状态允许设置设备本地的查看格式覆盖，不修改正文或文档元数据。

并排预览沿用现有桌面布局，手机保留源码/渲染单视图切换。不可预览的类型隐藏渲染、并排预览和 Markdown 专用工具；查找替换、行号、软换行、语法折叠、撤销重做、缩进、书签和状态栏继续复用。Flow 源码可以使用 Markdown 编辑辅助；Mermaid 和普通代码不会继续 Markdown 列表，也不会响应粗斜体等 Markdown 命令。

## 数据权威

Markdown 保持现有 Delta 与渲染编辑器的权威边界，`markdownSource` 保留未经渲染编辑改写的原始 Markdown。

非 Markdown 文档以 `DocumentMetadata.sourceText` 保存原始源码；`ops` 是通过 `plainTextToDelta` 生成的可搜索纯文本投影，不经过 Markdown 解析。`sourceLanguage` 决定文档类型，`sourceFormat: text` 防止普通文本中的表格、列表等符号被历史兼容逻辑重新解释。发布元信息的 `language` 仍表示自然语言。

原有纯文本导入若没有 `sourceText`，从纯文本 ops 恢复；此前只选过语法、但尚按 Markdown 存储的文档，优先使用保留的 `markdownSource`，再使用结构化序列化结果。新导入按扩展名推断类型，并立即保留源码。编码和换行解码沿用现有文本导入约定，不新增字节级文件编码编辑能力。

源码修订使用 `SourceNavigationSession`，非 Markdown 分支构造字面段落模型，并按原始行建立导航位置；不会为了目录、书签或同步滚动再调用 Markdown 解析器。Flow、Mermaid 的预览模型单独把整份源码作为一个相应代码块投影，不替换源码权威。

## 格式切换

状态栏和 macOS“格式 → 文件格式”共用文档语言选项；文档选项从代码块语言中派生，并合并 C/C++、排除 C#。可编辑文档使用下述保存链路；只读数据库文档和磁盘文件改用设备本地查看覆盖，并提供“自动识别”恢复文档元数据或文件扩展名的类型，不改名、不写文件，也不进入备份。

1. 刷新当前未保存的正文。
2. 取得当前完整源码；源码视图优先读取活动 CodeMirror 文档，渲染 Markdown 优先读取保留源码。
3. 切换到 Markdown 时解析为 Markdown Delta 并保存 `markdownSource`；切换到其它类型时保存 `sourceText` 与纯文本投影。
4. 通过现有正文保存链路提交，同时映射内部引用与书签；不能将表示方式变化冒充 metadataOnly 更新。
5. 按新类型启用或隐藏视图入口。源码中的字符、缩进、空行不会因文件格式选择而添加转义或被裁剪。

修改同一个源码视图的类型时不重建 CodeMirror，保留选区及编辑历史。Markdown 与纯文本之间解释方式不同；当切回渲染并继续编辑时，后续源码标准化仍遵循既有 Markdown 编辑规则。选择已生效的类型是空操作。

## 语法、预览与故障

源码折叠的光标规则：折叠区域包含当前光标时，临时将光标投影到可见的折叠边界；展开后恢复折叠前的行、列。期间若主动移动光标、搜索跳转或编辑正文，则新位置优先，不再自动跳回。单纯滚动不取消光标记忆，视口定位仍独立处理。嵌套折叠逐层恢复；一次展开全部优先最内层的原始位置，隐藏子区域提前展开时把待恢复位置留给仍折叠的父区域。

这一规则由 `source-fold-cursor.ts` 的文档级 CodeMirror 状态统一处理，适用于源码三角、折叠占位符、快捷键及工具栏（包括 Markdown 标题级别）。可编辑与只读共用逻辑；只读模式额外同步被折叠 DOM 的原生选区，不抢焦点且继续隐藏编辑光标。共享源码编辑器在行号和折叠图标的鼠标按下阶段阻止浏览器先选中文字或移动焦点，再分别打开行菜单或执行折叠，数据库文档和磁盘文件一致。点击占位符只展开，不先移动光标而取消记忆。折叠及光标记录不修改正文、不触发文档保存；有正文编辑时清除旧偏移，不对变化后的源码猜测原列位置。

CodeMirror 使用 Compartment 切换语法，按需加载 `@codemirror/language-data`；Text 不安装解析器，Flow 复用 Markdown，Mermaid 使用轻量词法高亮，真正的图表校验仍由 Mermaid 渲染器负责。异步语言请求具有失效检查，旧请求不能覆盖新选择。

独立预览复用 `FlowBlockContent` 和 `MermaidDiagram`。并排预览复用同一代码块渲染器，保证语法和主题一致。Mermaid 错误不会改写或删除原文；源码入口始终保留，用户可返回修正。编辑类插件在只读预览表面禁用，切回源码后恢复相应能力。

纯文本/代码保持源码视图，重开恢复源码滚动位置。Flow、Mermaid 可恢复上次渲染/源码选择；源码与图形不具有逐行一一对应关系，并排滚动使用现有锚点及滚动范围映射。

## 导入、导出与增量备份

文本导入白名单扩展到支持的代码及图表扩展名；仍先解码文本、拒绝二进制控制字符。单文档导出使用对应扩展名，原始源码不添加 Markdown 标题、不裁剪尾部空白。

增量元数据认证允许 `sourceText`，并核对其纯文本投影与正文一致。Flow、Mermaid 派生资源复用现有可移植资源检查；源码中包含不能备份的本机图片引用时不能绕过认证。源码字符串作为文字保存，不被当成 HTML 插入页面。

## 验证

单测覆盖类型能力矩阵、菜单枚举、扩展名推断、原始源码往返、纯文本导航及备份认证。Chromium/WebKit 交互回归覆盖源码专用入口、Markdown 命令门禁、空行和缩进、撤销/重做、Text/Markdown 往返、Flow/Mermaid 三种视图、连续重开和 Mermaid 错误恢复。macOS 原生菜单的实际展示需要重新构建 Tauri 后确认，浏览器测试使用同一宿主命令注册器。

### 代码类型与粘贴保真

文档格式列表合并显示 C/C++，旧 C++ 文档按该类型打开；C# 不再作为可选文档格式，既有 C# 原文仍可作为纯文本打开。代码块自身的语言列表不受影响。代码与纯文本源码使用等宽字体，独立于正文排版字体。

源码粘贴读取纯文本，不采用剪贴板的 HTML 排版。Markdown 语法高亮或微渲染只是显示层，不应改写字符。回归验证包含带 HTML 的 C 源码粘贴、渲染往返、切换 C/C++、保存重开，检查符号、Tab、空行和尾部换行。

### C/C++ 分类高亮

`source-code-highlighting.ts` 复用 CodeMirror/Lezer 的 C++ 语法树，为 C/C++ 文档提供独立分类样式。宏定义名称补充 `PreprocDirective/Identifier` 的上下文标记，不用正则猜测符号。控制关键字、定义关键字、修饰符、类型、函数定义/调用、成员、宏、预处理、字符串/字符/转义、数值与注释分别展示。普通变量继续使用正文颜色，函数定义适度加粗。

颜色使用当前风格的 `--syntax-*` 色值；对比度不足的关键字和预处理颜色与正文色混合。语法高亮关闭时取消分类色及额外字重，不修改源码或撤销历史。本能力仅为语法分析，不保证解析宏展开后的类型、跨文件符号及编译条件。

### C/C++ 本文件符号大纲

C/C++ 文档复用源码模式既有的目录面板及固定/悬停状态，面板名称为“源码符号”；Markdown 继续显示标题目录。宿主通过 `source-symbol-provider.ts` 的内部提供器契约选择解析器，目前 C/C++ 提供器调用 `source-symbols.ts` 中的 CodeMirror C/C++ Lezer 解析器；该契约不向插件开放。解析结果包含命名空间、结构体/联合体/枚举、类型别名、类型成员、函数定义/声明及文件级变量。函数体内的局部变量不进入大纲。列表以 `{}`、`ƒ`、`T` 等窄标记区分类型、函数和别名，并采用较紧凑的行高；成员显示为 `name: type`，函数签名包含可解析的返回类型。原始 `text` 保留解析器识别的名称/签名，单独的展示文本用于列表，不改写源码。

大纲还收集 `#define`、`using`/`typedef`（包括指针与函数指针类型）别名、命名空间别名、嵌套命名空间与类型、构造/析构函数、运算符、重载函数及函数指针变量；返回函数指针的函数保留完整声明签名。成员详情带访问级别。符号身份结合限定作用域、类别和规范化的函数参数类型；参数名不参与身份，因此声明与定义的参数命名不同仍可对应，重载仍可区分。

源码符号和同词匹配现在各自注册为受信任的内置分栏展示插件，设置可以独立调整字体、字号、行高、颜色及辅助信息。插件只接收展示配置，不接触源码缓冲区、Lezer 解析树、选区或跳转回调；插件停用后回退到宿主默认外观。源码编辑区的右键菜单由宿主提供，按只读状态开放撤销/重做、剪切、复制、粘贴与全选；普通文档树及其它面板不被该菜单拦截。

单击源码行号打开该行的操作菜单，包括选择、复制、剪切、删除、复制到下一行、前后粘贴/插入空行、上下移动、缩进、注释与书签。相对行号和折叠只影响显示，操作以 CodeMirror 的实际文档行定位。编辑命令可撤销；只读文档禁用修改操作。剪贴板按纯文本读取，复制整行带换行，前后粘贴保留行边界。异步剪贴板读取完成前再次检查文档快照、菜单会话和只读状态，菜单关闭、切换文档或修改正文后取消过期操作；空文本及权限失败在菜单内提示。

源码变化先合并到短暂快照，再延迟解析；解析以小时间片协作推进，用户继续编辑或切换文档时会取消旧任务。目录列表复用已有折叠、当前项跟随、滚动定位和展示配置。解析不依赖光标移动，因此光标更新不会触发全文解析。当前项先在源码顺序中按偏移解析，再映射到显示排序后的列表索引，避免字母排序时把源码较早但显示靠后的符号误判为当前项。用户在延迟更新窗口内点击旧列表时，先用源码编辑映射得到近似位置，再对最新缓冲区解析并按稳定符号身份重新定位；同一身份有多个候选时取距离原位置最近的一项。如果解析期间源码仍有变化则重试，符号身份已变化、声明已删除或无法取得稳定快照时不猜测跳转位置，等待大纲刷新。这样插入/删除前置内容后仍优先跳到对应声明，而不是沿用过期偏移。

每份文档的源码符号结果保存在它自己的保留编辑会话中。切换文档时暂停该文档的解析并保留最后一次完整结果；返回时若源码未变化就直接复用，源码变化后才重新解析。文档编辑会话被淘汰时，其符号缓存也随之释放。

源码模式的书签仍是文档级 `metadata.bookmarks`，与渲染模式共用 ID、名称、创建时间及 ProseMirror 位置；源码解析层额外维护原始源码偏移，供源码跳转使用。添加时按光标所在文本块建立锚点，编辑时跟随源码位置映射并刷新摘要；重命名和删除直接更新同一份元数据。切换回 Markdown 渲染视图或重新打开文档后，书签仍对应同一文本块。源模式侧栏复用渲染模式的书签行、重命名对话框、删除操作和展示插件。

这是语法级单文件大纲，不提供跨文件索引、宏展开或编译条件下的语义保证。未完成/不完整的源码由容错语法树尽力识别；无法识别的声明暂不列出，不影响编辑和跳转到其它已识别符号。单元测试覆盖宏、命名空间、模板、别名、嵌套类型、访问级别、重载、特殊成员函数、函数指针、数组、多声明、初始化表达式、原始偏移及取消行为；浏览器回归验证 C/C++ 面板入口和跳转。

后续如扩展跨文件索引，需另行设计 Web/Tauri 的目录授权、文件索引和语言服务接入；不能把当前本文件解析器描述成项目级语义索引。

### C/C++ 折叠与结构化缩进（2026-10-21）

编辑器使用 CodeMirror C/C++ Lezer 语法树提供花括号块折叠。`if (...) { ... } else { ... }` 中，首个分支的折叠范围在 `else` 前结束，保留 `else` 自己的行和 gutter 折叠入口；折叠首分支不能吞掉后续分支的控件或内容。`catch` 使用相同边界处理。格式错误源码由容错解析器处理，但只保证已识别的语法范围。

悬停 C/C++ 折叠占位符会打开只读 CodeMirror 预览，使用当前语言解析器及主题语法高亮，显示完整折叠源码并保留文本选择和滚动；预览按代码实际占用收缩，最大宽度为正文可视区的 3/4，最大高度为 1/2。超过上限时由内部滚动区承载，支持触控板横向及纵向滚动。点击占位符仍执行原有展开操作。滚动正文、窗口尺寸变化、占位符卸载或 Escape 会关闭预览。预览是独立只读视图，不替换编辑器正文、选区、折叠状态或撤销历史。

自动缩进命令分别支持当前选区和全文。C/C++ 按词法扫描花括号、圆括号和方括号层级并跳过注释、普通/原始字符串和预处理行；参考 Vim `cindent`，圆括号内的跨行参数和条件比开启行额外缩进两级（Tab Size 为 4 时是 8 列），方括号内的数组下标和普通代码块增加一级，同一行的嵌套括号不叠加续行缩进。闭合括号对齐开启行，后续语句恢复外层缩进；多行函数签名最后一行的参数缩进不传入函数体。类/结构体声明体内成员按类级缩进，访问标签与类体起始列对齐，类中的函数体再增加一级。它不依赖语法树恢复类作用域，因此暂时不完整的源码仍可整理缩进。选区命令读取全文上下文，只改选中行；连续执行结果稳定，遵循当前 Tab Size 和 Tab/空格偏好。其它语言使用 CodeMirror 语言缩进规则。修改作为一个可撤销编辑事务提交；只读、无有效选区或无需更改时不改正文。clang-format 的续行布局仍由所选风格或自定义配置决定。

自动缩进与“格式化全文”是两项独立操作；后者严格执行自定义 `.clang-format`。若希望 Tab Size 为 4 时函数参数续行多 8 列，配置 `ContinuationIndentWidth: 8` 和 `AlignAfterOpenBracket: false`；`UseTab: Always` 让可用 Tab 表示的续行对齐也采用 Tab。可导入[完整示例配置](examples/c-tab-continuation.clang-format)。不会在格式化后再次以缩进命令强行覆盖自定义布局。

源码符号大纲保留嵌套结构体的实例类型信息，例如 `struct B { ... } test;` 显示为 `test: struct B`。具名结构体的成员保持在该结构体下；匿名结构体若声明了实例（如 `struct { ... } C;`），成员归属在实例 `C` 下，避免错误提升到外层；真正没有实例名的匿名类型继续沿用外层作用域。点击成员仍按原始源码偏移定位，并可通过该实例节点折叠。

上述行为由 `e2e/source-folding.spec.ts`、`e2e/source-symbols.spec.ts`、`e2e/source-indentation.spec.ts` 和 `tests/source-symbols.test.ts` 覆盖。该解析器是单文件语法工具，不解析宏展开、条件编译结果或跨文件类型语义。

### C/C++ 代码格式化

源码工具栏提供“格式化全文”“格式化选区”和“代码格式风格”，原有自动缩进命令继续只调整缩进。macOS 原生 File 菜单的“源码整理”也可调用两项格式化命令。只读文档禁用执行；空选区禁用选区命令，多光标须先改为一个连续选区。

默认 LLVM，可选 Google、Chromium、Mozilla、WebKit、Microsoft、GNU。预设的 IndentWidth、TabWidth、UseTab 衔接当前 Tab Size 与 Tab/空格设置。选择“自定义 .clang-format”后，可粘贴 YAML/JSON 或选择配置文件；显式配置完全优先于缩进偏好。当前文档是虚拟文档，不自动遍历本机目录寻找项目配置；格式配置仅存于本机 `nr:source-formatting`，不写入正文或共享备份协议。配置无效时显示错误并保留原文。

YAML 格式支持 `#` 整行注释及空格后的行尾注释，例如 `IndentWidth: 4 # 缩进宽度`；注释随自定义配置原样保存，由 clang-format 自身解析，不用正则删除，避免损坏引号内的 `#`。不把 C/C++ 的 `//` 或 `/* ... */` 当作配置注释。

格式化器的 JS 异常可能只给出 `Invalid argument`，具体 YAML 诊断来自 stderr。独立 Worker 在初始化 WASM 前捕获自身的 `console.error`，保留最多 16 KiB 详细原因，附带未知配置项、非法数字、错误枚举值、语法片段及定位箭头；仅在片段能唯一匹配配置原文时补充行列，避免对重复行猜测。Worker 结果标识配置错误，前端在配置页的可滚动错误区持续展示；如果期间仍在编辑，只给出“查看错误”入口，不抢焦点。传输/加载/超时仍按一般执行失败提示，不误报为配置问题。

Web 和 Tauri 均使用固定版本 `@wasm-fmt/clang-format@23.1.1`，在按需启动的独立 module Worker 中运行。WASM 和 Worker 是本机同源资源，随生产 PWA 预缓存，无代码上传或系统工具安装；每次结束即释放 Worker。单次限制为 10 MiB UTF-8 正文、60 秒执行时间，失败和超时不修改正文。源码类型合并为 C/C++，格式化使用 `.cpp` 上下文。

选区以完整文件作为语法上下文，将 UTF-16 编辑器偏移转换为 UTF-8 字节范围后传给 clang-format。格式化器可能调整相邻完整语句、声明或预处理结构，不承诺严格只改选中字符。格式化整理布局，不进行编译或证明语义等价；语法不完整时由 clang-format 容错处理，报告失败则不应用结果。暂不执行保存时自动格式化。

返回结果优先以线性扫描识别空白变化，保留每个代码字符的对应位置；若涉及 include 排序等非空白变化，再使用有预算的通用差异算法。生成的 CodeMirror ChangeSet 映射选区、折叠及滚动快照，使用独立的一次撤销事务。应用前再次检查文档实例、内容修订、语言、读写状态及选区；执行期间输入、切换编辑状态或选区变化会丢弃过期结果。格式化接口仅接收源码、语言、配置和可选范围，为后续增加语言格式化 provider 保留边界，目前不开放外部插件注册。

成功产生修改后，下方提示提供“查看差异”；提示自动消失后仍可使用源码工具栏的“查看上次格式化差异”。居中的只读弹层展示格式化前/后原始源码、行号和增删背景，共用文档对比的有界逐行算法，相同行默认折叠，可展开；左右支持横向/纵向同步滚动，标题及关闭按钮固定。源码不经 Markdown 序列化，保留空白和特殊字符。查看差异不写正文或插入撤销记录。

点击省略行仅展开这一段相同内容，两侧同步。展开段左侧的三角与细竖线是可点击、可键盘聚焦的收起按钮；“显示相同行”复选框控制全部相同段，部分展开时显示混合状态。展开前置相同段时，以紧随其后的差异行为滚动锚点，让新展开的相同内容出现在它上方，保持差异行的位置；收起时若后续差异行可见，同样保留它的位置。全部开关优先保留可见差异行。在长段中部收起且后续差异行尚不可见时，将该段的折叠占位行保留在可视区顶部，不返回文档开头。末尾没有后续差异行的相同段保持该段顶部位置。上述操作同时保留横向位置。内容缩短到不足以维持原滚动位置时，受滚动区边界限制。这套交互与文档对比共用，修改折叠状态不写源码、不进入撤销历史。

快照仅在实际成功应用修改后创建；无变化、格式错误、超时或结果过期不覆盖原记录。以保留的源码会话为弱引用键，每份文档只存最近一次的前/后源码、风格、范围类型和时间，不持久化、不生成文档副本、不进入备份。切换文档不混用快照，保留实例内重新打开源码视图可继续查看；会话淘汰或应用重启后不保证保留。再次打开时核对当前正文与格式化后内容是否一致，编辑或撤销后明确标识“当前正文已变化”，不将历史快照当作实时差异。

### 源码换行缩进

非 Markdown/Flow 源码的 Enter 使用 `source-newline.ts`：优先执行 CodeMirror 原生换行与语言缩进，再对普通单换行补充当前行的手动缩进。语言建议缩进不大于原缩进时保留原始空格/Tab 前缀；语言要求更深缩进、匹配括号的双换行，以及当前行以闭合括号开始的退缩进，继续使用原生规则。修正合成为一次编辑事务，光标移动到继承缩进之后，支持多光标与撤销，不改写粘贴内容或其它行。Markdown/Flow 保留原有列表和引用续写规则。

### 行号与折叠

源码状态栏的“行号与折叠”菜单管理行号、相对行号、相对编号当前行的对齐方式、折叠图标显示和成对符号。编号显示直接读写系统的 `editor_show_line_numbers`，不再使用源码独立覆盖；行号隐藏时相对行号与对齐禁用，对齐要求相对行号开启，选择后菜单保留以方便预览。折叠标识共用系统已有配置，预置线条箭头、大小三角和两种加减号，正文与源码同步生效。源码折叠图标可见性使用同一工作区偏好，在系统设置与状态栏均可修改。编号展示插件接管时禁用对应内置选项。隐藏图标只撤下 gutter，保留独立的 CodeMirror 折叠状态和上方工具栏的折叠/展开能力，不改变正文。

展开的源码折叠区域在起始行显示展开标识，并在末尾行（例如 C/C++ 的闭合花括号）显示反向标识；点击任一端都折叠同一区域。嵌套层级循环复用文档树的六级路径色，并跟随默认或自定义路径配色。鼠标悬停任一端时，同色连接线在 fold gutter 内连接成对标识；长区域的另一端不在 CodeMirror 可视 DOM 内时，连接线裁切到 gutter 可视边界，不触发屏外 DOM 挂载或额外正文测量。连接线可设为实线、虚线、点线或不显示，并可选择 1–4px 宽度和 25%–100% 透明度；源码状态栏、编辑器设置与内置编号展示插件共用设备本地偏好。点击折叠或展开、以及滚轮或触控板开始滚动时立即撤下连接线及成对高亮，避免旧几何残留或随 gutter 内容移动。多个区域共用末尾行时，末端操作优先最近的内层。行号菜单按当前行计算包含它的折叠层级，可以折叠最近层，并跳到最近层或最外层的开始、末尾；跳转只移动选择与视口，不修改正文或折叠状态。

### Tab Size 与缩进方式

非 Markdown/Flow 的源码状态栏显示 Tab Size（2/4/8，默认 4）和缩进方式（Tab/空格，默认 Tab）。选项保存在本机工作区设置中，编辑器的 Tab 显示宽度、Tab 键缩进及语言换行缩进同步生效。既有其它 Tab Size 设置继续保留，不在打开文件时重写正文。Markdown/Flow 继续采用原有空格缩进与列表规则。

Tab Size 是纯显示设置：改变已有 Tab 的显示宽度并同步编辑器配置，不转换正文，因此只读数据库文档、磁盘文件和轻量只读预览均可使用。缩进方式才是内容转换入口：按当前 Tab Size 计算行首缩进的显示列数，再转换为目标空格或 Tab 加剩余空格，避免改变不足一个 Tab 的对齐。只转换行首缩进；行内空白和跨行字符串/注释的内容不变。依靠语法树识别跨行字面量，解析未完成时拒绝转换并提示重试。转换作为独立的编辑事务保存，可撤销；撤销正文转换不回退本机偏好设置。只读文档继续禁用缩进方式转换。
