# 本机版本历史

版本历史与编辑器撤销栈、GitHub 备份相互独立。Web 保存到 IndexedDB，Tauri 保存到 SQLite 的 note_versions 表。

## 快照与恢复

切换文档等会话边界、外部正文替换、指定正文修复和历史恢复会创建完整快照；自动保存的每次输入不都生成历史。普通快照最多保留 30 个。Web 与 Tauri 用相同规则比较正文、标题、标签、置顶及排序，跳过重复快照。

打开历史管理时先冲刷待保存编辑，再读取当前文档用于对比。恢复前再次保存编辑、留下当前快照，然后恢复历史。清理历史不会修改当前文档，也不重置编辑器撤销栈。

## 查看与清理

- 预览使用安全的只读内容组件，不自动加载外部资源；加密正文不自动解密。
- 与当前文档比较复用文档对比器，支持 Markdown、结构及属性比较、行号、相同行折叠和同步滚动。
- 多选删除或保留最近 1、3、5、10、20 个版本均需确认；取消不写入。
- 删除只针对指定文档及版本 ID，单次事务提交，不能误删其它文档历史。
- 容量仅为所选快照 JSON 的估算值，不包括数据库页、索引及独立图片；删除后数据库文件不一定立即缩小。
- 删除不可撤销。已有远端备份不受影响。普通文档历史不包含在现行备份中，加密历史随保护数据导出。

## 验证

IndexedDB 适配器测试验证去重、仅标题变化、跨文档误选保护和正文不变。Tauri 存储测试验证事务及文档范围约束和错误传播。浏览器测试覆盖预览、差异、取消删除、多选清理、保留最近版本和恢复前快照。
