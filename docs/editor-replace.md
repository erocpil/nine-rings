# 正文查找与替换

- 手机：编辑工具栏的 `⋯ → 查找与替换`；桌面宽工具栏提供查找图标入口。已有文档内查找栏也可展开“替换”。
- 仅作用于当前可编辑正文；只读时不提供替换操作，执行时再次检查编辑权限。不会批量更改其他文档或标题。
- 默认不区分大小写，可勾选“区分大小写”“全词匹配”“正则表达式（Perl）”；高亮与实际替换遵循同一选项。全词边界识别 Unicode 字母、数字、组合标记及下划线。替换模式和正则模式保留查询首尾空格，可查找连续空格；替换内容留空表示删除。
- 正则使用本地 PCRE2 WebAssembly 引擎，首次启用时按需加载；无需安装 Perl、不访问在线正则服务。直接填写表达式，不使用 `/…/` 分隔符。支持 `\bword\b`、`^word`、`word$`、`foo|bar`、`(?i)`、捕获组、后顾、`\K`、`\Q…\E` 等 Perl 兼容语法；`^` / `$` 默认按行匹配。仅匹配零宽位置的结果不计入高亮或替换，空表达式不搜索。PCRE2 不是完整 Perl 解释器，不执行嵌入的 Perl 代码。
- 正则替换支持 `$1`、`${name}`、`$<name>`、`$0` / `$&` 与 `$$`；普通文本替换保持字面量。渲染正文不跨结构边界替换或插入换行，源码查找则直接作用于 Markdown 原文，可跨行。无效表达式与超出回溯限制的匹配会显示错误，不沿用旧匹配结果。
- 单处替换后跳到下一处；全部替换基于一次文档快照，从后向前执行，避免位置偏移。替换文本包含原查询时不会循环替换新插入内容。
- 保留段落、标题、列表、表格、代码块等结构；不跨结构边界匹配。跨行内格式匹配时，新文本沿用第一个匹配字符的格式，周围文字格式不变。
- 全部替换是一个撤销步骤；面板提供“撤销替换”，也可用编辑器原有撤销操作。手动编辑和撤销后重新计算匹配。
- 查询、替换内容仅在当前编辑器内存中使用，切换文档清空，不进入全局搜索索引、收藏或备份元数据。
- 搜索面板从左侧展开，点击入口时同步聚焦以兼容 iOS 键盘唤起。查找上一处/下一处保持查找输入焦点，连续替换保持替换输入焦点；中文输入法确认候选词的 Enter 不触发导航或替换。

测试：`tests/unit/editor-replace.test.ts`、`tests/unit/search-highlights.test.ts`、`e2e/editor-replace.spec.ts`。覆盖格式保留、特殊字符、空格删除、Unicode 位置、跨块边界、一次撤销、只读限制和手机横竖屏。

## 全局搜索

全局搜索提供相同的三个选项，并可与路径、类型、概念筛选结合。默认普通搜索保持原有多关键词 AND 匹配；正则将整个输入视为一个表达式。搜索结果在原始文本上确定匹配范围后再截取片段，避免行首锚点或后顾被片段裁切改变。点击结果时把选项一起传递给正文定位；底部匹配计数旁的“×”取消高亮。加密正文继续不参与索引。搜索语法回归见 `tests/unit/search-matching.test.ts`、`e2e/search-options.spec.ts`。

打包时将 PCRE2 内嵌二进制提取为本地 `.wasm` 资源，按需加载并纳入 PWA 离线缓存；Tauri CSP 仅额外允许 WebAssembly 编译（`wasm-unsafe-eval`），不开放 JavaScript `unsafe-eval`。
