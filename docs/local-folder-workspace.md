# 本地文件夹工作区

状态：2026-10-24，前三阶段已在可信内置插件中接通：本地目录浏览、安全编辑保存、外部变化比较与恢复草稿，以及 Markdown、Mermaid、Flow 和授权根内相对资源预览。仍需在 macOS、Windows、Linux 与真实浏览器环境做交互验收；声明式插件包不具备任意文件读写能力。

## 现有入口与实现

在「设置 → 高级 → 启用插件功能」后，于插件列表开启「本地文件」（默认停用）。桌面活动栏提供独立入口；手机从文档树上方的文件夹按钮进入，沿用原抽屉。选择目录后按需展开，点击文件在中央区域打开。中央查看器复用文档源码模式的 CodeMirror、工具栏、状态栏、行号与折叠设置、查找、语法高亮、不可见字符和软换行；本地文件身份、保存目标和返回原视图仍由本地工作区负责。标题栏提供编辑/只读切换、保存、另存为、预览及重新读取。`⌘S` / `Ctrl+S` 保存到原文件；成功后更新磁盘版本基线，未保存编辑不进入文档数据库、搜索索引或 GitHub 备份。另存为优先使用系统/浏览器文件选择器，不支持时下载副本。源码符号、会话书签和同词匹配保留为标题栏下方、编辑区右侧的独立停靠区，宽度可拖动并在本机记忆，不跟随普通文档侧栏的左右位置。源码符号复用共享展示插件和主题语义色，折叠状态按文件保存在本机。标题栏仅显示一次文件名，悬停保留完整相对路径；只读时隐藏插入光标，保留文本选取，并高亮当前行和行号。UTF-8 文本上限 4 MiB，允许空文件；二进制、无效 UTF-8 与超限文件明确拒绝。

- Tauri 授权根保存在本机应用数据目录的 `local-file-roots.json`，与图片目录授权分离。选择目录、枚举、读取、统计、图片资源读取及写入通过独立 Rust 命令执行；写入只接受授权根 ID 和相对节点，拒绝根外路径、符号链接及 Windows reparse point。保存核对 SHA-256 版本，在目标同目录写临时文件、同步并替换，替换前再次核验版本。只读权限文件拒绝原位保存。普通文件系统没有通用跨进程 compare-and-swap，因此末次核验到替换之间仍有极小竞争窗口。
- Web 支持目录选择器时先请求读取权限，仅在用户点击保存时另行请求读写权限；写入使用浏览器目录句柄的 `createWritable()`，在提交前再检查版本。外部文件替换的原子性取决于浏览器实现。不支持目录选择器时使用目录快照；快照最多 10000 个文件，只能另存为，不能覆盖输入快照。
- 文件打开请求先经过现有中央视图保存门禁，再读取源文件；原数据库文档保留会话。文件来源不会创建文档，不进入搜索索引或 GitHub 备份。最近文件位置本机记忆，内存查看状态最多保留三份。
- 查看器每 3 秒检查文件大小和修改时间，并每 15 秒做一次哈希复核。干净会话检测到变化后自动重载并保留位置；脏会话显示双栏差异，可重载磁盘版、明确覆盖或另存副本。文件删除或权限失效时保留编辑内容并显示状态。
- 未保存内容每 500ms 暂存到独立 IndexedDB，最多保留 5 份草稿、单份 30 天，文件保存或用户选择重载后清除。离开查看器/停用时也会触发一次暂存。草稿不加密、不参与备份，可能包含敏感源码；用户通过保存或重载完成清理。
- 权限 `filesystem.files.read`、`filesystem.files.write` 与 `filesystem.images.read` 分离；读写能力只由可信内置插件声明，不对可安装声明式包开放。停用会撤销视图和分栏贡献、清理内存会话；异步操作返回前重查激活与授权代次。
- UTF-8 文本上限 4 MiB，保留 BOM 与统一 LF、CRLF 或 CR 换行。混合换行可编辑、比较和另存为，但原位保存会拒绝，避免静默统一换行。二进制、无效 UTF-8 与超限文件明确拒绝。

主要实现：`src/lib/local-files/`、`LocalFilesPanel.tsx`、`LocalFileView.tsx`、`MarkdownSourceEditor.tsx`、`builtin-local-files.ts`、`src-tauri/src/commands/local_files.rs`。本地文件仍使用独立会话和存储服务，不复用数据库文档写入接口。停靠区宽度、本地书签、未保存草稿属于设备本地状态，不进入文档备份；编辑器使用 LF 内部文本，统一换行在写入时还原。

验证入口：`tests/unit/local-files.test.ts`、`e2e/local-files.spec.ts` 和 Rust `commands::local_files::tests`。本次改动已通过 `npm run typecheck`、`npm run lint` 与本地隔离 Rust 工具链 `cargo check --offline`；没有运行单元测试或 E2E。仍需用真实目录授权验收 Tauri 保存、保存冲突、系统另存为，以及支持 File System Access API 的浏览器读写授权；模拟目录句柄不能代替真实权限验证。

### 文件树、菜单与恢复

- 文件树工具栏的放大镜开启文件名过滤，作用于已展开目录的直接文件，保留目录供继续展开；不递归扫描整个授权根。过滤与排序在分页前完成，首批 200 项之外的匹配仍可读取。
- 显示菜单提供名称升序、名称降序和文件类型排序，均保持目录优先；点号开头的隐藏条目默认隐藏，可手动显示。排序和隐藏偏好保存在本机。
- 分栏可见、窗口获得焦点时，每 5 秒检查可见的已展开目录；返回窗口或切回分栏时补查。只替换有变化的目录页，不清空树或重置展开状态，保留已加载分页范围；收起目录的后代不继续枚举。目录快照仍需重新选择才能反映磁盘变化。
- “在本地文件树中显示”会清除文件名过滤、按需显示隐藏条目、展开祖先目录并加载到目标所在页，再将目标滚动到可视区。定位不会打开或替换中央文件，也不会再次点击已打开分栏而将它收起。
- 目录和文件右键菜单支持复制路径、重命名与切换本机只读规则。Tauri 复制绝对路径，浏览器复制授权根名称加相对路径。目录规则向下继承，更深层路径可覆盖；不修改系统文件权限。重命名迁移位置、书签、查看设置和 tab 身份；受影响文件有未保存编辑时先要求保存。
- 退出时实际显示的本地文件会在下次启动恢复；只在树中选中过的旧文件不抢占随后打开的数据库文档。恢复入口只执行一次，后台树刷新不会重新打开旧文件。本地 tab 独立记忆顺序、支持重排和双击关闭，激活已有 tab 不移动其位置。

本批交互验收由用户执行，自动化测试尚未运行。重点检查首屏以外文件的过滤与定位、外部增删后的树连续性、隐藏目录的定位，以及改变排序后快速展开和分页时不被旧请求覆盖。

## 目标与定位

在现有数据库文档工作区之外，提供可选的「本地文件夹工作区」：用户选择一个目录，通过文件树浏览文件，在中央编辑区编辑原文件并保存回磁盘。适用于代码阅读、小规模源码修改、技术文档目录和本地笔记库。首期不演进为完整 IDE，不引入工程构建、调试器、clangd 或跨文件语义索引。

数据库文档与磁盘文件是两类资源。打开文件不是导入，不自动生成数据库文档，也不将整个目录纳入现有 GitHub 备份。需要导入、导出或备份时使用独立的显式操作。已有 P.A.R.A. 文档树、保护机制和同步行为继续由现有工作区管理。

## 宿主与插件分工

采用「宿主文件服务 + 文件会话 + 插件分栏与命令」的组合，可以先作为一个可信内置插件交付，再按需要拆出展示扩展。避免为每个插件实现一套读写与冲突处理。

| 层次 | 职责 | 边界 |
| --- | --- | --- |
| 宿主文件服务 | 目录选择、授权、枚举、读取、校验后保存、变化监听 | 不向插件暴露任意绝对路径读写或通用原生命令 |
| 宿主文件会话 | 原始文本、脏状态、撤销、保存回执、冲突、位置恢复 | 不套用数据库文档保存接口，不以展示缓存作为内容权威 |
| 文件夹分栏插件 | 文件树、过滤、排序、图标、菜单与打开命令 | 复用分栏固定/悬停、宽度、移动端抽屉和资源生命周期 |
| 编辑与预览适配器 | 中央区域打开文件，复用源码编辑、符号、同词匹配等能力 | 先明确文件资源身份与保存目标，再复用编辑器组件 |
| 后续可选插件 | 目录搜索、Git 状态、工程导航等 | 分别申请能力，不作为首期完成条件 |

现有[图片目录服务](plugin-local-image-panel.md)可借鉴授权根、相对节点、按需枚举与监听生命周期；不能直接扩大图片只读权限来取得文本写入权。[主区域视图贡献](plugin-main-area-views.md)可复用导航和保存门禁，但现有 image/vocabulary renderer 不等于可编辑文件会话，需要新增明确契约。[插件体系](plugin-system-design.md)继续约束所有权、撤销和异步结果代次。

## 资源与保存契约

以下是当前内置宿主实现契约，不是开放给第三方的 API：

- 文件身份使用来源类型、授权根 ID 和根内相对节点 ID，与数据库文档 ID 区分；路径改变不能继续假定旧身份有效。
- 按目录分页枚举，展开时读取；默认不扫描整个目录，不解析所有文件正文。隐藏文件、大目录和二进制文件提供明确策略，限制并发与缓存。
- 读取返回原始文本、编码/BOM、换行方式及文件版本凭据。当前支持 UTF-8；其它编码或二进制明确提示，不以替换字符读入后直接覆盖。
- 保存携带预期版本凭据；宿主核验磁盘当前版本，再按平台能力使用安全替换策略。记录写入回执，不仅以界面脏标记清除判断成功。时间戳和大小只能快速筛查，必要时使用内容摘要；普通文件系统不能承诺跨进程比较并交换的绝对原子性。
- 外部变化：未修改的会话可重读并保持位置；存在未保存编辑时提示比较、重载或明确覆盖，不静默丢弃任一方。删除、移动、权限变化与监听丢失分别报告。
- 停用插件或撤销目录授权前先处理未保存会话；保存失败或用户取消时保留内容与恢复入口。撤权后不继续写入，迟到的异步结果不能重开旧资源。
- 原文、位置和本机授权分开保存。目录授权和绝对路径不进入共享备份；崩溃恢复草稿若落本机，须明确保留周期、敏感内容及清理规则，不能悄悄当成普通文档同步。

磁盘文件以源码模式为编辑入口。Markdown、Mermaid、Flow 预览从当前源码派生；相对 Markdown 链接与常见图片路径相对当前文件解析，并通过同一授权根校验，拒绝越界读取。相对图片目前限制 PNG/JPEG/GIF/WebP/SVG/AVIF、单文件不超过 20 MiB。渲染预览暂不支持可视化编辑回写 Markdown。

## 平台与权限

| 平台 | 计划路径 | 限制与回退 |
| --- | --- | --- |
| macOS / Windows / Linux Tauri | 宿主选择目录并签发作用域句柄，Rust 服务执行文件操作 | 每次读写复核授权根及路径边界；处理符号链接、Windows reparse point、大小写和权限差异 |
| Web | 能力检测后使用用户授权的目录/文件句柄 | 读与写分别确认；重启可能需重新授权，不承诺所有浏览器支持直接保存 |
| 缺少目录写入能力的浏览器与手机 | 选择文件、查看或导出副本 | 明确标为快照或副本，不显示已保存回原文件 |

浏览器写入和另存为能力仍以运行时特性检测为准；缺少文件系统访问 API 时提供副本下载。文件变化通过 stat 轮询与周期性内容摘要复核，而非实时系统事件。首期不自动安装外部工具，不改变系统工具链；Flutter 与 iOS Tauri 的新适配不纳入这一阶段。

插件读写能力分开，并绑定当前激活身份；目前写权限只由可信内置本地文件插件使用。当前可安装的声明式数据包不执行代码，不能因增加此功能而默许第三方脚本获得文件系统权限。

## 分阶段推进

1. **只读入口（已接通）。** Tauri 授权目录、分页文件树、源码打开、资源身份与中央区域导航；复用现有符号和查找展示。
2. **安全编辑（已接通，待真实环境验收）。** UTF-8/BOM/统一换行、版本核验保存、另存为、脏状态、外部变更比较、IndexedDB 恢复草稿与权限失效回退。离开查看器前会尽力先暂存恢复草稿。
3. **预览与平台（已接通，待权限验收）。** Markdown、Mermaid、Flow 预览、授权根内相对链接和图片资源、Web 目录句柄写权限及回退。
4. **按需求扩展插件（持续推进）。** 已接入文件名过滤、排序、隐藏条目、目录增删检测和重命名。后续为文件/目录创建、移动、删除到回收站、目录全文搜索、未保存会话汇总及按需 Git 状态；分别设计确认、恢复及会话身份迁移。

## 验收重点

- 打开、切换、关闭与重启恢复：文件和数据库文档身份不串用，撤销与阅读位置保持，未保存内容不被导航或停用丢弃。
- 保存保真：UTF-8/BOM、LF/CRLF、空文件、尾部换行、大文件；不支持编码、只读文件及磁盘写入失败应明确失败。
- 并发变化：外部编辑/删除/重命名、保存期间变化、监听事件风暴和断开授权；覆盖必须明确，陈旧结果不写入新会话。
- 安全边界：路径穿越、根外符号链接、授权撤销、插件重启代次、浏览器拒绝写入；未授权读取和写入均被宿主拒绝。
- 性能与平台：按需加载、目录树缓存、后台任务取消、触摸操作；浏览器模拟测试与原生文件选择、真实磁盘保存分别验证。

已确定：支持 UTF-8、4 MiB 文本、BOM 与统一换行；恢复草稿保存在本机 IndexedDB，最多 5 份、每份 30 天，不加密且不备份；外部变化通过 stat 轮询并定期做哈希复核；停用时尽力暂存草稿。后续验收重点是 macOS、Windows、Linux 的实际替换行为、浏览器权限续期、混合换行提示及外部编辑竞争场景。
