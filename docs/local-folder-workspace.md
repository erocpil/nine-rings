# 本地文件夹工作区

状态：2026-10-23，第一阶段只读入口已实现，后续写入与扩展仍为规划。本文记录打开磁盘目录、浏览和直接编辑其中源文件的方向；现有声明式插件包不具备任意文件读写能力。

## 第一阶段使用与实现

在「设置 → 高级 → 启用插件功能」后，于插件列表开启「本地文件」（默认停用）。桌面活动栏提供独立入口；手机从文档树上方的文件夹按钮进入，沿用原抽屉。选择目录后按需展开，点击文件在中央区域只读打开。中央查看器直接复用文档源码模式的 CodeMirror、工具栏、状态栏、行号与折叠设置、查找、语法高亮、不可见字符和软换行；本地文件身份、重新读取和返回原视图仍由本地工作区负责。源码符号、会话书签和同词匹配保留为标题栏下方、编辑区右侧的独立停靠区，宽度可拖动并在本机记忆，不跟随普通文档侧栏的左右位置。源码符号复用共享展示插件和主题语义色，层级三角及 `−`/`+` 支持逐项或全部折叠/展开，折叠状态按文件保存在本机。标题栏仅显示一次文件名，悬停保留完整相对路径；查看器不单独提供专注按钮，也不重复放置查找按钮，只读时隐藏原生及绘制插入光标，保留文本选取，并高亮当前行和行号。UTF-8 文本上限 4 MiB，允许空文件；二进制、无效 UTF-8 与超限文件明确拒绝。

- Tauri 授权根保存在本机应用数据目录的 `local-file-roots.json`，与图片目录授权分离。选择目录、枚举及读取通过独立 Rust 命令执行；只接受授权根 ID 和相对节点，拒绝根外路径、符号链接及 Windows reparse point。目录读取在后台线程执行；单目录最多 10000 项，每页 200 项，不递归遍历。
- Web 支持目录选择器时仅请求读取权限；不支持时使用目录快照。两种来源都仅保留本次会话，刷新需重选。目录快照最多 10000 个文件，不宣称保存回原文件。
- 文件打开请求先经过现有中央视图保存门禁，再读取源文件；原数据库文档保留会话。文件来源不会创建文档，不进入搜索索引、文档 tab 或 GitHub 备份。分栏隐藏和切换保留目录展开及列表，最近三份文件在本次会话缓存源码查看状态；重启恢复文件位置尚未实现。
- 刷新按钮重读已展开目录，查看器可重新读取当前文件。外部文件变化暂不自动监听，不提供写入、创建、重命名、移动或删除；「移除目录」只撤销授权。撤销或停用会丢弃对应的查看缓存并返回原视图。
- 权限 `filesystem.files.read` 与 `filesystem.images.read` 分离；它是可信内置宿主能力，不对可安装声明式包开放。停用会撤销视图和分栏贡献，异步读取返回前再次检查激活与授权代次。

主要实现：`src/lib/local-files/`、`LocalFilesPanel.tsx`、`LocalFileView.tsx`、`MarkdownSourceEditor.tsx`、`builtin-local-files.ts`、`src-tauri/src/commands/local_files.rs`。中央查看器复用完整源码编辑表面与宿主源码高亮、同词高亮及符号解析，但保持只读且不复用数据库文档写入接口。停靠区宽度及本地书签属于设备本地状态，不进入文档备份；符号位置按查看器统一换行后的文本计算，避免 CRLF 导致偏移。

验证入口：`tests/unit/local-files.test.ts`、`e2e/local-files.spec.ts` 和 Rust `commands::local_files::tests`。本批验证通过：`npm test`、211 份 Vitest 测试文件（2407 项）、Rust 库测试（74 通过、1 项既有忽略）、Chromium 新入口 2 项、WebKit 新入口及图片分栏回归 3 项，以及类型、Lint、IPC 契约与生产构建检查。浏览器模拟目录句柄验证导航流程，不能替代系统目录选择器、跨平台真实磁盘及权限验收。

## 目标与定位

在现有数据库文档工作区之外，提供可选的「本地文件夹工作区」：用户选择一个目录，通过文件树浏览文件，在中央编辑区编辑原文件并保存回磁盘。适用于代码阅读、小规模源码修改、技术文档目录和本地笔记库。首期不演进为完整 IDE，不引入工程构建、调试器、clangd 或跨文件语义索引。

数据库文档与磁盘文件是两类资源。打开文件不是导入，不自动生成数据库文档，也不将整个目录纳入现有 GitHub 备份。需要导入、导出或备份时使用独立的显式操作。已有 P.A.R.A. 文档树、保护机制和同步行为继续由现有工作区管理。

## 宿主与插件分工

采用「宿主文件服务 + 文件会话 + 插件分栏与命令」的组合，可以先作为一个可信内置插件交付，再按需要拆出展示扩展。避免为每个插件实现一套读写与冲突处理。

| 层次 | 职责 | 边界 |
| --- | --- | --- |
| 宿主文件服务 | 目录选择、授权、枚举、读取、校验后保存、变化监听 | 不向插件暴露任意绝对路径读写或通用原生命令 |
| 宿主文件会话 | 原始文本、脏状态、撤销、保存回执、冲突、位置恢复 | 不套用数据库文档保存接口，不以展示缓存作为内容权威 |
| 文件夹分栏插件 | 文件树、过滤、排序、图标、菜单与打开命令 | 复用分栏固定/悬停、宽度、移动端抽屉和资源生命周期 |
| 编辑与预览适配器 | 中央区域打开文件，复用源码编辑、符号、同词匹配等能力 | 先明确文件资源身份与保存目标，再复用编辑器组件 |
| 后续可选插件 | 目录搜索、Git 状态、工程导航等 | 分别申请能力，不作为首期完成条件 |

现有[图片目录服务](plugin-local-image-panel.md)可借鉴授权根、相对节点、按需枚举与监听生命周期；不能直接扩大图片只读权限来取得文本写入权。[主区域视图贡献](plugin-main-area-views.md)可复用导航和保存门禁，但现有 image/vocabulary renderer 不等于可编辑文件会话，需要新增明确契约。[插件体系](plugin-system-design.md)继续约束所有权、撤销和异步结果代次。

## 资源与保存契约

以下是待实现的语义，不是已发布 API：

- 文件身份使用来源类型、授权根 ID 和根内相对节点 ID，与数据库文档 ID 区分；路径改变不能继续假定旧身份有效。
- 按目录分页枚举，展开时读取；默认不扫描整个目录，不解析所有文件正文。隐藏文件、大目录和二进制文件提供明确策略，限制并发与缓存。
- 读取返回原始文本、编码/BOM、换行方式及文件版本凭据。首期优先 UTF-8；其它编码或二进制明确提示，不以替换字符读入后直接覆盖。
- 保存携带预期版本凭据；宿主核验磁盘当前版本，再按平台能力使用安全替换策略。记录写入回执，不仅以界面脏标记清除判断成功。时间戳和大小只能快速筛查，必要时使用内容摘要；普通文件系统不能承诺跨进程比较并交换的绝对原子性。
- 外部变化：未修改的会话可重读并保持位置；存在未保存编辑时提示比较、重载或明确覆盖，不静默丢弃任一方。删除、移动、权限变化与监听丢失分别报告。
- 停用插件或撤销目录授权前先处理未保存会话；保存失败或用户取消时保留内容与恢复入口。撤权后不继续写入，迟到的异步结果不能重开旧资源。
- 原文、位置和本机授权分开保存。目录授权和绝对路径不进入共享备份；崩溃恢复草稿若落本机，须明确保留周期、敏感内容及清理规则，不能悄悄当成普通文档同步。

磁盘文件首期以源码模式为编辑入口，保证文本保真。Markdown、Mermaid、Flow 的只读预览可由原文派生；可视化编辑回写 Markdown 要独立验证语法往返，不能借此承诺字节级无损。相对链接与图片应相对当前文件解析，并通过同一授权根校验，禁止越界读取。

## 平台与权限

| 平台 | 计划路径 | 限制与回退 |
| --- | --- | --- |
| macOS / Windows / Linux Tauri | 宿主选择目录并签发作用域句柄，Rust 服务执行文件操作 | 每次读写复核授权根及路径边界；处理符号链接、Windows reparse point、大小写和权限差异 |
| Web | 能力检测后使用用户授权的目录/文件句柄 | 读与写分别确认；重启可能需重新授权，不承诺所有浏览器支持直接保存 |
| 缺少目录写入能力的浏览器与手机 | 选择文件、查看或导出副本 | 明确标为快照或副本，不显示已保存回原文件 |

具体 API 和浏览器支持情况须在实现时核验。首期不自动安装外部工具，不改变系统工具链；Flutter 与 iOS Tauri 的新适配不纳入这一阶段。

插件读写能力应分开，按用户选定根授权，并绑定当前激活身份；权限名称和 SDK schema 在实现时确定。当前可安装的声明式数据包不执行代码，不能因增加该功能而默许第三方脚本获得文件系统权限。

## 分阶段推进

1. **先建立只读入口（已接通）。** Tauri 授权目录、分页文件树、源码打开、资源身份与中央区域导航；复用现有符号和查找展示，验证不会污染数据库文档或备份。
2. **再支持安全编辑。** 文件会话、编码与换行保留、保存/另存为、脏状态、外部变更比较、退出与停用门禁、异常恢复。完成后才将入口描述为可编辑工作区。
3. **扩展预览与平台。** 接入 Markdown 等预览、相对资源解析、Web 能力适配及权限失效回退；根据实测优化大目录和大文件性能。
4. **按需求扩展插件。** 搜索、Git 状态、更多树展示配置；文件创建、重命名、移动和删除分别设计确认、恢复及会话身份迁移，不与首期浏览入口捆绑。

## 验收重点

- 打开、切换、关闭与重启恢复：文件和数据库文档身份不串用，撤销与阅读位置保持，未保存内容不被导航或停用丢弃。
- 保存保真：UTF-8/BOM、LF/CRLF、空文件、尾部换行、大文件；不支持编码、只读文件及磁盘写入失败应明确失败。
- 并发变化：外部编辑/删除/重命名、保存期间变化、监听事件风暴和断开授权；覆盖必须明确，陈旧结果不写入新会话。
- 安全边界：路径穿越、根外符号链接、授权撤销、插件重启代次、浏览器拒绝写入；未授权读取和写入均被宿主拒绝。
- 性能与平台：按需加载、目录树缓存、后台任务取消、触摸操作；浏览器模拟测试与原生文件选择、真实磁盘保存分别验证。

实现前还需确定：首期支持的文件大小与编码范围、本机恢复草稿策略、文件监听降级方式，以及插件停用时未保存文件的保留界面。这些决定应进入实现契约和测试，不能只在插件 UI 中约定。
