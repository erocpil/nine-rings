# 编辑内容权威模型与块工作区协议

## 已确定的模型

- **持久化与跨端交换：Quill Delta。** 数据库、备份、Flutter 与同步继续使用既有 Delta 契约，本轮不迁移数据库格式。
- **活动编辑会话：主 ProseMirror EditorState.doc。** 它是本地当前编辑内容的唯一写入权威，也拥有唯一的撤销历史。保存生成这个不可变文档快照的 Delta 投影，保存回执或界面偏好更新不反向覆盖活动会话。
- **派生视图：只读虚拟视图、块工作区 ProseMirror 和 CodeMirror。** 这些视图不能独立保存整份文档；输入必须经过主编辑器事务。缓存只是可丢弃的投影。
- **Markdown：导入导出格式。** 不承诺原始空格、围栏或不受支持格式的逐字往返。历史 PM JSON 只在读取边界兼容。

共享入口 editorDocumentFromContent 用于完整编辑器和只读视图的结构转换。遇到只读渲染器无法表达的节点/标记，保留回退完整编辑器的机制。现有 Delta 字号映射等损耗仍需后续独立兼容性设计；本轮不增加跨端不识别的属性。

## 块同步协议

1. 打开工作区时记录目标位置与不可变块快照。每次源事务映射目标位置；目标被删除/替换为其他块时使工作区失效。
2. 主文档其他位置的编辑不使目标基线失效。目标内容变化时向局部视图同步，局部应用不进入第二套撤销历史。
3. 局部 ProseMirror 提交必须同时匹配当前源块和局部事务的 before 快照；转换到源 schema 后再比较，避免不同 schema 对象身份导致误判。
4. 先完整构造并校验事务，再一次性提交；最终文档必须等价于只替换目标块，禁止改写相邻块。
5. CodeMirror 提交携带输入前的文本基线。基线过期时暂停写回，保留草稿，用户可复制或明确放弃草稿并重新载入源内容。冲突未解决前不能关闭或导航丢弃草稿。
6. 原文只读、保存失败等既有保护继续生效；导航和关闭仍等待主编辑器保存冲刷。

## 渲染复用与挂载策略

- 引用块工具栏、预览标题及触摸折叠处理由编辑与虚拟只读视图共同使用。
- 代码块语言、简介、折叠、换行、Mermaid 模式的解释集中于共享显示模型；阅读覆盖值不改写传入内容。
- 两条路径共用延迟 Mermaid 容器，在距离可视区约 800px 时启动；已加载图形保持挂载，避免滚动时高度跳变。
- 全文代码块共用一个 IntersectionObserver。屏外或折叠状态不创建行号测量用的 ResizeObserver/MutationObserver；回到可视区域后重新测量。
- 保留完整 ProseMirror contentDOM，以保证跨块选区、复制、输入法和撤销。正文 DOM 虚拟化、表格/图片的挂载重构和增量 Delta 保存不在本轮引入。

## 验证

单元测试覆盖跨 schema 映射、相邻块保护、目标基线过期、块前插入位置映射、内容转换和共享显示规则。
浏览器回归覆盖实际块编辑、撤销、外部替换、CodeMirror 基线冲突草稿、只读入口、Mermaid 可视区挂载和手机交互。

### 本轮验证结果与遗留项

- 12 项模型/同步/只读单元测试通过。
- Chromium 针对性用例验证了块编辑、共享撤销、草稿冲突恢复、只读切换及两类屏外挂载策略。
- WebKit 18 项组合回归通过（Chromium 专用触摸注入用例跳过），覆盖 Mermaid、块工作区和虚拟只读视图。
- 后续已修复 readonly-rendering.spec.ts 的 4 个历史导航用例：更新目录、书签及关闭按钮的可访问名称；按可视视口验证上半区打开阅读侧栏、下半区打开设置；验证完整编辑器切换到局部阅读时保留书签固定状态，再收起并重新打开。保留 1500 块末章折叠与回退、窗口外书签跳转、跨窗口选区及触屏双击的原有断言。该文件全部 7 项用例已分别在 Chromium 和 WebKit 验证通过。
- 真实 iPhone PWA/macOS Tauri 输入法与性能仍需真机验收；本轮不宣称已完成全文编辑虚拟化或所有格式的无损映射。
