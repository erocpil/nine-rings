# 编辑内容权威模型与块工作区协议

当前系统设计入口见[关键设计总览](current-design.md)。本文的验证数量与日期是对应批次记录，不是最新完整回归状态。插件草案中的统一修订协议目前仅接入自动保存批次与确认水位，视图/选区和完整会话生命周期仍待实现，不替代本文既有会话边界。

## 已确定的模型

- **持久化与跨端交换：Quill Delta。** 数据库、备份、Flutter 与同步继续使用既有 Delta 契约，本轮不迁移数据库格式。
- **富文本活动编辑会话：主 ProseMirror EditorState.doc。** 它是本地当前富文本内容的唯一写入权威，块工作区的编辑统一进入主会话撤销历史。保存生成不可变文档快照的 Delta 投影，保存回执或界面偏好更新不反向覆盖活动会话。整篇源码模式拥有独立历史，尚未跨视图共享撤销。
- **富文本派生视图：只读虚拟视图、块工作区 ProseMirror 和块工作区 CodeMirror。** 这些视图不能独立保存整份文档；输入必须经过主编辑器事务。缓存只是可丢弃的投影。
- **Markdown 源码会话：CodeMirror 文本与 SourceNavigationSession。** 当前源码是本会话的编辑依据，解析模型、目录和并排预览均为派生结果，经既有保存入口投影为 Delta。仅切换视图保留原始源码；富文本实际修改后使旧源码缓存失效。不承诺任意富文本格式的 Markdown 无损往返，也不混合两种编辑器的撤销历史。历史 PM JSON 只在读取边界兼容。

共享入口 editorDocumentFromContent 用于完整编辑器和只读视图的结构转换。遇到只读渲染器无法表达的节点/标记，保留回退完整编辑器的机制。现有 Delta 字号映射等损耗仍需后续独立兼容性设计；本轮不增加跨端不识别的属性。

## 块同步协议

1. 打开工作区时记录目标位置与不可变块快照。每次源事务映射目标位置；目标被删除/替换为其他块时使工作区失效。
2. 主文档其他位置的编辑不使目标基线失效。目标内容变化时向局部视图同步，局部应用不进入第二套撤销历史。
3. 局部 ProseMirror 提交必须同时匹配当前源块和局部事务的 before 快照；转换到源 schema 后再比较，避免不同 schema 对象身份导致误判。
4. 先完整构造并校验事务，再一次性提交；最终文档必须等价于只替换目标块，禁止改写相邻块。
5. CodeMirror 提交携带输入前的文本基线。基线过期时暂停写回，保留草稿，用户可复制或明确放弃草稿并重新载入源内容。冲突未解决前不能关闭或导航丢弃草稿。
6. 原文只读、保存失败等既有保护继续生效；导航和关闭仍等待主编辑器保存冲刷。

## 渲染复用与挂载策略

- 普通文档最多保留三个完整编辑会话（最近使用优先）。进入工作区首页不清空当前文档；首页是独立展示状态。离开当前文档时将其 DOM 移出活动页面，保留组件、ProseMirror/CodeMirror 状态和撤销历史；打开第四份时释放最久未访问项。
- 后台会话不响应导航或全局查找，不用隐藏期间的几何数据覆盖阅读位置；写入回调检查当前文档 ID。自动保存回执更新会话版本；再次打开时版本不匹配或收到其他窗口的修改通知，丢弃旧会话。加密文档保持离开即锁定，不保留解锁后的后台会话。缓存仅在本次应用运行中有效，持久化仍经过原有保存边界。

- 引用块工具栏、预览标题及触摸折叠处理由编辑与虚拟只读视图共同使用。
- 代码块语言、简介、折叠、换行、Mermaid 模式的解释集中于共享显示模型；阅读覆盖值不改写传入内容。
- 两条路径共用延迟 Mermaid 容器，在距离可视区约 800px 时启动；已加载图形保持挂载，避免滚动时高度跳变。
- 全文代码块共用一个 IntersectionObserver。屏外或折叠状态不创建行号测量用的 ResizeObserver/MutationObserver；回到可视区域后重新测量。
- 保留完整 ProseMirror contentDOM，以保证跨块选区、复制、输入法和撤销。正文 DOM 虚拟化、表格/图片的挂载重构和增量 Delta 保存不在本轮引入。
- 目录三角按标题树判断：仅下一条标题级别更深的条目显示三角，包含跳级标题；叶子标题仍可跳转。正文章节三角独立按是否有下属块判断，保留只有正文的章节折叠。
- 只读专注模式在可折叠章节的第二次鼠标按下时阻止原生选词，确认双击后清除残留选区，保留第一次按下、拖选与复制，以及链接、按钮等独立交互。只读双击折叠后的帧校正及 100ms 延迟校正属于当前操作；新手势、导航、文档或模式切换及卸载取消旧校正，不覆盖用户的下一次阅读位置。

## 验证

### 自动目录、标题跳转与独立块排版（2026-10-09）

`/toc` 空格/Enter 创建 `language: toc` 的围栏块，模型只存 `levels: 1,2,3` 等配置。React 节点视图、局部只读和源码预览共用 `TableOfContentsBlock`，通过各视图的目录上下文读取当前完整标题列表及导航回调；不会读取 DOM 临时标题或写回生成列表。块视图内直接调用导航，避免依赖 React portal 外层点击捕获。普通 `#标题` 链接按完整标题解析，局部只读能力门及链接渲染允许同文档片段，脚注专用导航保持优先。

H1～H6 独立字号及代码/引用/Mermaid/flow 块字体、字号通过 AppConfig 持久化，Web 和 Rust 配置默认值一致，并加入排版草稿、应用、取消与恢复默认流程。字号 0、字体 default 不输出覆盖变量，保留原有风格/手机响应式字号与代码等宽字体。Mermaid 字体传入串行渲染器，在布局前计算文字尺寸，避免仅修改成品 SVG 导致节点溢出；字体上下文按设置值记忆化，普通主题/滚动变化不触发重绘。代码行号继续按实际字体测量。行内代码与工具栏不随块字体设置变化。

### 设置预览与源码同步滚动（2026-10-09）

桌面设置外部点击不关闭；在背景遮罩上按住鼠标左键时整层透明，指针捕获保证松开、取消捕获或失焦后恢复。遮罩仍拦截点击，避免预览手势误操作正文，关闭按钮与 Escape 保留；手机沿用外部点击关闭。

源码和预览在同一次 scroll 事件中更新对侧 scrollTop，不再等待下一帧或 CodeMirror 异步位置测量。按源码块与预览块的实际坐标建立分段连续映射，首尾对应；布局变化才重新测量，滚动不重复查询全文 DOM。两侧排版高度不同，语义位置保持对应，不能保证所有内容拥有相同像素位移或浏览器合成帧绝对一致。预览内容解析仍合并 220ms 内的输入，与滚动同步机制分开。

### 桌面链接与脚注气泡（2026-10-09）

编辑、完整只读、局部只读及 Markdown 源码并排预览复用 `useDocumentHoverPreview`。桌面细指针悬停正文链接时显示原始 `href`，包括外部网址、相对 Markdown 路径及内部文档链接；脚注引用优先显示脚注正文，返回箭头不生成链接气泡。预览不访问网络、不读取目标文档、不改变原有跳转或右键菜单行为。只读链接支持焦点预览，编辑模式保留 contenteditable 的光标与 Tab 行为。

气泡使用统一主题变量和脚注样式，长地址换行，按可视窗口限制位置，底部空间不足时放到链接上方。鼠标离开、焦点移出、滚动、点击、键盘操作、窗口失焦或尺寸变化时关闭，避免缓存会话和布局变化残留气泡。手机及触屏指针不启用悬停预览。实现不按 OS 或 CPU 架构区分，桌面 Web 与 Tauri 共用。

单元测试覆盖跨 schema 映射、相邻块保护、目标基线过期、块前插入位置映射、内容转换和共享显示规则。
浏览器回归覆盖实际块编辑、撤销、外部替换、CodeMirror 基线冲突草稿、只读入口、Mermaid 可视区挂载和手机交互。

## 增量转换与移动输入（2026-09-25）

- 每个富文本会话持有 IncrementalDocumentSerializer，以不可变顶层节点身份为缓存键，同时缓存 JSON 与 Delta；修改、撤销、插入删除均通过节点身份失效。WeakMap 不额外保留废弃的文档版本。
- 保存仍组装完整 Delta 并调用原有数据库接口，扫描及数组组装仍为 O(n)。一个大列表仍是一个转换单元，不宣称已实现增量持久化或增量网络同步。
- MobileInputSession 区分点按、阅读拖动、选区、IME 组合、输入与显式导航。正文保留原生选区确认和视觉视口协调，源码通过 CodeMirror scrollHandler 抑制不合时宜的自动滚动；只读原生选择不被接管。
- 浏览器模拟键盘/组合事件回归不代替 iOS、Android 和 Tauri 原生输入法真机验收。


## 自动保存队列边界（2026-10-10）

渲染和源码视图继续共用 `useAutoSave`，实际写入调度由 `AutoSaveQueue` 负责。登记正文仍保存延迟读取函数；入队时执行一次全文读取并深复制 Delta、标题和标签，避免文档切换或后续数组修改改变已经排队的快照。持久化仍是完整 Delta，不改变数据库、备份或 Flutter 格式。

队列尾部只负责串行调度，可以恢复失败以允许下一次写入；等待保存的调用方必须等待实际任务的成功或失败。对正在保存的文档再次 flush 不能等待吞掉错误的尾部。退出、更新和页面隐藏的 flush 包含全部待保存文档，失败的后台文档也保留可重试的数据。切换活动文档按该文档真实 dirty/saving/error 状态恢复，不重置为 clean。浏览器关闭事件仍不能保证异步写入完成。

失败批次按字段计数保留重试值，较新的待保存或已排队字段优先；这些计数仅用于重试保护，**不是**插件的文档修订号。明确放弃会跳过尚未执行的旧快照，不恢复旧失败数据；已经进入存储层的写入不能由队列撤销。统一文档代次、修订令牌、成功确认水位与外部替换的屏障仍待 R3/R4 接入，不能据本批宣称插件 `whenSaved` 已实现。


## 保存修订与确认水位基础（2026-10-10）

`DocumentSaveRevisions` 在自动保存流内为正文、标题和标签的接受批次登记同一逻辑修订，不使用时间戳或字段重试计数作为文档版本。PM 正文更新与同一文档快照的书签/引用位置重映射共用批次，只计一次；独立书签/引用元数据操作计为新修订。源码接受一次编辑（包括撤销/重做）登记一次；视图投影、选择和保存回显不登记。包装层保留批次与 metadataOnly 参数，避免丢失语义。批次使用 WeakMap，不额外保留被淘汰文档的 PM 树。

入队快照记录内部宿主签发的不可变修订对象和各字段接受水位；仅成功的实际写入确认快照中包含的字段，全部前序字段得到覆盖后才前移文档确认水位。一个较新正文快照不能替先前失败的标题确认保存。`whenSaved` 针对指定文档，允许后续编辑状态覆盖原目标；写入失败返回 SAVE_FAILED，重复调用是显式重试；取消只停止等待，不撤销已经接受的持久化任务。明确放弃/接受外部更新立即使旧目标和等待返回 STALE_REVISION，迟到旧写入不能推进新代次的确认。

令牌对象通过宿主 WeakMap 身份校验；跨文档、跨队列或从 JSON 重建均拒绝。它是内部契约，尚未通过插件 SDK 暴露，未来 R6 必须将字符串线协议映射到宿主签发的对象与激活代次。本批未覆盖全部属性更新、会话淘汰/所有重载换代或视图/选区代次，R3/R4 仍进行中。已经开始的存储写入仍无法由队列取消；外部替换的完整存储提交屏障仍待实现。共享 Delta/数据库/备份格式不变。
