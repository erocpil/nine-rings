# 独立阅读资料库入口

## 第一阶段（2026-09-08）

- 侧栏新增“阅读 · PDF / EPUB”，直接打开独立资料库页面。设置中的“阅读资料库”保留为跳转，管理界面不再嵌在设置中。
- 复用原有导入、封面、书架/列表、删除和单书阅读备份功能；新增继续阅读、书名/文件名/作者搜索及刷新。
- 从资料库打开文件，关闭阅读器后回到资料库；保留本次应用会话的搜索、格式筛选和滚动位置，书架/列表偏好沿用原存储键。
- 从阅读器创建摘录会切换到笔记；从笔记的摘录链接打开文件，关闭后回到笔记，不强制跳转资料库。
- 进入资料库前先等待笔记保存。资料库导入或阅读备份写入期间，禁用页面返回和设置入口；资料库内 Ctrl/Cmd+F 查找书籍、Esc 返回（有备份面板时先关闭面板），笔记工作区快捷键不会在后台切换文档。
- 封面对象 URL 在刷新/页面离开时释放；过期异步请求不再创建封面 URL。

## 导航精简（随笔 / 待办暂时隐藏）

- 侧栏顶部用“文档 / 阅读”替代随笔切换，阅读直接打开原 PDF/EPUB 资料库；移除下方重复入口。返回仍回到原文档。
- 暂时隐藏随笔列表、日期选择、每日概览、待办/过期面板、待办拖动分隔条，以及相关设置、Markdown 随笔导入、快捷记录和热键入口；桌面托盘同步收起入口。
- 旧 `daily` 默认视图和已展开待办状态不再激活隐藏功能。启动优先恢复已有文档，没有文档时展示空态；全新工作区的示例放到 `references`，不再创建随笔。
- 搜索与快速切换仅呈现文档，启动不再创建每日页或继承待办。历史随笔和待办不删除，备份/同步继续原样保留全部数据。
- 显示开关集中在 `src/workspace-features.json`，由前端和 Rust 托盘共享；本次是界面精简，不是存储迁移。Flutter 独立界面未调整。

## 数据边界（不变）

没有修改 PDF/EPUB 文件存储格式、阅读器渲染、全文锚点或 GitHub 同步范围。原文件仍只保存在当前设备；全量 JSON/GitHub 备份仍不包含 PDF/EPUB 文件及其阅读数据。阅读数据可逐书导出，原文件另行保留。

本阶段不增加底部全局导航、不迁移文件、不新增启动后自动进入资料库的偏好。

## 验证入口

- `e2e/reading-library.spec.ts`：手机/桌面独立入口、导入、继续阅读、作者搜索、筛选与滚动恢复、摘录返回笔记。
- `e2e/pdf-reader.spec.ts` / `e2e/epub-reader.spec.ts`：原设置入口兼容、完整阅读和摘录流程。
- `e2e/reading-backup.spec.ts`：PDF/EPUB、390/1280px 的导出/预检/取消/恢复。
- 真机 PWA 和 Windows Tauri 验收仍需实际设备；浏览器模拟不代表安装版实测。
