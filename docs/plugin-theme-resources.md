# 风格主题资源贡献

## 范围与入口

高级设置 → 启用插件功能 → 插件列表开启「风格主题」→ 点击名称配置。独立开关默认关闭，配色资源默认纸页，排版建议默认关闭。内置资源包括纸页、清雅、精简、九环、物哀、幽玄、侘寂七组成对浅深配色。列表中的配色选择与「界面风格」分开：原风格继续决定布局、控件、装饰和专注行为，插件提供基础配色与语法颜色。外观与布局页在资源生效时说明当前配色来源。

浅深模式仍由宿主外观设置决定，包括跟随系统及经典的命名主题；插件不改写 interface_style、theme、interface_color_mode 或排版设置。未开启时使用既有风格；停用、总开关关闭、资源撤销或所选 ID 缺失时回退原风格，保留设备本地选择。缺失资源恢复后重新应用，不偷偷换成其它主题。损坏偏好回退关闭状态，不自动覆盖原记录。

首版只向可信内置模块开放。没有第三方主题安装、脚本、CSS、HTML、外部字体或文件读取权限，Flutter 插件宿主不在本批范围。P4 的完成范围是内部主题资源贡献，不表示全部风格布局迁入插件或 R7 安装门禁完成。

## 声明式契约与资源归属

`ThemeResource` 使用 version=1，包含有界 ID、名称、完整 light/dark 配色和可选 typography。内部 TypeScript 契约与运行时校验共同约束输入；未来第三方包须另经 R7 包 schema、来源和资源读取校验，不能直接调用内部注册器。

| 字段 | 规则 |
| --- | --- |
| id | `插件ID/资源名`，ASCII 受限字符和长度；必须归属于当前激活插件 |
| name | 非空、最多 64 个 UTF-16 单元，不允许 C0 控制字符 |
| light/dark | 两者必须齐全；每个包含 15 项固定颜色，无未知字段，仅六位十六进制 |
| 基础颜色 | bg、surface、border、text、muted、accent、accentHover、hover、active、code |
| 语法颜色 | syntaxKeyword、syntaxString、syntaxValue、syntaxMeta、syntaxType |
| typography | 桌面/窄屏各六级标题比例、代码/引用/流程块的默认字体；不含正文大小、全局间距或任意 CSS |

浅色背景亮度至少 0.5，深色至多 0.15。正文与次要文本在正文、面板、代码背景上的对比度均至少 4.5:1；强调及悬停强调色与正文背景至少 4.5:1。校验不等于对全部控件、图表内文字和装饰颜色做完整可访问性认证。内置基础配色与原 CSS 回退通过独立契约测试对照；无独立语法色的风格使用既有 sRGB 语义混色规则生成可序列化值。

`ThemeResourceRegistry` 支持多个命名空间提供者：一次注册最多 8 份，全局最多 32 份；整批验证通过后才发布。拒绝伪造激活、重复 ID、跨插件名称、非法颜色/字体/比例及未知字段。注册结果深冻结并复制，不向观察者暴露可变资源。停用同步撤销；旧清理句柄不影响重新激活的新资源。观察者失败不阻止撤销。资源的激活、超时和异常由现有生命周期监管，无需文档读写权限。

## 应用、排版优先级与性能

`theme-application.ts` 只把已认证资源映射到宿主白名单 CSS 变量，补齐链接、抽屉、活动背景等受控派生别名。浅深状态读取宿主主题 class，窄屏沿用 768px 边界；订阅变化只更新令牌，不重新读取正文或卸载编辑器。Mermaid 图内现有独立配色不在此贡献点中替换。

排版建议需显式开启。标题默认比例范围 1～3，六级严格递减且 H6 不小于正文；窄屏使用独立比例。代码默认字体只允许宿主等宽字体，其它块仅允许宿主已有的 system/sans/serif/monospace 字体集合。引用与流程块可提供字体建议。优先级如下：

1. 文档自身的文字格式，以及用户在排版设置中指定的标题字号、块字体和块字号。
2. 开启后的主题标题默认比例与块默认字体建议。
3. 原风格及宿主默认值。

正文与源码的字体/字号、行距、块间距仍由既有设置管理；主题不能覆盖。主题令牌位于根节点，用户排版变量位于编辑区，因此显式设置优先。改变排版建议前，宿主通知局部只读阅读器保存可见锚点并清除屏幕内外的旧行高测量，保留已经排队的导航锚点；源码模式隐藏的阅读器只清缓存，不采集零尺寸视口。随后通过宿主阅读锚点补偿重排，保留选区与编辑器实例；仅配色变化不清缓存、不扫描长正文测量几何。观察器只关注主题 class，避免自身写入 style 触发循环。主题应用保存并只清理自己拥有的行内变量，恢复原值及 important 优先级，不移除其它宿主属性。

## 偏好与故障回退

`nr:pluginTheme` 保存 enabled、themeId 和 typography，仅本机使用，不进入文档、Markdown、GitHub 备份及增量设置实体。支持同窗口事件与跨窗口 storage 更新。调色和排版选择不重启仍有效的提供者；手动停用运行实例后不会因状态通知自行复活，修改配置或重新开启总开关才会重新激活。快速开关的过期任务不能注册到较新的状态。

配置弹层沿用宿主的模态、焦点和 Esc 管理，包含浅深预览、排版建议及恢复默认按钮。恢复默认保留独立开关。资源缺失显示说明，预览不假装是已经生效的主题；第三方资源获取、远端发布与下载均未实现。

## 验证边界

单元测试覆盖资源完整性、对比度、白名单、归属、原子注册/撤销、冻结及过期清理、局部变量映射、用户覆盖、缺失/损坏偏好、跨窗口更新、快速开关和单独停用。浏览器测试覆盖桌面/手机、七组浅深系统切换、配置焦点、同一编辑器实例、经典命名深色模式、用户字号/代码字体、刷新恢复及缺失回退。局部只读长文档还覆盖主题排版切换、源码隐藏视图、行高重测和原文/视口不变。实际执行结果记录在 [E2E 进度](e2e-repair-progress.md)，不把浏览器模拟当作原生 GUI 或全产品 E2E 验收。
