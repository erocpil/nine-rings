# PDF / EPUB 阅读宽度

- PDF：阅读设置 → 手动缩放 →「锁定当前宽度」。按页面占可视区宽度的比例保存，混合纸张尺寸、横向翻页、纵向滚动及屏幕旋转共用同一宽度规则。每份文件单独记住，重新打开继续使用。
- 锁定时屏蔽双击缩放与双指缩放，单指滚动/平移不受影响。点击「解锁宽度」恢复固定缩放倍数；主动点击缩放、适宽或适高也会解除锁定。「适宽」是恢复默认的入口。
- EPUB：阅读设置 →「正文宽度」，范围为 60%–100%，独立于字号；沿用居中排版和桌面最大行宽。换章及重新打开保持，提供「恢复默认宽度」。
- 两项设置包含在单书阅读备份中；旧记录及旧备份仍按原默认方式打开。不修改原文件，也不裁剪 PDF 白边。

自动化覆盖：混合尺寸 PDF 页宽、旋转、重新打开与重置；EPUB 换章、重新打开、独立字号与重置；存储及阅读备份往返。手机安装版/PWA 的真实触摸手感仍需设备验收。

## 桌面阅读分栏拖动（2026-09-15）

针对 Windows Tauri 中阅读分栏拖到最右端再拖回时整窗无响应的报告，减少共享前端的连续排版与栅格化压力：

- splitter 的中间宽度每帧最多提交一次，结束时直接保存最新指针位置。
- 拖动期间保持右侧编辑区布局宽度，由工作区裁剪显示；阅读分栏占满时仍为编辑区保留至少 320px 的内部排版宽度，避免长文档被挤成零宽列。正文保持挂载，不重新加载或清空。
- 拖动开始时冻结阅读区域的实际宽高（包括资料库、PDF、EPUB 和工具栏），只改变外层分栏的裁剪范围；结束后解除冻结，按最终尺寸重新排版。EPUB 的 iframe 不销毁、不随每个中间宽度重新换行。
- PDF 同时暂停尺寸监听、页面几何更新、可见页计算、滚动进度监听和预渲染调度，保留已有画布；结束后重新测量并恢复最终尺寸的高清渲染。不改变手机滚动时的渲染策略。
- 指针捕获丢失、窗口失焦、页面转入后台也结束拖动，恢复光标与选择行为，防止残留拖动状态。
- 回归中发现 EPUB 初始 iframe 暂无根节点时会抛出异常，补上就绪检查。

回归使用 300 段正文、2 倍像素密度的 PDF/EPUB，验证连续最右/返回、捕获丢失、失焦、正文不变、拖动期间工具栏/页面/iframe 尺寸不变、画布不重绘以及释放后的自适应与高清恢复；另外覆盖资料库布局冻结和 pointercancel 清理。Windows WebView2 的整窗卡死仍需安装版实机验收，浏览器回归不等同于该宿主验证。

定向回归：`npx playwright test e2e/reader-sidebar-resize.spec.ts --workers=1`，附加 `--browser=webkit` 验证 WebKit。Windows 安装版验收需使用包含本次提交的新构建；`vcd4e85d.20260915T034859` 不包含此修复。验收时打开长文档及 PDF/EPUB，连续将阅读分栏拖到最右再拖回，确认松手后正文重新适配、高清恢复，且书签与设置仍可响应。
