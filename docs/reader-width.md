# PDF / EPUB 阅读宽度

- PDF：阅读设置 → 手动缩放 →「锁定当前宽度」。按页面占可视区宽度的比例保存，混合纸张尺寸、横向翻页、纵向滚动及屏幕旋转共用同一宽度规则。每份文件单独记住，重新打开继续使用。
- 锁定时屏蔽双击缩放与双指缩放，单指滚动/平移不受影响。点击「解锁宽度」恢复固定缩放倍数；主动点击缩放、适宽或适高也会解除锁定。「适宽」是恢复默认的入口。
- EPUB：阅读设置 →「正文宽度」，范围为 60%–100%，独立于字号；沿用居中排版和桌面最大行宽。换章及重新打开保持，提供「恢复默认宽度」。
- 两项设置包含在单书阅读备份中；旧记录及旧备份仍按原默认方式打开。不修改原文件，也不裁剪 PDF 白边。

自动化覆盖：混合尺寸 PDF 页宽、旋转、重新打开与重置；EPUB 换章、重新打开、独立字号与重置；存储及阅读备份往返。手机安装版/PWA 的真实触摸手感仍需设备验收。
