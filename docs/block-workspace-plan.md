# 代码／引用块工作区计划

更新：2026-09-09

## 产品约定

- 块顶部最右侧提供统一「放大阅读」图标；普通、专注和只读模式均可进入。
- 弹层略小于正文可视区，背景压暗并轻度毛玻璃；手机横竖屏及键盘变化后仍在可视范围内。
- 非只读文档有编辑／阅读模式，初始阅读；只读文档只有阅读模式。切换不改变文档 readonly 属性。
- 编辑作用于原块，复用原编辑器的数据与撤销历史、自动保存，不创建文档副本。显示设置不进入正文。
- 弹层仅一个纵向滚动区；关闭后还原原文滚动位置和入口焦点。编辑模式背景点击不关闭。
- 复用代码语言、简介、行号、软换行、复制、缩进以及引用文字格式等相关操作。
- 空白标记第一版仅阅读模式：空格 ·、Tab →、实际换行 ↵；软换行无标记。符号不进入保存、复制或导出。
- 所有批次单独验证、提交和推送；浏览器模拟不代替手机 PWA、Windows Tauri 真机验收。

## 批次 1：独立工作区与安全编辑

状态：基础实现已完成，WebKit 回归通过；复杂引用格式补齐与导航显示在下一批继续。

- 代码／引用入口、模态弹层、阅读／编辑切换。
- 原块同步、共享撤销／重做、保存状态；只读文档禁止编辑。
- 相关格式／代码选项、缩进和复制；正文位置、键盘焦点恢复，Esc 与背景关闭规则。
- 外部原块被删除、切换文档或重新锁定时不得把旧内容写入其它位置。

验收：编辑只改变目标块；两处撤销一致；只读粘贴无效；阅读切换不写数据；桌面及 WebKit 手机视口可操作。

## 批次 2：阅读显示与导航

状态：实现完成，自动化验证通过。

- 块内查找、匹配数量；编辑模式限定当前块替换；代码跳转行号。
- 阅读模式显示空白：关闭／全部／仅异常（行尾空格、混合缩进），Tab 显示宽度 2／4／8。
- 模式和字号切换按行／段落锚点恢复，不使用滚动百分比；弹层字号独立调整。
- 正文长代码高度可配置，默认约 60% 可用高度，始终不超过可用视口；弹层解除内部限高。

验收：搜索替换不影响块外内容；Tab 宽度不转换字符；复制无辅助符号；软换行与空行定位准确。

## 批次 3：连续阅读与跨设备收尾

状态：待实现。

- 前后同类块导航，离开前确保编辑已进入原文保存流程。
- 长代码性能、引用内嵌套结构、窄屏工具溢出与触摸热区检查。
- 横竖屏、软键盘、安全区、深浅主题、保存失败与块失效回归。
- 桌面左右编辑／预览列为后续可选增强，不为并排而引入第二份可写数据源。
