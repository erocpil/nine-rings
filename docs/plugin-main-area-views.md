# 插件主区域视图贡献

状态：2026-10-23，可信内置图片查看、词汇学习与本地文件只读插件已接入。当前是内部 TypeScript 宿主能力，未开放第三方安装、任意 HTML/React renderer 或公开 SDK JSON 方法。

## 职责边界

插件声明名称、视图 ID、宿主支持的 renderer 和数据，调用绑定到当前激活的视图接口。宿主管理中央区域、保存门禁、前后视图切换、编辑器保留、焦点、手机抽屉和资源释放。展示权限 `views.present` 不包含文档写入权限；目录图片另需 `filesystem.images.read`。

`MainViewRegistry` 是独立于左侧 `WorkspacePanelRegistry` 的贡献点。当前 renderer 为 `image`、`vocabulary` 与 `local-file`，贡献 ID 由宿主注册且全局唯一。以后文档统计、搜索结果、对比和图片处理结果可增加明确的数据 schema 与受认可 renderer，不需要插件选择 DOM 容器或复制导航机制。

可信模块绑定示例：

```ts
const views = mainViews.bind(context.activation);
views.register({ id: "builtin.image-viewer", label: "图片查看", renderer: "image" });
const requestId = views.open("builtin.image-viewer", { image, images });
views.close(requestId);
```

绑定对象只提供注册、打开与关闭自己的视图；不能关闭其它插件的视图，也不提供宿主 accept/reject、首页暂停或恢复接口。注册和每次调用校验宿主签发的激活身份，复制的身份描述不构成权限。贡献与请求随激活撤销，不把视图状态保存到文档或 GitHub 备份。

## 打开与保存

打开请求先进入 pending，`usePluginMainView` 经过既有自动保存协调器冲刷，再由宿主 accept。期间原视图继续显示；保存失败拒绝新请求、报告错误并保留当前文档/已有主区域视图。连续请求只接收最新请求；插件停用或导航关闭后，迟到的保存结果不能再次打开视图。

请求数据经过 shape/数量校验并复制冻结，拒绝未知字段、空集合及超过 5000 张的集合。目录节点只使用授权根 ID/相对节点 ID；查看资源最终仍由既有图片服务校验。查看文档图片不要求文档编辑权限，插入操作继续经过图片插入插件、保护检查和宿主编辑事务。

## 原视图保留与导航

主区域图片打开时，当前文档在 RetainedDocument 中停放：保留实例、选区、滚动、源码或渲染模式及各自撤销历史。当前文档仍是原文档，不伪造一份图片笔记。关闭/按 Esc 返回原视图；停用插件自动返回，切换文档或打开 PDF/EPUB 则结束图片视图。敏感文档继续遵守已有离开会话的释放策略。

PDF/EPUB 及路径页作为原视图时隐藏但保留布局，而非 display:none 或因图片视图卸载；返回沿用原来的阅读器状态。进入首页暂停主区域视图并保留查看组件，返回恢复缩放/平移等状态。在首页另打开图片时接收新图片；返回上一页面继续显示新图片。普通文档导航结束该图片视图。

桌面图片树保持可操作，使用已有固定/悬停及分栏宽度。手机图片树打开主区域图片后自动收回抽屉，避免遮挡图片；仍可通过既有入口重新打开抽屉。

桌面点击文档树按钮暂停图片视图并恢复原文档；点击图片分栏按钮先保存文档，再恢复保留的图片视图和图片树。悬停预览分栏不切换中央内容。图片工具栏的「返回原视图」仍结束图片视图并返回原内容，首页期间的分栏点击继续遵守首页导航规则。

## 图片两个入口

- 图片分栏：默认打开中央区域。工具栏/文件名固定，缩放、平移、预览旋转、复制和上一张/下一张共用图片查看内容组件。
- 文档正文：默认临时弹层，保留原有查看/关闭行为；工具栏新增「在主区域打开」，显示当前正在查看的图片及其图库。

图片查看内容与容器分开：`ImageViewer` 的 modal/main 呈现复用相同资源和操作逻辑。弹层使用原生 dialog 与焦点限制，主区域不限制 Tab 离开，不阻止宿主 Command/Ctrl 组合键。目录查看与插入、资源预算和后续图片处理契约见[图片分栏](plugin-local-image-panel.md)。

## 后续扩展

先按 renderer 增加宿主支持的类型化数据和工具栏动作，再接入相应插件。公开 SDK 需补协议版本、能力协商、打开结果/生命周期事件、取消与错误回执及资源句柄边界；这次没有偷偷扩展 JSON RPC 的公开协议。第三方自定义界面未来需独立隔离容器和权限评估。

图片主区域 renderer 在同一激活/视图 ID 内保持实例，再次打开树节点只更新图库与当前图片，使属性固定/专注等查看状态连续。当前图片选中另由会话状态广播到树，树切换不再决定方向键是否可用。详细属性属于该 renderer 的宿主内建区域，不开放第三方 DOM 或文件系统写入。

## 词汇学习视图

词汇分栏调用受限宿主读服务并提交文档身份、名称与 Markdown 快照。`documents.vocabulary.read` 与 `views.present` 分开核验；不开放任意文档读取或正文写入。词汇视图复用主区域保存与恢复门禁，未知格式保留完整原文；预算、保护检查、手机入口和未来文章关系详见[词汇学习插件](plugin-vocabulary-learning.md)。

词汇主区域已接入激活绑定的同组顺序导航适配点；排序和分组由提供者决定，宿主管理快捷键冲突、并发操作和关闭后的迟到结果。普通文档复用邻居选择算法，不依赖启用插件。具体契约见[词汇学习同路径导航](plugin-vocabulary-learning.md#同路径前后导航)。

## 本地文件只读视图（2026-10-23）

新增 `local-file` renderer，只接受授权根 ID、根内相对节点和名称，不接受正文、任意路径或插件 renderer。`filesystem.files.read` 与展示能力独立检查；宿主接受 pending 后由 `LocalFileView` 再通过只读服务读取原文件。分栏插件不取得数据库编辑接口，原文档继续驻留。目录撤权/插件停用关闭视图并清理对应缓存；普通返回保留本次会话最近三份文件的查看状态。范围与未实现部分见[本地文件夹工作区](local-folder-workspace.md)。
