# 手机右侧导航与应用设置的手势职责

日期：2026-11-11。状态：已实施。

## 背景与选项

原右侧手势绑定在渲染编辑器和虚拟阅读器中，源码与首页缺少入口，源码导航还主动屏蔽了手机布局。逐个视图新增设置回调会重复处理全局状态；另一方案是在应用中通过 DOM 查询猜测当前模式，容易唤醒保留的编辑器。

## 决定

应用 App 统一接管右侧下半屏设置手势，文档所属视图仅处理上半屏阅读面板；首页上半屏不执行文档操作。保持30px起手范围、60px横向阈值及现有控件/选区/模态排除规则。现有 onOpenSettings 参数接口保持兼容，仓库内文档调用方仅 App，实际设置状态仍由同一 setter 修改。

源码的共享 DocumentNavigationWorkspace 复用 DocumentPanelDrawer，数据库和本地文件在手机使用同一抽屉；桌面控制器保留位置、固定状态和排序逻辑。上半屏默认打开可用大纲（Markdown 标题或源码符号），记住书签选择，无大纲能力回退书签。抽屉内跳转后收回，文档失活不响应；手机只在展开时更新导航，保留已完成的符号缓存，避免隐藏文档持续解析。

## 实施与验证

增量新增应用设置监听及源码抽屉，复用已有识别器、反向收回、焦点恢复和滚动列表，不引入新解析器。验证数据库可编辑/只读、普通/专注模式、符号跳转、切换到 Text、首页设置及本地文件从桌面到手机再返回桌面。观察入口次数、解析时机、导航位置和桌面布局是否保持；Chromium/WebKit 自动化与真机触摸验收分开记录。
