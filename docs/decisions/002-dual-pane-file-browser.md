# 双栏文件浏览的宿主与插件边界

日期：2026-11-06。状态：已采纳，三批基础能力已实现；原生磁盘授权、大目录性能及跨平台 GUI 待现场验收。

现有文件树适合导航和编辑入口，但无法承载两个独立目录的对照浏览。备选方案为在 App 直接实现文件管理器、开放第三方任意视图、或扩展可信内置本地文件插件。采用第三种：复用授权文件服务与主区域保存门禁，宿主只增加受限 renderer 和可保留的浏览返回目标，左右栏逻辑留在插件视图中。

先交付浏览、导航、状态恢复与既有查看器接入，再扩展跨栏写入及效率工具。首批不改变文档存储或同步格式。验证关注旧请求丢弃、停用清理、保存失败仍保留原视图、只渲染可视条目及浏览往返不丢位置。完整计划见[双栏文件浏览](../plugins/plugin-dual-pane-browser.md)。

效率批次使用版本化设备标签状态，复用原授权读取/搜索与排他写入规则；快速预览、当前层元信息比较与批量命名计划均由受限宿主组件呈现。目录比较不代表递归正文认证，批量操作不代表整批原子事务，其它文件提供者待明确需求。

2026-11-07 补充：双栏浏览独立为可信内置插件，活动栏直接进入，不创建空分栏。相比继续嵌入本地文件或复制文件服务，采用独立贡献所有权加共享宿主资源持有计数；便于独立启停，又避免授权/会话被另一插件清理。原浏览设备状态不迁移，只有启用偏好一次性继承。需验证两种停用顺序、总开关撤回、浏览往返和独立打开文件。后续优化计划不因拆分而提前开放额外文件权限。

操作队列采用激活身份所有权而非弹层所有权：确认弹层只冻结计划并入队，关闭、收起或重新打开浏览器不会重放任务。插件停用时停止待执行工作，已开始的原生操作仍需结算。保留未知失败的“需核对”状态，暂停后续任务，不能将一般 I/O 异常视为“尚未写入”而直接重试。后台执行期间通过宿主临时路径锁防止来源编辑/保存与移动或删除冲突，不更改用户只读偏好；每项执行前重新检查草稿。任务与结果仅保留在本次激活内，不在重启后自动恢复磁盘写入。

2026-11-08 跨文件系统移动：保留同磁盘排他重命名；只针对系统明确的 CrossesDevices 错误降级。相比“复制后递归永久删除来源”，采用目标侧临时复制、完整目录清单/SHA-256 校验、排他发布，再将来源交给系统回收站。目标发布后的失败使用独立错误标识，不允许误判为可重试的同名冲突，不做路径迁移。不会提前将来源改名藏入临时目录，也不在启动后自动恢复未完成写入。验证覆盖校验失败、外部变化、发布竞争、回收站失败和断点前后的数据保留；真实跨卷和平台回收站行为另行验收。

2026-11-08 进阶效率：继续让独立双栏插件拥有比较、目录标签及拖放编排，宿主文件服务不新增权限或 IPC。比较选择有界递归和已有 UTF-8 原始字节摘要，而非默认扫描全部正文；预算不足或不支持必须显示未知。拖放只产生确认提案，再走原队列，避免第二套写入路径。目录标签增加可选本机状态，恢复关闭标签不恢复已撤销的目录授权。优先核验取消后的迟到结果、活动标签身份、多选快照、固定标签保护及拖放确认，保留既有浏览/队列回归。

2026-11-08 预览接续：预览的查找、缩放和连续浏览保持为插件界面能力，复用原读取预算，不把预览变成第二份可编辑模型。连续浏览只使用当前可见来源列表已加载的文件；文本方向键和查找输入保留原本含义。选择统计仅报告已知元数据，不因选择大目录启动后台递归扫描。图片缩放复用原适窗计算，以原始像素百分比定义固定倍率，原生滚动条承担有限边界的平移。验证关注 Esc 焦点顺序、局部滚动、不修改文件、窄屏布局及插件停用清理。
