# ADR 001：所有记录使用统一文档模型

- 状态：已采纳，记录日期 2026-10-10。
- 旧独立随笔和待办移除日期：2026-09-27。

## 背景

初期设计区分按日期组织、无路径的随笔与有路径的文档，设想随笔单向晋升。用户随后确认这两个独立功能尚未提供给用户，没有用户数据需要迁移，并要求清除它们。后续新增随记用于临时想法和任务记录。

## 决定

不恢复独立随笔/待办模型。随记复用普通 Note、编辑器、路径、保存、搜索、版本和备份；入口是 ideas/notes，分组使用子路径，待办保存在正文任务列表中。

旧 daily_pages 等未发布存储在现有升级路径中清理；不设计不存在的用户数据迁移。此决定不授权删除其它文档，也不意味着可以随意删除仍在使用的 date 字段。

## 理由与代价

共同模型避免重复编辑、保护、备份和插件适配。代价是随记不会具有独立日记/任务数据库的调度语义；日期视图或任务聚合若需要，应从普通文档派生，另行设计。插件不得依赖已退役的随笔晋升操作。

## 验证依据

现有 IDB 升级移除 daily_pages；随记交互见[工作区布局](../workspace-layout.md#随记notes)，共享数据字段见 schema/note.yaml。任何后续共享格式扩展必须验证未知数据保留和不支持客户端的写入边界。
