9|
10|本计划用于跟踪 Nine Rings 从快速功能开发阶段进入可信 Beta 所需的工程整改。
11|
12|总体原则：
13|

154|## 5. 第 1 轮：修复本地日期

> **状态：✅ 已完成** | 交付提交：`b867349`
155|
156|### 5.1 问题
157|
158|项目大量使用：
159|
160|```ts
161|new Date().toISOString().slice(0, 10)
162|```
163|
164|它返回 UTC 日期。在 Asia/Shanghai 时区，每天 00:00–07:59 会得到前一天。
165|
166|可能影响：
167|
168|- 今日页面。
169|- Quick Capture。
170|- 新建文档默认日期。
171|- 逾期待办。
172|- 跨日检测。
173|- “回到今天”快捷键。
174|
175|### 5.2 实现原则
176|
177|新增统一工具：
178|
179|```ts
180|export function localDateKey(date = new Date()): string {
181|  const year = date.getFullYear();
182|  const month = String(date.getMonth() + 1).padStart(2, "0");
183|  const day = String(date.getDate()).padStart(2, "0");
184|  return `${year}-${month}-${day}`;
185|}
186|```
187|
188|不能机械替换所有 `toISOString()`：
189|
190|应使用本地日期：
191|
192|- 每日页面 key。
193|- Quick Capture 日期。
194|- 逾期判断。
195|- 跨日检测。
196|- 用户可见的“今天”。
197|
198|应继续使用 UTC：
199|
200|- `created_at`。
201|- `updated_at`。
202|- 同步/备份版本时间戳。
203|- 日志时间。
204|- 跨设备排序时间。
205|

236|## 6. 第 2 轮：自动保存与版本策略

> **状态：✅ 已完成** | 交付提交：`c2bf29c`
237|
238|### 6.1 核心决策
239|
240|分离两个概念：
241|
242|1. 自动保存：保证当前内容不会丢。
243|2. 版本 checkpoint：保存有意义的编辑里程碑。
244|
245|普通自动保存不能自动创建版本。
246|
247|### 6.2 自动保存策略
248|
249|- 输入后 500–800ms debounce。
250|- 每篇笔记使用串行保存队列。
251|- 编辑器失焦时立即 flush。
252|- 切换笔记前立即 flush。
253|- 页面隐藏时尽可能 flush。
254|- Tauri 关闭或隐藏窗口前 flush。
255|- React 组件卸载时 flush。
256|- 保存失败后保留 dirty 状态并允许重试。
257|
258|推荐状态机：
259|
260|```text
261|clean → dirty → saving → saved
262|                    ↘ error
263|```
264|
265|### 6.3 乱序防护
266|
267|必须防止：
268|
269|```text
270|保存 A 发出
271|保存 B 发出
272|保存 B 完成
273|保存 A 后完成 → 旧内容覆盖新内容
274|```
275|
276|可选机制：
277|
278|- 每篇笔记串行 Promise queue。
279|- 客户端 revision。
280|- 数据库条件更新。
281|
282|仅使用 AbortController 不能完全保证数据顺序。
283|
284|### 6.4 版本 checkpoint 策略
285|
286|建议创建 checkpoint 的事件：
287|
288|- 切换笔记。
289|- 显式保存。
290|- 关闭应用。
291|- 恢复另一个历史版本前。
292|- 可选：超过一定编辑时间或内容变化阈值。
293|
294|不创建 checkpoint 的事件：
295|
296|- 普通 debounce 自动保存。
297|- 只改变光标或滚动位置。
298|- 内容与上一个 checkpoint 完全相同。
299|
300|建议 API 明确分离：
301|
302|```ts
303|saveNote(id, changes)
304|createNoteCheckpoint(id)
305|```
306|
307|而不是让 `updateNote()` 隐式决定是否产生历史版本。
308|
309|### 6.5 快照语义
310|
311|版本历史必须保存“更新前状态”或明确的稳定 checkpoint。
312|
313|错误顺序：
314|
315|```text
316|UPDATE
317|INSERT 当前状态
318|```
319|
320|正确顺序：
321|
322|```text
323|读取稳定状态
324|  ↓
325|在一个事务内保存 checkpoint
326|  ↓
327|执行需要的状态变更
328|```
329|
330|恢复历史版本时：
331|
332|1. 保存当前状态 checkpoint。
333|2. 恢复目标版本。
334|3. 两步应原子执行。
335|
336|### 6.6 任务
337|
338|- [ ] 提取 `useAutoSave`。
339|- [ ] 建立每篇笔记的保存队列。
340|- [ ] 实现 debounce。
341|- [ ] 实现 flush。
342|- [ ] 显示保存状态。
343|- [ ] StorageAdapter 增加显式 checkpoint 能力。
344|- [ ] IDB 自动保存不再生成版本。
345|- [ ] IDB checkpoint 去重。
346|- [ ] Tauri 实现相同语义。
347|- [ ] 版本恢复前保存当前 checkpoint。
348|
349|### 6.7 验收标准
350|
351|- [ ] 快速输入不会被旧异步响应覆盖。
352|- [ ] 切换笔记后最后一次输入不会丢失。
353|- [ ] 保存失败可见且可重试。
354|- [ ] 最近 30 个版本代表编辑里程碑，而不是最近 30 次按键。
355|- [ ] Web 与 Tauri checkpoint 行为一致。

408|## 8. 第 3B 轮：Tauri 事务可靠性

> **状态：✅ 已完成** | 交付提交：`cb0c416`（与第 3A 轮合并交付）
409|
410|### 8.1 版本 checkpoint 原子性
411|
412|Tauri checkpoint 应在 Rust 事务中完成。不能在前端分别：
413|
414|```text
415|SELECT
416|INSERT version
417|UPDATE note
418|```
419|
420|否则多个异步保存之间可能交错。
421|
422|### 8.2 `PRAGMA query_only`
423|
424|当前 `db_query` 在成功路径才恢复：
425|
426|```sql
427|PRAGMA query_only = OFF
428|```
429|
430|短期方案可使用保证清理的闭包：
431|
432|```rust
433|conn.execute("PRAGMA query_only = ON", [])?;
434|
435|let result = (|| -> Result<_, String> {
436|    // prepare/query/collect
437|})();
438|
439|let reset_result = conn.execute("PRAGMA query_only = OFF", []);
440|// 合并 result 与 reset_result
441|```
442|
443|也可以实现不会阻碍正常借用的 RAII Guard。
444|
445|长期可考虑：
446|
447|- 固定只读连接。
448|- 固定写连接。
449|- 避免在共享连接上反复切换 PRAGMA。
450|
451|### 8.3 手工事务
452|
453|所有手工：
454|
455|```sql
456|BEGIN;
457|COMMIT;
458|ROLLBACK;
459|```
460|
461|应评估是否改用 `rusqlite::Transaction`。
462|
463|注意：
464|
465|- `Connection::transaction()` 可能需要 `&mut Connection`。
466|- AppState 锁变量和服务函数签名需要相应调整。
467|- 中途任何错误都必须自动回滚。

## 9. 第 4A 轮：字段边界与交换格式
490|
491|### 9.1 命名决策
492|
493|采用：
494|
495|```text
496|SQLite / Rust DB Row       snake_case
497|             ↓ mapper
498|Domain / IPC JSON          camelCase
499|             ↓
500|TypeScript / Dart UI       camelCase
501|```
502|
503|只允许在固定 mapper 边界转换。
504|
505|建议建立：
506|
