## 样板范围

正文、固定目录、文档标题栏、工具栏和代码块。浅/深色、密度切换、目录展开收起、章节跳转、专注模式、代码折叠与复制可操作。其余入口明确标为视觉示意，无真实编辑或保存。手机尺寸做了适配，用于检验规则，不替换当前手机界面。

## 规则

| 维度 | 规则 |
| --- | --- |
| 视觉优先级 | 正文 > 标题与当前导航 > 辅助工具 > 块号、元信息 |
| 色彩 | 画布、内容、控件底色、文本、辅助文字、分隔线、强调色、选中底色分别使用语义变量。目录和正文共用内容底色 |
| 强调 | 使用低饱和绿色作为样板强调色；不要求以后所有主题变绿。仅用于当前项、状态和少数交互 |
| 文字 | 桌面页标题 34、章节标题 21、正文 15、导航 13、辅助 11–12px；手机标题 27、正文 14px。正文行高 1.9，代码 1.9 |
| 字重 | 正文 400；控件及小标题 500；章节 600。不要所有按钮和导航一起加粗 |
| 间距 | 优先使用 4/8/12/16/24/32/48px。段落间 16，章节前 28；分组先用间距，再考虑分隔线 |
| 控件 | 默认无明显边框；悬浮显露浅底和细边；选中使用强调底色。常规高 32px，图标 18px，圆角 6px |
| 容器 | 代码块以轻背景分组，不再嵌套粗边框；区域分隔线缩进，避免与 splitter 形成十字交点 |
| 正文宽度 | 舒适模式内容约 680px；紧凑模式约 580px。留白随可用宽度收缩，不靠强制缩小字体适配 |
| 辅助操作 | 块号常驻但视觉较弱；插入操作在悬浮/聚焦时显露。手机不依赖悬浮，保留可见入口 |
| 焦点与反馈 | 保留明确键盘焦点；提示预留位置，不推挤正文。低对比装饰不得作为唯一的交互线索 |

## 评审重点

1. 是否接受更安静的工具栏，还是希望默认按钮底色更明显？
2. 舒适与紧凑，哪一种更适合作为桌面默认？
3. 当前内容层级是否清楚，块号是否过淡？
4. 目录与正文连续底色是否比独立色块更自然？

上述规则已映射到已有主题变量与真实组件，具体范围见下文。独立 demo 没有实现 splitter、编辑器或导航历史，章节按钮仅用于演示跳转。

## 已集成的正式设置

排版设置新增 H1～H6 独立字号及代码、引用、Mermaid 图块、flow 块的字体与字号；所有风格共用这些覆盖项。“默认”保留当前风格与手机适配，不固定原有自适应字号，代码块默认继续使用等宽字体。恢复默认排版会清除这些覆盖项。块工具栏及行内代码保留原样，Mermaid 按字体重新布局。

目录与书签的桌面悬停浮层复用文档树右键菜单的 `--ui-shadow-popover`；非经典风格的阴影混合主题文字颜色，深色背景下呈现柔和亮色光晕。固定阅读面板保持无阴影。点击目录或书签按钮时，文档树右键菜单先关闭，再完成对应面板操作。

入口：设置 → 外观与布局 → 界面风格。可查找“风格 / 清雅 / 紧凑”。

- 七种公开的非经典风格及兼容保留的清雅·紧凑默认共用侘寂原有的正文排版：系统无衬线正文、16px、1.8 行距、统一标题字号和块间距。在“外观与布局 → 风格排版”中调整会同步作用于非经典风格，不覆盖经典设置；各风格继续保留自己的配色与控件细节。
- 2026-10-09：移除风格之间的标题字重与阅读几何覆盖。H1～H6 共用字重 600、字距 0；16px 正文时桌面标题为 34/21/18/16/16/16px，随正文设置等比例缩放。窄分栏与手机使用同一套缩放规则。
- 正文块间距默认 16px、标题前 28px、标题后 12px，读取共享配置的像素值；展陈密度不再覆盖这些排版值。连续标题保留紧凑层级，折叠标题间距一致；手机与窄分栏按统一比例收紧标题前后距离。正文、完整/局部只读、源码并排预览及设置预览共用这些规则。
- 非展陈正文基础最大宽度统一为 780px、侧边留白基准 32px；展陈的宽幅/标准/窄幅仍由用户选择。自定义最大宽度会限制宽幅正文，不因展陈布局覆盖而失效。已有共享字号、行距、间距、字体和宽度设置原样保留，无须迁移文档数据。
- 风格配色可选择浅色、深色或跟随系统；新工作区默认浅色。经典仍使用用户自定义主题与排版。

以 `interface_style` 和 `interface_color_mode` 持久化在 Web/Tauri 配置中。新工作区的展陈文本宽度默认为宽幅、密度默认为舒适。经典的主题、字体、字号、行距、导航颜色始终原样保存；预设使用单独的显示配置，切换时不将预设值写回经典配置。

清雅系列隐藏不生效的主题、导航样式和排版外观选项，搜索这些设置会引导至风格入口。排版子页保留行号、Tab、空白字符、代码换行和 Mermaid 显示等功能选项。恢复默认块显示不会改动经典排版。工具栏正文缩放入口在清雅下隐藏，避免暗中修改经典字号。

文档内明确设置的富文本格式、Mermaid 源码指定样式、图形缩放及独立块阅读操作仍属于内容或局部阅读功能，不由外观预设抹除。风格切换不修改文档内容。原型页面保留在 `/demos/visual-system.html`。

### 桌面细化

桌面清雅系列采用统一的 48px 顶栏基线，紧凑为 42px；工具按钮高度分别为 32px、28px。分隔线两侧留空，目录与正文共用底色。文件树、列表与阅读导航以柔和选中背景和细侧标识强调当前位置，辅助计数和类型标签不使用额外的重底色。

正文左右留白根据实际分栏宽度收缩，而不是仅依赖窗口宽度。窄分栏中的代码工具栏允许换行，确保所有操作可达。文件列表由虚拟列表管理的行高保持不变；以上桌面细化不应用到手机触控布局，也不改变经典风格。

### 弹层与正文细节

桌面清雅菜单统一 8px 圆角、轻阴影和舒适操作行距；块阅读及插入弹层采用 12px 圆角，标题延续工作区基线。选中菜单使用强调底色，危险操作保留独立颜色，禁用状态和键盘焦点继续可辨。弹层定位、边缘避让和焦点管理沿用原组件。

正文表格保留完整网格及列宽交互，减轻纵向分隔，强化表头并加入浅行底色；行内代码取消明显边框。引用使用正文颜色，列表与嵌套层级增加适度呼吸空间。正文块和独立阅读弹层共享这些细节，手机触控布局和经典风格保持原样。

### 设置页与工具栏

设置分类与子页切换时从顶部展示，查找设置仍定位到命中的选项。桌面打开设置时，外部界面使用 6px 毛玻璃；按住外部鼠标左键时隐藏设置并清除模糊，松开后恢复，过渡为 180ms。减少动态效果时关闭可见过渡，手机保持原有遮罩与触控行为。

正文标题栏的源码入口使用 `</>` 图标，源码模式返回渲染视图使用文档图标；保留悬停提示与无障碍名称，桌面、手机和只读视图共用。

源码工具栏的查找替换、跳转行、软换行、撤销重做、加粗、行内代码及链接使用统一的图标按钮，保留悬停说明和可访问名称；软换行仍显示选中状态，只读时禁用修改操作。源码高亮中的硬换行反斜线、分隔标记和转义符使用正体，避免斜体改变符号的视觉方向；正文强调和注释仍保留原有斜体。

源码工具栏新增 `A` 图标的“源码微渲染”开关，默认关闭，本机记忆并随前端偏好备份。开启后 H1/H2/H3 分别使用正文的 1.25/1.15/1.08 倍字号，H4～H6 保持基础字号；链接加下划线，列表、任务、引用与代码分隔标记使用风格强调色，行内代码使用等宽字体。所有源码字符和地址保持可见，普通点击仍定位光标；图片、公式、图表与 HTML 不变成预览组件。增强依赖 CodeMirror/Lezer 的语法分类而非全文正则，保留按视口挂载、选择、折叠与撤销历史。开启或关闭后重新测量行高，供并排预览同步使用。

源码行号和折叠符号字号为基础正文的 85%，最大 16px，行高独立保持与源码一致。标题的微渲染字号不传给行号，等宽数字保持原有对齐；这项行号调整不依赖微渲染开关。

书签 SVG 自带明确尺寸，渲染标题栏保持图标居中，计数作为独立角标，不参与图标布局。文档树工具栏在没有当前文档或路径时禁用属性与当前路径操作；首页保留的文档实例不计作当前选择。新建文档仍可使用，批量操作按文档数量、勾选状态、同步忙碌状态及操作回调启用。

桌面清雅设置页将普通设置组的外层卡片改为留白和底部分隔线，标题 14px/500、说明 12px，入口按钮与可比较的风格选项仍保留轻底色。首页分类弱化边框，更新记录采用分段排版，保留搜索定位、滚动和保存反馈。

工具栏沿用原有按钮次序和溢出逻辑，通过历史操作组的细分隔、统一图标尺寸、强调色选中态以及清晰的键盘焦点区分状态；禁用操作保持可辨。手机触控布局和经典风格不受此轮调整影响。


### 长文档、窄栏、导航与反馈（四步细化）

1. 长文档：顶层段落、列表、代码、引用和表格使用明确的块间距，标题前间距不再随标题字号重复放大。只读虚拟行根据完整可见块序列标记后续标题，避免窗口挂载边界改变间距。
2. 窄栏：使用阅读容器实际宽度；不足 480px 时收紧标题、表格和工具栏，正文大小不变。源码工具栏与行内留白同步适配。
3. 导航：细化标题、路径和标签层级，保留完整标题提示；文件树文档标题支持 Tab 聚焦、Enter/Space 打开。区分空列表、空收藏、无最近访问及筛选无结果，并提供对应操作。
4. 反馈：保存和同步状态使用语义色，辅助文字提高对比度，焦点可见；减少动画偏好下停用保存脉冲、同步旋转与平滑滚动。

排版和信息密度细化限定桌面清雅系列。文件树键盘语义与空结果文案适用于所有风格；减少动画设置同样适用于移动端清雅系列。回归覆盖 Chromium/WebKit、编辑/源码/只读往返及内容不变性。

### 展陈工作区布局

2026-10-09：概览标题行中央增加可点击的工作区摘要，桌面显示文档、随记、今日修改和收藏数量；手机仅显示文档和今日修改，保留紧凑的单行布局。概览收起后摘要仍可用，首页与文档页共享统计。文档/收藏/今日修改入口打开文档列表并清除先前筛选；“今日修改”使用可移除的筛选标签，按本机自然日计算，跨午夜和页面唤醒时自动更新。随记入口打开原有随记分栏，包括未分组与已分组文档。点击摘要不改变当前文档，桌面展开固定分栏，手机打开文档列表弹层。

统计项靠右排列在“展开/收起概览”按钮左侧。桌面点击统计时，若已有可见固定分栏，则所有统计列表沿用该分栏的实际宽度；否则统一使用文档列表偏好的宽度。这个展示宽度在切换随记、文档、今日修改和收藏、窗口 resize 和首页往返时保持，拖动可以调整；活动栏正常切换仍读取各分栏原有的独立宽度偏好，恢复默认宽度会清除此临时覆盖。

2026-10-10：桌面悬停四项统计时，就近弹出对应文档列表，按最近修改排序，与统计共用路径、自然日和收藏筛选规则。弹层采用目录面板的主题底色、边框和光晕，最多十五行，空间不足时按视口缩小；超过后在弹层内滚动。标题单行省略，悬停显示完整名称，点击直接打开文档并冲刷当前保存。列表超过六十项后按可视行挂载，不改变分栏或正文宽度。

鼠标可跨越按钮与弹层之间的间隔，离开后收起，移入其它统计立即切换。点击外部、Escape、打开文档、进入专注或受模态窗口阻挡时关闭。键盘在统计项按向下箭头打开，列表支持方向键及 Home/End，Escape 返回统计按钮。原有点击统计打开分栏及手机的点击列表方式保持有效。

顶部显示工作区路径、返回首页入口和风格/明暗切换；中央是原有编辑器与分栏；下方提供继续阅读（最近访问）、常用文档（文档收藏）、最近修改和快捷操作。列表使用摘要数据，点击才读取正文。返回首页及跨文档打开前先冲刷自动保存。文档状态下默认收起概览，首页展开，专注模式隐藏整个外围框架。四栏在窄桌面变为两栏，手机一栏并限制概览高度，保证编辑区仍可使用。

桌面展陈顶部承载工作区标识和窗口操作，中央不再重复显示软件标题栏。Tauri 保留标题区拖动、双击最大化/还原、全屏和关闭到托盘；Web 仅在浏览器支持时提供全屏。专注模式恢复紧凑窗口标题栏，手机继续使用原有布局。

桌面展陈左上恢复 NINE RINGS / WORKSPACE 与路径两级标识，窗口操作仍保留在外围。风格、配色右侧提供文本宽度（窄幅 690px、标准为窄幅与宽幅的动态中点、宽幅铺满可用列）与密度（舒适、紧凑）；密度改变控件高度和段落留白，保留风格字体与配色。选项独立持久化，桌面展陈及其专注状态生效，手机不应用。专注标题栏使用无 Logo 的大写字标，词首 N/R 稍大。

### 九环

位于精简之后的独立风格。浅色用雾紫纸面（#f0ebf5）、灰紫强调色（#67497e），深色用低彩度灰紫底（#37313f）、柔和紫强调色（#c5a9df）；豆沙粉引用线与灰蓝紫链接下划线提供次级色彩。主文字保持深浅对比，饱和色集中在交互与细节，避免整片高饱和背景造成阅读疲劳。它与其他非经典风格共用统一正文排版，并兼容桌面展陈宽度与密度设置；预览复用真实配色，支持手机与源码。

九环柔化参考 [Radix 色阶职责](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)：背景、交互底色、边界与文字分层使用，降低大面积底色彩度，标题使用正文色。展陈左上角进入首页前保存文档并暂存文档/目录位置，再次点击返回；已删除的文档显示明确提示。

九环进一步收窄明暗跨度：浅色正文用 #f0ebf5，面板用 #e6ddec；深色正文用 #37313f，面板用 #403848。设置、文件导航和正文共享同一组色阶，代码底色居中，避免浅色接近白纸、深色接近纯黑。

桌面展陈的四项选择使用受控菜单，同一时刻只打开一项。首次点击启用菜单后，鼠标悬停其它顶部选项会直接切换菜单；再次点击当前按钮、Escape 或点击外部关闭，并结束这次悬停切换。关闭时清除鼠标焦点框，保留键盘焦点提示；单纯悬停不会首次打开，触屏不启用悬停切换，取消不写入配置。触发按钮所在祖先区域滚动会关闭菜单，独立正文区域的滚动及阅读位置恢复通知不会关闭；文档列表的筛选菜单沿用点击切换规则，不启用展陈悬停行为。手机继续原生选择器。九环深色当前块高亮与源码统一为强调色 8% 混合。

### 工作区汇总与最近打开

点击汇总项打开对应分栏，再次点击当前项恢复进入汇总前的分栏、固定/悬停/收起状态、宽度及文档列表筛选。切换汇总项沿用同一恢复目标；切换首页/文档视图时重新记录。“最近打开”弹层按访问历史展示最多十六份；分栏继续按最后编辑时间展示十五份，文档列表原有“最近打开”标签仍按访问历史排序。

在“设置 → 外观与布局 → 布局设置 → 工作区概览汇总”选择互斥的三种交互：点击弹出分栏；默认点击显示弹层（再次点击收起）；悬停显示弹层（移出收起，键盘进入不受鼠标离开影响）。手机悬停模式通过点击打开弹层。弹层可见文档数默认十五，范围一至五十，超过后滚动查看，较小视口自动缩减高度。弹层选择文档不更改分栏布局，最近打开弹层最多取十六份访问记录，分栏仍取最近编辑的十五份文档。设置复用本机工作区布局偏好并随全量备份恢复，不增加文档或数据库字段。

### 编号汇总弹层（2026-10-10）

弹层中的“最近打开”按本机访问历史选取最多十六份仍存在的文档，包含只浏览、没有编辑的文档；不按编辑时间替代访问记录。随记、今日修改和收藏先按原有范围筛选，再选取最近修改的十五份。上述四种弹层将近期项置于下方，按自上而下的十六进制编号直接打开：最近打开十六行对应 `0`～`f`，其他十五行对应 `0`～`e`，没有对应行的键不执行操作；接受大小写，忽略组合键、输入法组字和按键重复。正文、查找框等输入区域的正常输入不会被截获；全部文档弹层及分栏查询维持原有规则。最近访问事件即时刷新预览，无需重新加载页面。弹层默认可见十六行，空间不足时按视口收缩；用户已自定义的可见数量保留。可见行数小于候选数时默认滚到下方，先显示近期文档。

### 最近打开扩展与编辑标识（2026-10-10）

最近打开弹层上限更新为十六份，按访问顺序将近期项放在下方，编号覆盖 `0`～`f`。随记、今日修改、收藏仍最多十五份，分栏规则保持不变。可见行数仍由设置控制（默认十五），因此第十六份可通过滚动或编号选择，默认定位下方。

成功保存标题、正文或标签后，最近访问历史记录该文档已编辑，弹层显示为主题强调色和 600 字重；仅浏览显示普通正文色和 400 字重，并提供编辑状态的辅助说明。标识来自本机实际保存，而非导入/历史修改时间；旧记录没有可靠编辑依据时不推断。重复打开保留已有标识，历史淘汰时同步清理标识；这两项本机记录随全量备份恢复。可选标识存储失败不影响已完成的正文保存。
