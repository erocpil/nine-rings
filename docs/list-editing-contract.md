# 列表回车与持久化契约

- 直接位于列表项内的非空段落按 ProseMirror splitListItem 拆分为下一项，键盘 Enter 和可取消的 beforeinput/insertParagraph 共用这一处理。
- 在含代码或引用内容的项末尾空段落上回车，先拆出新项，不将整项连同代码移出列表。
- 真正空的列表项可退出当前列表层级。退格合并留下的多个空段落先归一为一个，再执行退出；输入法组合期间不干预。
- Shift+Enter 继续插入块内换行。代码块、引用块内部继续使用各自的退出规则。

## 保存结构

Delta 的列表换行新增两个可选属性：list-continuation 表示同一项内的续段，list-block-start 表示新列表边界。旧数据无这些属性时按原规则读取。代码和引用沿用 code-block / blockquote 等已有内容属性，同时记录所属列表；不再丢弃结构块内容。Markdown 导出为缩进续段，不额外生成列表编号。

旧客户端不识别新的结构属性时不能保证多段列表的完整往返；本轮保证更新后的 Web、PWA 和 Tauri 共用相同读写规则，不对旧客户端行为作保证。已被旧版本保存丢失的内容不能由这些属性自动恢复。

## 源码滚动

源码 textarea 使用固定大小容器，底部内边距按可视高度减去首行高度和上边距动态计算。窗口尺寸改变时重新计算，不修改文档文本，也不插入用于撑高的空行。

## 引用内的结构与源码空行（2026-10-09）

引用内出现列表、标题、嵌套引用、代码、表格等结构时，导入器递归解析引用正文，保存为版本化 `blockquote: { version: 1, content: DeltaOp[] }` embed；纯段落引用仍兼容原有逐行格式。列表节点及行内代码不会再变成带字面量 `-` 的普通段落。存储、Markdown 导出和搜索文本提取共用该结构。

顶层列表紧接未缩进的代码或引用且源码没有空行时，保留自动跟随缩进；至少一个空行时记录显式零缩进，阻断自动跟随。源码已明确缩进时优先保留该缩进。该规则控制顶层块的展示，不把顶层结构强制重写为列表项；真正位于列表项内的块仍遵循原有列表持久化契约。Markdown 导出保留边界，避免源码往返重新产生自动缩进。

已有旧版本导入且保存为普通段落的引用列表不会被猜测性改写，避免将用户有意编写的 `-` 文本误认为列表；可重新导入原始 Markdown 获得修正后的结构。
