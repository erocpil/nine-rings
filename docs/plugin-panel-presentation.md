# 分栏展示与风格插件

## 目标与归属

以宿主提供的数据模型和控制器为基础，插件贡献展示配置与工具栏，类似 MVC 的 V 加命令入口。文档树、目录、书签和随记使用共同的展示边界；风格作为主题资源贡献，不替换工作区控制器。先实现声明式展示，再按实际需求考虑整个视图的替换。首版仅可信内置模块，不开放第三方脚本、安装或稳定公共 SDK。

| 功能 | 宿主保留 | 展示插件贡献 |
| --- | --- | --- |
| 文档树 | 路径及摘要查询、保护、选中、折叠、打开、移动、重命名、批量操作 | 字体、字号、行高、主题语义颜色、提示、辅助字段和工具按钮 |
| 文档目录 | 标题解析与索引、正文/源码位置映射、折叠与跳转、当前标题同步 | 标题层级排版、编号、截断、过滤入口及工具按钮 |
| 书签 | 存储、编辑后的锚点映射、定位、失效处理 | 分组、排序、标签、提示和列表外观 |
| 随记 | 文档与分组身份、日期、顺序、创建及分组操作、保存与恢复 | 分组标题、日期展示、摘要字段和工具按钮 |
| 风格 | 设置持久化、布局、浅深主题切换、可访问性约束 | 主题/排版令牌及所属视图局部装饰 |

分栏宽度、固定/悬停、首页快照恢复、手机抽屉、长按、焦点、Esc 优先级、滚动位置由宿主管理。展示停用不删除数据、不卸载编辑器、不重置折叠或改变导航方式。

## 共同契约

`PanelDisplayTarget` 使用稳定槽位标识 `document-tree`、`document-outline`、`bookmarks`、`notes`，与按钮中文名称和存储路径无关。文档树、文档目录、书签和随记均已接入可信内置展示。

`PanelDisplayContribution` 是可序列化配置，无 React 组件、函数、DOM、HTML 或任意 CSS：

- `font`：跟随宿主、系统无衬线或宿主等宽字体；不下载外部字体。
- `fontSize`：12～20 px；`rowHeight`：28～48 px，触控设备由宿主保留至少 36 px 的行高。
- `labelColor`：跟随风格、次要文本、主题强调色。宿主将它们映射到当前浅/深主题令牌，选中颜色及路径层次色仍由宿主决定；文档树仅给文档名称应用该字段。
- `tooltip`：名称或完整路径，使用宿主已有字段，不调用正文/保护内容读取。首期是原生 `title` 提示，不包含自定义富文本气泡。
- `showCounts`、`showMetadata`：是否显示宿主已有计数和辅助信息，不改变模型及查询结果。
- `toolbar`：所属槽位允许的宿主命令 ID。文档树使用 `tree.expand-all` 和 `tree.refresh`，目录使用 `outline.reveal-current`；跨槽位命令拒绝，书签提供 `bookmarks.reveal-current`，随记提供 `notes.expand-all` 和 `notes.refresh`。

注册时校验并冻结配置，拒绝未知字段、重复命令、跨槽位命令及越界尺寸。每个槽位仅有一个主展示提供者，不以注册顺序静默覆盖；未来独立装饰/工具贡献另行定义顺序、去重和数量预算。

注册必须持有宿主签发的活动身份，资源由运行时托管。停用、总开关关闭、异常或卸载移除配置并恢复宿主展示。工具按钮执行前再次核对活动配置与已声明命令，旧按钮不能在停用或切换后执行。按钮的禁用状态由当前宿主上下文决定，插件不得扩大权限；本批两个工具命令只操作展示/刷新，不提供文档写入能力。

这不是任意视图替换或第三方安全沙箱。注册器仅向可信内置宿主开放；未来 SDK 需要经来源认证和消息校验才能接入相同的声明式注册器，不能直接把内部类导出为公共接口。

## 本批实现与入口

高级设置 → 启用插件功能 → 右侧插件列表 → 点击「文档树展示」名称。配置弹层显示全部选项，未启用展示时也可先调整设置。默认不启用展示扩展，开启后使用 14 px、30 px 最小行高、跟随风格字体/颜色、完整路径提示，显示计数及文档类型；工具栏加入展开全部和刷新。可以恢复展示默认设置。列表同时展示日期、实时统计与插入图片的名称、类型、简介和运行状态；配置弹层支持结果展示设置，调用参数在文档菜单中选择。桌面列表在设置右侧，手机纵向排列。配置窗口阻止背景交互，Esc 仅关闭配置并恢复插件名称焦点；其它窗口关闭总开关会撤销配置窗口。

`nr:pluginTreeDisplay` 是设备本地偏好，不进入文档、Markdown、GitHub 数据备份。关闭插件功能保留偏好但撤销活动注册；再次开启重新签发身份。运行状态中的单独停用保持停用，不因运行状态通知立即复活；修改该扩展设置或重开总开关才能重新激活。

代码分层：`panel-display.ts` 管校验、注册和撤销；`builtin-panel-display.ts` 共用偏好及受监督的激活，树和目录各自声明默认值与本机键；`usePanelDisplay` 订阅稳定配置快照；`DocTree` 使用配置渲染，既有控制器与树数据不移动到插件。标题/目录将来的展示配置更新同样不得引发编辑器重建。

## 风格主题资源首版（2026-10-17）

书签面板同时移除顶部“取消当前位置书签”按钮；当前位置没有书签时保留“添加”，删除通过具体条目右侧“×”或已有快捷键/块菜单进行。总数移到标题行右侧，渲染、源码和局部只读保持一致；展示插件隐藏计数的偏好仍生效。

## 后续阶段与性能边界

1. 文档树首版：声明式配置、局部样式、允许的工具入口、停用回退及桌面/手机回归。
2. 文档目录：复用槽位与生命周期，先给现有目录组件接入；统一渲染/源码目录的展示配置，标题位置映射和自动跟随仍在宿主。验证长标题、长目录、折叠后定位与 Top/Mid/Bot。
3. 书签与随记：分别接入已有列表，保留锚点与分组身份；增加经过宿主验证的分组/排序/新建命令。纯展示不请求正文权限，数据操作须遵循已有 SDK 权限与保存门禁。
4. 风格资源：独立主题贡献点，对颜色/字体/间距令牌做 schema 校验，处理浅深配对、主题缺失回退和用户排版覆盖。保持现有经典及其它风格兼容。
5. 只有确实需要另一种布局时再开放替换视图。宿主提供有版本与分页预算的只读节点摘要和稳定节点身份，视图用命令 ID 表达意图；不提供全文对象、内部 DOM 或可变树。

展示更新只重绘所属组件，不重新读取正文。现阶段文档树没有新增全文订阅或节点回调。后续大目录虚拟列表、分页、排序、增量摘要和取消预算由宿主提供，不要求插件逐次输入遍历整篇文档。HTML/JS、任意全局 CSS、动态编辑器 schema 与公共包安装不在本批范围。

## 文档工具与结果展示

插入日期、图片和实时统计属于文档工具，分别提供编辑命令与只读实时统计。
功能分类、读写权限和结果展示策略相互独立；展示选项不授予额外权限。
当前内置试点通过宿主管理的 `result-presentation.ts` 保存本机偏好，尚不是第三方 SDK 的公开接口。

在高级设置的插件列表点击名称，可选择状态栏或弹层，并选择弹层位于文本区上方、中央或下方。
日期默认状态栏，成功保存后提示三秒；统计默认中央弹层，包含未保存正文，持续更新至关闭。
弹层不自动获取焦点、不阻止编辑；日期插入后仍可直接撤销。
状态栏不存在或不可见（包括当前源码视图）时回退到所选位置的弹层。
弹层以当前编辑器可视边界定位，调整窗口或分栏尺寸时重新定位。
结果不增加正文行，不改变文档内容与保存权威。

Esc 优先关闭当前插件结果，下一次才处理分栏。关闭统计、切换文档/视图、离开文档、停用插件或总开关都会回收订阅。
展示偏好支持跨窗口刷新，改变展示方式不会重新执行日期插入或重新创建统计订阅。
今后插件应提供结构化消息或统计字段，由宿主统一呈现；不接受插件自带 DOM、任意 CSS 或屏幕坐标。

### 启停入口

高级设置的“启用插件功能”内包含只读运行状态（权限、资源和异常）；插件列表是各插件启停的统一入口，配置弹层只负责配置。
文档树开启后自动激活；日期、图片和统计开启后按需调用。停用会释放正在运行的实例，并禁止再次调用，选择仅在本机持久化并支持跨窗口更新。
总开关关闭会终止所有任务，但保留独立插件选择；重新开启不会自动执行日期或统计命令。

配置弹层遮罩采用暗色半透明毛玻璃，避免浅色背景过亮；更新反馈在标题名称旁显示，不额外占正文高度。关闭按钮保留可访问名称，不再显示悬停提示。结果弹层由当前主题正文背景混入少量文字色，在浅色主题中略深、深色主题中略浅；状态栏结果与关闭按钮同排居中对齐。

## 调用参数与配置的边界

长期配置决定插件默认行为和结果展示；调用参数只决定本次执行。插件声明参数，宿主生成菜单/表单并执行验证，不接受插件自带界面。

| 参数声明 | 宿主呈现 | 执行时机 |
| --- | --- | --- |
| 无参数 | 普通菜单项，如文档统计 | 点击后执行 |
| 有限预设 | 菜单项右侧三角、二级参数菜单 | 选择预设后执行 |
| 多个输入参数 | 二级菜单中的「自定义…」或直接参数表单 | 校验通过并确认后执行 |

三种调用方式已通过内部 `PluginInvocation` / `CommandParameters` 声明统一接入 `PluginCommandMenu`。表单由 `PluginParameterDialog` 生成，不开放插件 DOM；公开参数 SDK 尚未发布。
日期与时间预设包括 YYYY-MM-DD、YYYY-MM-DD HH:mm、含秒、HH:mm:ss、中文日期时间和带本地偏移的 ISO 8601。菜单预览是示例，实际插入取执行时的本机时间，不转换到 UTC；ISO 偏移使用该时间的本地偏移，兼容夏令时和半小时/四十五分钟时区。
桌面悬停打开二级菜单，点击同样可打开；键盘右方向进入、左方向返回，Esc 先返回一级，再次 Esc 关闭。只读/停用状态不允许进入日期时间参数菜单。

多参数表单字段：稳定字段 id、类型（文本/数字/布尔/枚举）、名称、说明、默认值、必填和长度/范围限制；宿主拒绝未知字段与非法值。普通参数不赋予文档写入权限。
表单应采用居中弹层，提供执行/取消与键盘操作，取消不调用插件；确认后关闭表单并恢复当前编辑目标，再走既有目标校验、撤销、保存确认及结果呈现流程。
日期等编辑操作不能在每次输入参数时执行。支持预设和自定义的插件可两者并存；常用值保持二级菜单直接选择，不要求一律打开表单。


### 图片参数试点

开启插件功能和列表中的插入图片后，在文档 + 菜单选择「插入图片…」。表单提供图片类型、资源地址、替代文本和悬停标题；选行内图片时显示前后文字，引用式显示引用名称，链接式显示点击目的地址。默认使用 Markdown 全景示例的 `/icon-192.svg` 本地资源，可改为 `/ragdoll-32.png` 或 HTTP/HTTPS 地址；支持选择本机图片文件（PNG/JPEG/GIF/WebP/AVIF/BMP，最多 10 MB），执行时复制到宿主图片存储并插入稳定引用；取消表单不保存文件，原文件移动不影响文档。未开放第三方文件系统读取权限。

表单取消不编辑，执行前验证输入并拒绝可执行协议。引用名称自动加唯一后缀，避免覆盖当前文档已有定义。通过现有 Markdown 解析/SDK 选区插入，不绕过保存队列；支持源码和渲染，一次撤销恢复插入前内容，保存确认后才显示成功。只读与停用时不可调用。

本机图片通过宿主选择文件，不把文件句柄或操作系统路径交给插件；保存和备份复用现有图片机制。备份同时展开正文图片引用与保留的 Markdown 源码引用，避免恢复后切换源码重新使用旧设备引用。受保护文档仍遵守首期插件写入门禁。

本机图片树采用新增分栏注册与目录服务，首版可信内置插件已实现，详见[图片查看分栏](plugin-local-image-panel.md)；它独立于文档树展示配置。

## 目录展示首版（2026-10-13）

高级设置 → 插件列表 → 开启「目录展示」，点击名称配置。默认独立停用；开启后默认 13px 字号、28px 最小行高，触控至少36px。字体、主题语义色、标题层级标记（H1～H6）、标题数及悬停名称/章节路径可调整，支持恢复默认。只改变目录展示，不修改正文标题字号、位置、折叠或内容；层次颜色和当前标题强调保留优先级。

普通渲染与源码使用共用 DocumentOutlineList；实验性局部只读目录也应用同一配置。宿主保留现有折叠/展开、Top/Mid/Bot、固定/悬停、手机抽屉和导航。插件工具 `outline.reveal-current` 只将目录滚到当前章节，不移动正文；局部只读根据阅读锚点定位。配置更新和停用不卸载编辑实例、不重建标题索引；总开关和单独停用沿用受监督生命周期。

`nr:pluginOutlineDisplay` 仅本机保存，不进入文档/Markdown/GitHub备份，与树配置独立并支持跨窗口设置通知。注册器校验目标和允许命令，旧提供者的按钮不可执行；错误/损坏配置回退宿主。公开SDK、第三方包安装、目录数据控制器替换均未开放。

虚拟目录的估算缓存包含展示字体、字号、行高和层级标记；变化时清理已测量行高并重新测量自然内容，保留窗口化及Top/Mid/Bot定位。路径提示一次线性生成，不在滚动时逐标题回溯正文。书签与随记后续复用同一偏好工厂及配置表单，但命令和数据契约独立验收。

## 书签与随记展示（2026-10-13）

高级设置插件列表新增「书签展示」「随记展示」，均默认单独停用，开启后可调整字体、字号、最小行高、语义色、名称/上下文提示、辅助信息与工具栏，支持独立恢复默认。默认13px、32px，触控行至少36px。书签辅助信息为块号，提示上下文使用现有名称及正文预览；随记为分组计数及本机修改日期，路径提示使用现有路径/名称。不新增读取正文或写盘权限。

`order` 可选 `host/name/recent`，只允许书签及随记槽位。书签默认按正文位置，recent按创建时间；随记默认沿用最近修改排序。名称和时间相同按ID稳定排序，投影排序不更改原数组、书签位置或分组身份。普通渲染、源码及局部只读共用书签投影；源码定位工具使用最近书签，普通渲染使用宿主当前书签，局部只读点击工具时使用阅读位置。工具只滚动书签列表，不修改正文选区。

随记展开工具仅清除已有分组折叠状态，刷新重用宿主加载器，忙碌/暂停时禁用。创建、改名、删除、多选/分组、筛选、选中和分栏滚动仍由NotesPanel及现有保存/变更服务管理。普通书签行保留手机滑动操作；源码、局部只读原有管理能力保持不变。

`nr:pluginBookmarkDisplay` 与 `nr:pluginNotesDisplay` 仅保存在本机，排除备份；跨窗口通知、总开关与单独停用沿用同一受监督生命周期。配置窗口与目录/树共用表单；所有按钮受槽位白名单及提供者身份约束，旧按钮和跨槽位命令不可执行。插件不开放任意CSS、DOM、第三方安装或新的书签分组存储模型。
