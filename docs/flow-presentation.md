# 流程展示

流程展示是一种可选的阶段式文档呈现，适用于操作指南、机制说明和方案验证。正文仍使用普通 Markdown，无需特殊语法。

## 使用方法

打开文档属性，在「文档展示」中选择「流程展示」，选择作为阶段的标题级别（默认 H2），点击「保存展示方式」。切回「普通文档」即可关闭。只读文档可以查看，但不能修改此属性。

同一级别的标题按正文顺序生成圆形编号；后续正文沿虚线排列。更低级别的标题作为阶段内部的小节，更高级别的标题结束当前流程。脚注单独显示，不纳入流程。不要在阶段标题里手写编号，否则会出现重复编号。

建议使用以下内容结构：

1. 动作标题：阶段需要做什么。
2. 简短目的：为什么要做。
3. 输入或触发条件：从什么状态开始。
4. 操作与条件分支：怎样执行，异常时去哪里。
5. 输出与转移：完成标准，以及下一阶段。

ideas 路径预置「流程展示：从想法到可执行方案」，与风格设计示例位于同一路径。升级或首次启动仅添加一次；已有同名示例不会覆盖，用户编辑或删除后也不会重建。

## 数据与实现边界

展示设置保存在文档 `content.metadata.presentationMode` 和 `flowHeadingLevel` 中，随文档备份、同步及加密数据保存。纯 Markdown 导出保留正文，展示选项不会插入导出内容；重新导入纯 Markdown 时需要重新选择展示方式。

编辑器通过 ProseMirror 节点装饰添加 class 和编号属性，不创建额外的正文节点，也不重建编辑器实例。光标移动复用已有装饰，只有正文或展示设置变化才重新计算。普通文档默认关闭，不进行阶段扫描。局部只读渲染与源码并排预览复用相同的阶段索引，编号不随可见窗口重新开始。

配色取自当前风格的纸面、边框和强调色，支持浅色、深色与手机布局。原有标题折叠、块号、列表及编辑行为继续使用原来的文档结构。
