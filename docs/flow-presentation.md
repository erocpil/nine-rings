# 流程块与流程展示

## 独立 flow 块（推荐）

流程块可直接嵌入普通文档。正文工具栏「更多 → 插入流程块」（窄屏也可用「块 → 流程块」）可插入示例；也可粘贴以 `flow` 为语言的 Markdown 围栏：

````markdown
```flow
## 明确问题
*目的：说明为什么要做。*

- 记录输入与约束
- 确定完成标准

> 补充说明。

### 条件分支
信息不足时，返回前一个阶段。

## 执行与验证
描述操作与输出。
```
````

默认以 H2 标题作为阶段；没有 H2 时使用最浅的标题级别。更低级别标题作为阶段内分支，更高级标题和脚注结束当前主线。每个流程块独立编号。没有标题的内容也会正常呈现，空块提示如何添加阶段。

每条主线使用一个贯穿容器的虚线，经过块间距与阶段间距。圆形编号覆盖主线，正文、引用、表格和条件分支排在线的右侧。渲染页、完整/局部只读、源码并排预览和块工作区使用同一个展示组件与间距规则。

右上角可切换「源码 / 流程」、复制内部 Markdown、打开块模式、折叠整个块。折叠状态与现有结构块一样在编辑/只读间保留。块模式提供「阅读 / 编辑」，编辑使用 Markdown 高亮并写回原文档；桌面可实时并排预览，手机依次显示编辑区和预览，可关闭预览。撤销由原文档持有，查找时显示源码。多个流程块可在块工作区中前后切换。

推荐内容结构：动作标题 → 简短目的 → 输入或触发条件 → 操作与分支 → 输出与下一步。流程内的展示内容通过源码或块模式编辑，内部引用/代码的放大按钮不会误用外层文档的位置。嵌套流程最多呈现三层，再深的内容以源文显示。

流程内部需要代码围栏时，外层使用四个或更多反引号。导出的 Markdown 保留 `flow` 围栏与原文；其它 Markdown 软件可把它作为普通代码块显示。数据沿用现有代码块结构，不需要额外数据库或原生接口迁移。复制按钮复制内部源文，不包含自动编号。PDF 导出目前沿用代码块的源文输出。

## ideas 效果示例

ideas 路径预置「流程展示：从想法到可执行方案」，与风格设计示例位于同一路径。新版示例使用独立 flow 块。旧示例仅在正文仍与原始版本一致时原位升级，保留其它元信息；用户改过的正文不会覆盖，已经删除的示例不会重建。

## 旧版文档级展示（兼容保留）

已有文档属性中的「流程展示」继续可用，可按 H1–H6 指定的标题级别生成文档级编号；关闭后恢复普通文档。设置保存在 `content.metadata.presentationMode` 和 `flowHeadingLevel` 中，随文档备份、同步及加密数据保存。它不改写正文，也不重建编辑器。

新内容推荐独立 flow 块：将需要展示的阶段写入一个 flow 围栏，文档属性保持普通文档。这样展示范围、虚线连续性和跨视图一致性由块本身控制。
