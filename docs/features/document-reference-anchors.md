# 文档内部引用锚点

引用锚点用于在正文中引用另一份文档或当前文档的某个块、光标位置或选中文字；书签仍用于个人阅读导航，两者分别保存。

## 使用

编辑器右键菜单及工具栏更多菜单提供“复制块引用”和“复制此处引用”；选中文字时后者变为“复制选中文字引用”。块号菜单和标题栏“块级操作”共用菜单中的“复制块引用”，只读及局部只读可用；选择单块后的多选操作栏也保留该功能。复制结果是 Markdown 链接，可粘贴到文档或源码中：

```markdown
[引用说明](nr-note://文档UUID#nr-ref-锚点UUID)
```

点击链接先保存当前修改，再打开目标文档并跳转。目标标题、代码块和引用块已折叠时自动展开；选中文字引用定位到对应范围。导航沿用后退/前进历史。目标删除或锚点失效时显示提示，不根据相似文字猜测位置。已有标题链接、HTML 锚点与普通文档链接继续保留。

## 保存与编辑

复制在点击事件中立即发起 `ClipboardItem` 写入，以 Promise 延迟提供文本，直到锚点保存成功。避免 WebKit 在异步保存后失去用户手势权限；工具栏、右键菜单、块级操作栏和局部只读工具栏共用此边界。保存失败不提供链接内容，恢复存储后可以重试；不支持此接口的环境沿用原来的纯文本/兼容复制。WebKit 的限制见[官方异步剪贴板说明](https://webkit.org/blog/10855/async-clipboard-api/)。

目标文档的 `content.metadata.referenceAnchors` 保存锚点 ID、模型位置范围、种类和预览文字。复制相同位置复用已有有效 ID；不插入可见标记，不更改书签列表，也不产生正文撤销项。新增锚点仅修改元数据，保留导入源码和脚注定义原来的位置；实际正文编辑仍使旧源码缓存失效。

渲染编辑按 ProseMirror transaction mapping 更新位置；同一次事务移动唯一且内容未变的块时跟随移动，重复块不猜测。删除目标使锚点失效，最近的文档快照用于恢复撤销后的锚点。源码编辑通过渲染文本和结构映射更新位置，保留复合块范围，并将行内公式、图片等原子节点计入模型位置。源码会话的撤销版本恢复对应元数据。

锚点 UUID 和文档 UUID 不依赖标题、路径及可见块号。正文修改后的当前锚点列表由已挂载编辑器持有，通过原有保存边界持久化，避免 React 的旧属性覆盖映射后的新位置。

## 可移植边界

JSON 备份包含文档 ID 与锚点元数据。单独导出 `.md` 会保留链接文本，但不携带目标文档的锚点列表；将 Markdown 单独导入另一套工作区不能据此恢复内部引用目标。外部公开文档宜使用标准标题或 HTML 锚点链接。
