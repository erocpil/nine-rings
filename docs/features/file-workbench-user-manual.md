# File Workbench 用户手册

File Workbench 用于浏览本地目录、整理文件和编辑文本。桌面版提供目录授权、文件操作队列和独立 Editor 窗口。浏览器版可选择目录快照，适合查看和导出副本。界面会根据平台、目录授权和当前选择提供可用操作。

[toc]

## 1. 开始浏览

在桌面版点击目录选择按钮并授予访问权限。在浏览器版点击「选择目录快照」，选择要查看的文件夹。快照反映选择时的内容。要查看外部修改，请重新选择目录。桌面版授权可在「管理授权目录」查看和撤销。

左栏和右栏可以打开同一授权根中的不同目录，也可以打开不同的授权根。点击文件列表或目录标签可切换活动栏。工具栏的方向指示标出来源和目标。复制或移动到另一栏之前，先在对侧打开目标目录，再回到来源栏选择文件。

点击路径栏编辑授权根内的相对路径。用面包屑回到上级，或用前进、后退按钮浏览已经访问过的目录。名称过滤只缩小当前列表。需要搜索文件内容时，请使用「搜索正文」。文件列表展示设置提供字号、行高、日期格式和列显隐，也可按栏覆盖默认值。

## 2. 目录标签与工作区

用标签栏的加号新建标签，标签各自记住路径、浏览历史和显示偏好。拖动标签可排序。右键可以固定目录、关闭标签、恢复关闭的标签，或把标签移动或复制到另一侧。固定标签可返回原目录，也可按需要限制在该目录内或在切回标签时自动返回。

每栏可用「纵向目录数」增加目录行。拖动中间分隔条调整左右宽度，双击恢复等宽。「交换两栏」交换两套目录和标签，「两栏同路径」让另一栏转到当前目录。

用「命名工作区」保存当前双栏布局。工作区记录分栏比例、目录行、活动栏和标签，可随时载入、更新或删除。载入时按当前目录授权恢复可用的位置。

## 3. 选择文件与批量整理

点击选中单项，按住 Shift 选择连续范围，按住 Command 或 Ctrl 增减选中项。文件列表获得焦点时，Command+A 或 Ctrl+A 选中列表条目。编辑器和输入框使用各自的全选行为。右键菜单随选中内容及目录权限变化。

- **创建和重命名。** 用工具栏或右键菜单新建文件、文件夹或改名。批量重命名前会列出每个旧名和新名，并标出已发现的冲突。
- **批量重命名规则。** 可组合文本替换或正则替换、大小写转换、模板及编号补零。规则先处理主文件名，再应用模板。`{name}` 是主名，`{ext}` 是扩展名，`{n}` 是编号。常用组合可以保存为预设。
- **复制、移动和回收。** 确认弹层会显示来源、目标和项目数。拖到对侧或目标文件夹也会先生成确认计划，按住 Shift 拖放可提出移动。删除使用「移入系统回收站」。
- **操作队列。** 确认后的任务串行运行。「操作队列」可查看进度、逐项结果和等待处理的冲突。遇到同名项时，按面板提供的选项跳过、保留双方或改名。支持的替换场景可先核对版本再确认。停止任务会保留已完成的结果。

符号链接用角标区分。可以打开授权范围内可访问的目标。失效或越界链接会提示，可用的改名、复制和移动操作也会按链接类型受到限制。

## 4. 搜索、比较与跨目录收集

- **命令面板。** 点击「命令面板」，或按 Command+Shift+P / Ctrl+Shift+P，搜索文件命令、自定义工具、固定目录和最近目录。结果显示适用栏位、快捷键或禁用原因。
- **正文搜索。** 在待搜索的目录栏打开「搜索正文」，设置范围和查询后开始。打开匹配项可定位至对应文本。检查目录占用用「统计当前目录大小」。
- **目录比较。** 分别打开待比较目录，再点击「比较目录」。默认比较当前层的元信息。可选递归深度、UTF-8 正文或原始字节核验后重新比较。元信息相同只表示比较字段一致。
- **比较后复制。** 选择方向并勾选差异，查看复制计划、冲突和未知项，再提交队列。当前计划处理普通文件，目标父目录须存在。同名差异在队列里继续核对。
- **双文件差异。** 同一条目两侧都有普通文件时，可以点「差异」看逐行对照。选侧和行号后，可在编辑器打开对应行。
- **文件暂存架。** 从不同目录右键将普通文件加入暂存架。打开暂存架，选择目标栏及复制或移动，再点「核验并预览」。已失效的引用会标明原因，有效项可一次入队。

## 5. 快速预览与阅读

用「快速预览」查看活动栏当前文件，选中其他项目可切换预览。支持常见图片、文本、Markdown、PDF 和 EPUB，具体入口随文件类型而变。文本可以查找，Markdown 支持渲染与源码查看。PDF 支持缩放、分页、缩略图、搜索和书签。EPUB 支持目录、全书查找、排版、书签和脚注。

打开 ZIP 可浏览包内目录、预览 UTF-8 文本并解压所选条目。当前支持单卷 Store 或 Deflate ZIP，包体上限 32 MiB，单项解压上限 8 MiB。桌面版选择新文件名保存解压结果，浏览器版下载解压文件。

## 6. Editor 打开、编辑与保存

桌面版的文本文件可以在独立 Editor 窗口打开。编辑器顶部的文件标签可点击切换、拖动排序，悬停显示完整名称和所在目录。右键菜单提供复制路径、在文件浏览中定位及关闭标签等操作。浏览窗口的「显示编辑器窗口」可召回编辑器。重启后会尝试恢复退出前仍打开的文件和活动标签。

文件打开后，标题区域显示只读或可编辑状态。需要改动时选择「允许编辑」，完成后使用保存按钮或 Command+S / Ctrl+S。未命名文件首次保存需选位置。关闭未保存标签或退出时，按弹层选择保存、保留草稿、丢弃内容或取消。可从浏览窗口打开「恢复草稿」。丢弃前请核对文件名和内容。

在「编辑器设置」调整标签宽度、短文件名收缩、固定面板布局、配色和排版。源码模式提供查找、跳行、行号、折叠及适用语言的源码符号。Markdown 可在源码与渲染之间切换。源码模式可打开并排预览，渲染模式可使用文档目录、书签及同词高亮。固定导航面板可以按窗口布局叠放或组成标签组。

## 7. 磁盘文件发生外部变化

独立 Editor 会检查已打开文档的磁盘版本。后台有变化的标签会高亮，切到该标签时出现处理弹层。点击背景可继续查看弹层。用「稍后处理」返回正文时，旧版本暂时只读，可以在当前文件标题下方点「处理磁盘变更」重新打开弹层。

- 没有未保存编辑时，可直接载入磁盘版，或先比较两个版本。
- 有未保存编辑时，先比较或另存副本，再决定是否放弃编辑并载入磁盘版。需要覆盖时，编辑器会再次核验版本。
- 若文件在查看差异期间又变化，应重新比较最新版本。待处理的旧版保持受保护状态。

## 8. Markdown 链接与交付

相对链接可打开同一授权范围内的文件，也可定位到文档标题。跳转后可以沿链接历史返回。右键链接可以复制链接地址。用「检查文档链接」查看失效引用。同一授权根内重命名或移动后，浏览工具栏可预览并确认更新受影响的 Markdown 引用。

编辑器支持导出 Markdown、HTML，以及通过桌面系统打印对话框存储 PDF。导出生成供分享的副本，当前原文件依照独立的保存流程处理。

## 9. 自定义工具与快捷键

点「添加工具」配置程序、参数、名称和图标。可选直接启动或等待命令退出并查看输出。右键可以按已配置参数运行、调整位置、复制、编辑或删除工具。支持的文件也可拖到工具按钮。工具按钮或分隔符可右键选择「拖动调整位置」后重新排序，松开保存，Esc 取消。

使用配置参数运行工具前，确认面板显示程序、参数和工作目录。参数逐项传给程序。`{path}` 表示当前目录，`{file}` 表示首个选中文件，`{name}` 表示名称，`{target}` 表示另一栏目录，独占一行的 `{files}` 展开全部选中路径。运行命令需要桌面版。

「文件浏览快捷键」可以查看、录制、禁用和恢复按键。常见默认值包括 F2 重命名、F5 复制、F6 移动、F7 新建文件夹和 F8 移入回收站。多数文件操作快捷键只在文件列表获得焦点时生效。

## 10. 常见问题

**只能导出副本。** 检查目录来自浏览器快照还是具有写权限的授权目录，并核对当前应用能否保存原文件。

**文件移动或改名受阻。** 先检查该文件、目录或其内容是否打开、有未保存编辑或恢复草稿。处理相关会话后再重新确认操作。

**Gentoo 上启动出现 GBM/KMS 错误。** 完全退出应用后，可以在单次启动命令前加 `WEBKIT_DMABUF_RENDERER_FORCE_SHM=1`。例如 `WEBKIT_DMABUF_RENDERER_FORCE_SHM=1 file-workbench`。
