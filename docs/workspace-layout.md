# 桌面布局与阅读面板

桌面 Web 与 Tauri 共用相同交互：目录和书签按钮悬停时就近预览，面板与按钮留出间隔；点击按钮将该面板固定，再次点击收起。固定期间悬停不改变该面板，另一个未固定的面板仍能预览。点击目录或书签跳转不会收起已经固定的面板。

默认固定在正文右侧，目录在上、书签在下。两者同时出现时默认占比 2:1；拖动中间分隔条调整比例，拖动靠正文的边缘调整总宽度。比例分隔条也支持方向键和 Home / End。

“设置 → 外观与布局 → 布局设置”提供：

- 工作区分栏位置：文档树、文档列表、PDF / EPUB 阅读分栏可放在正文左侧或右侧。
- 目录与书签位置：固定面板位于正文左侧或右侧。
- 目录与书签排列：上下排列或左右排列。左右排列时目录在左、书签在右。
- 恢复目录与书签比例：恢复到 2:1。

位置、排列、比例、宽度和固定状态保存在本机 `nr:workspaceLayout`，并纳入设置备份。旧版固定目录的位置与宽度会迁移。完整编辑器、完整只读和局部只读共用布局；手机版保留原来的点击弹出和边缘抽屉交互，不应用桌面的固定状态。

验证覆盖 Chromium / WebKit 的悬停定位、固定与收起、比例持久化、左右布局、右侧分栏拖动、手机竖横屏和 Tauri 标题栏模拟。真实 macOS / Windows 原生窗口仍需在相应系统验收。
