# 桌面布局与阅读面板

桌面 Web 与 Tauri 共用相同交互：目录和书签按钮悬停时就近预览，面板与按钮留出间隔；点击按钮将该面板固定，再次点击收起。固定期间悬停不改变该面板，另一个未固定的面板仍能预览。点击目录或书签跳转不会收起已经固定的面板。

默认固定在正文右侧，目录在上、书签在下。两者同时出现时默认占比 2:1；拖动中间分隔条调整比例，拖动靠正文的边缘调整总宽度。比例分隔条也支持方向键和 Home / End。

目录与书签使用一致的文字样式和正文底色，长条目最多显示两行。悬停预览和默认固定宽度按完整条目内容自动加宽；手动拖动后优先使用保存的宽度。固定面板的总宽度不超过当前文档编辑区域的一半；窄文本区中的悬浮面板允许超出文本区加宽，并限制在窗口边缘以内。

切换到 Markdown 源码时继续保留固定的目录、书签及其位置和比例。点击条目直接定位源码；输入后目录自动更新，书签跟随对应内容移动并更新预览，保存和切回渲染视图时保留书签名称、ID 与位置。源码目录的折叠按钮仅折叠目录子项。

“设置 → 外观与布局 → 布局设置”提供：

- 工作区分栏位置：文档树、文档列表、随记、PDF / EPUB 阅读分栏可放在正文左侧或右侧。
- 目录与书签位置：固定面板位于正文左侧或右侧。
- 目录与书签排列：上下排列或左右排列。左右排列时目录在左、书签在右。
- 恢复目录与书签比例：恢复到 2:1。

位置、排列、比例、宽度和固定状态保存在本机 `nr:workspaceLayout`，并纳入设置备份。旧版固定目录的位置与宽度会迁移。完整编辑器、完整只读和局部只读共用布局；手机版保留原来的点击弹出和边缘抽屉交互，不应用桌面的固定状态。

验证覆盖 Chromium / WebKit 的悬停定位、固定与收起、比例持久化、左右布局、右侧分栏拖动、手机竖横屏和 Tauri 标题栏模拟。真实 macOS / Windows 原生窗口仍需在相应系统验收。

桌面分栏的当前面板、展开状态和固定状态保存在 `nr:desktopSidebar`。刷新、安装升级后的重新启动及手机/桌面布局切换不会重置固定布局；临时悬停预览不写入此状态。首次读取会沿用旧版的侧栏隐藏偏好。分栏顺序、各分栏宽度及阅读分栏比例也纳入设置备份。

分栏拖向收起边缘并吸入时保留本次拖动开始前的宽度，再次点击对应按钮恢复该宽度；未吸入的普通宽度调整继续保存最终宽度。文档树、文档列表、随记、图片及阅读分栏共用此规则，左右布局镜像处理。

手机版工作区概览的汇总入口只展示“最近打开”，桌面保留全部汇总项。手机文档树遮罩在完整点击后才收起，按下到松开期间保持阻挡，避免路径页的文档行收到穿透点击；再次主动点击文档行仍可正常打开。

首页往返需要同时恢复 `nr:desktopSidebar` 与悬停控制器的内存状态，取消遗留的预览/收起计时器。打开文件不能将悬停预览自动转为固定分栏；完整交互规则见 [首页与分栏恢复](web-workspace-chrome.md#工作区首页与分栏恢复)。回归覆盖 `exhibition-workspace.spec.ts` 中的浮层/并排、原先展开/隐藏，以及文档树/列表的悬停/固定选择路径。

“编辑器 → 排版设置 → 列表后的块自动缩进”默认开启。紧接有序/无序列表的一组独立引用块、代码块在桌面使用一级列表的缩进宽度，遇到普通段落或其它块结束；手机自动缩进最多 4px。此设置只改变显示，不改写文档结构或 Markdown。手动缩进优先；引用块可使用 Tab / Shift+Tab，代码块使用工具栏的增加/减少块缩进按钮，代码内部 Tab 保持代码缩进语义。手动层级保存在文档中，手机代码/引用块每级仅显示 4px，桌面恢复正常层级宽度。

桌面 PDF/EPUB 阅读分栏在剩余文本区宽度不超过 64px 时吸附到边缘，自动隐藏文本区，保留边缘的 4px 分隔条及高亮引导线。向回拖动离开吸附范围后恢复文本区；保存占满宽度的比例后，再次打开阅读分栏仍保持文本区收起。右侧布局按相反拖动方向镜像处理，手机抽屉不使用此吸附策略。

## 随记（Notes）

工作区分栏默认顺序为文档树、文档列表、随记、PDF / EPUB 阅读。升级旧分栏顺序时，将随记插入文档列表之后；设置中仍可重新排序。随记复用桌面悬停/固定、左右位置、宽度与首页恢复机制。手机保留文档树、文档列表、阅读资料库三个边缘右划区域，通过文档树或文档列表顶部的随记按钮进入，打开或新建后自动收起抽屉。

随记是普通文档，保存在 `ideas/notes` 路径下；无需独立数据库或备份格式。新随记以本地日期时间（含秒）命名，可通过正文标题或列表的重命名按钮改名。多选后点击分组，选择已有组或输入新名称；新组同样默认按日期时间命名。分组对应子路径，支持改名、折叠、筛选与取消分组，分组归属随文档一起保存及备份。在文档树中移动至该路径的已有文档也会出现在随记中，移出则离开列表。

所有可编辑文档的段落开头输入 `/todo` 后按空格或回车，会生成未完成待办，正文 Markdown 使用 `- [ ]` / `- [x]` 表示。点击方框切换状态，回车继续生成未完成项，空项再按回车退出列表；代码块里的 `/todo` 保持代码文本。随记沿用普通文档的编辑、源码、撤销、搜索、链接、只读、回收站、导出和备份功能。

### 专注模式最近文档标签

桌面客户端和宽屏 Web 专注模式在 NINE RINGS 右侧显示最近文档标签，双击标识切换显示状态。外观与布局中可配置最多标签数（默认 32，1–64）；最近访问记录保留 64 份，工作区概览仍按其独立数量上限展示。标签使用完整名称提示、截短标签文字以及隐藏滚动条的横向滚动，支持触控板和鼠标滚轮。桌面客户端在全屏按钮左侧留出 36px 窗口拖动/双击区域，Web 不预留该区域。

标签读取与工作区概览相同的最近访问 ID，但排序、关闭及显隐保存在本机 `nr:focusTabs`，不修改最近记录、文档内容或收藏。重新打开已关闭的文档会恢复其标签。当前文档优先保留可见标签；关闭当前标签先保存，再切到相邻标签，关闭最后一个返回首页。右键支持复制完整逻辑路径（路径/文档名称）、在文档树中显示以及关闭此文件、右侧、其它及全部；删除标签不删除文档，保留原有文档会话缓存。

标签关闭后不会自动补入未显示的旧记录；重新实际打开文档可恢复标签。切换标签先完成保存。文档缓存必须同时检查当前 sessionKey 的条目存在，不能仅凭 previousKey 判断已完成切换，以免保存通知与导航状态并发时活动编辑区为空。

标签首次建立后保存自己的顺序，点击仅切换活动项，不随最近访问记录重排。拖动使用指针捕获和本地排序，结束后提交，取消不修改顺序；分隔线采用主题语义色。取消旧版 350ms 单击等待，双击关闭通过取消尚未完成的打开意图/恢复原活动项处理。只有文档集合变化或树刷新时重新读取摘要，访问顺序变化不重新加载树。原生标题显式标记 `data-tauri-drag-region="false"`，文字及内部装饰字母都不能触发窗口拖动或最大化；保留右侧空白区窗口手势。

旧版随显隐/排序写入的默认 16 会迁移为 32，其它自定义上限保留。新偏好版本下明确选择的 16 也保留。标签数量不增加正文缓存实例数；最近三份文档仍使用原有驻留缓存。在文档树中显示独立标记目标并展开祖先，不切换中央正文或改变文档属性操作目标。
