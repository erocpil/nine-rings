# 词汇学习插件（第一阶段）

## 启用与使用

1. 在设置 → 高级中开启插件功能，在插件列表中启用「词汇学习」。
2. 点击插件名称配置词汇路径，默认 `references/vocabulary`，包括其子路径。可以改为已有词汇文档的路径；修改后按 Enter 或移出输入框保存。
3. 将手动生成的词汇 `.md` 通过「备份与导入」导入到配置路径。插件自身不运行抓取脚本、不联网。
4. 桌面从左侧「词汇学习」按钮打开；手机划出文档树后从上方书本按钮进入。分栏上方提供字母顺序 A–Z / 添加时间（最新在前）排序，选择保存在本机，添加时间使用创建时间而非编辑时间。筛选名称后点击词汇，在中央区域打开学习视图；无匹配时提供提示。重复点击当前词汇保留视图。
5. 「普通文档」打开该词汇原文供编辑、导出；「返回原视图」恢复此前文档。停用插件撤销分栏和学习视图，词汇文档保持不变。

## 内容模型与呈现

词汇继续作为普通 Markdown 文档保存、同步和备份。学习视图从当前权威文档模型序列化 Markdown，通过共享 GFM AST 生成只读投影，不回写正文、不插入专用 fenced block。

当前结构识别手动抓取结果：H1 词汇；H2 剑桥/Cambridge、FreeCollocation 来源；H3 词性条目；H4 各来源自己的词义；H5 搭配分类。FreeCollocation 未提供 H4 时，以「搭配与用法」承接分类。不按编号推断两个词典词义相同，不拆分逗号或 `|` 分隔的搭配组。嵌套例句、译文留在原搭配或释义下。

音标、来源链接和提取时间独立显示；例句默认折叠，可配置。译文独立控制且默认折叠，收起或打开例句保留译文的展开状态。切换词汇、关闭再打开或刷新后，按文档 ID 恢复阅读位置与每处例句/译文折叠状态；正文变化时重置，避免错配。状态仅在本机保存，不包含原文，最多保留最近 50 份文档、每份最多 512 处折叠状态；写入失败不影响阅读。例句与译文按紧凑附属文本排版，正文、例句和译文共享排版设置的字体、字号与行高，标题使用对应级别的字号及默认比例。释义内部紧凑排列，释义与例句之间留出组间间隔，译文紧随所属例句；取消嵌套卡片的重复背景与内边距。文本可选择复制，折叠控件不进入复制内容；支持 CSS Custom Highlight 的引擎保留原生选区及复制行为，仅以逐文本节点范围绘制高亮，避免 WebKit 跨段落选区染满卡片或外侧留白；不支持该 API 时保留原生文字选区。控件与隐藏内容不绘制高亮，清除选区或离开学习视图时清理绘制范围。未知格式、不识别的内容可通过「普通文档」查看和编辑；学习视图不再附加完整 Markdown 原文区域。HTML 不作为可执行内容加载，链接只允许 HTTP(S) 和 mailto。

学习视图是当前文档快照。编辑应通过普通文档完成，再从分栏打开更新后的学习视图。其它窗口修改该文档时，旧快照关闭，避免继续展示过期内容。

## 宿主与权限边界

受信任内置插件注册 `vocabulary-library` 分栏及 `vocabulary` 主区域 renderer。渲染、主视图保存门禁、原编辑器保留和焦点布局均由宿主控制；这不开放任意插件 DOM/React 或脚本执行。

内部权限 `documents.vocabulary.read` 仅供受信任内置模块使用，不是已发布的公共 SDK 能力。宿主读服务只允许配置路径；列表仅取摘要、不读取全部正文。选中后在保护写入锁下检查文档身份、路径、加密和保护路径，异步操作后再次核验激活身份。受保护正文拒绝读取；停用/撤销清理贡献及待处理视图。保护或同步事务开始时关闭学习快照。

本阶段预算：列表最多 5000 份文档（达到限制显示提示）；正文最多 250000 字符；解析最多 10000 个顶层 AST 节点。超限可回到普通文档查看。插件配置保存在本机，正文沿用现有文档持久化和备份。

## 后续文章关联

预留 `VocabularyArticleContext` 类型：关联 ID、词汇文档 ID、文章文档 ID、表达、原句、可选文章锚点及来源/词义身份。当前不创建关联数据，不实现复习调度，也不自动扫描相关文章。

UI 的语义散列与重复计数用于 React key 及正文指纹约束下的本机展示状态，不可作为文档的持久引用锚点。后续关系必须使用真实文档和引用锚点身份，支持一篇文章含多个词汇、一个词汇关联多篇文章。抓取刷新应只更新词典资料，个人练习与文章关联应独立保存。

## 当前界面收尾

分栏顶部以排序控件替代重复的「词汇学习」标题。词汇行的气泡沿行左侧对齐，公共提示系统根据实际宽高居中或贴边，并限制在可视区内；不再用字符总数估计多行气泡宽度。未启用的阅读语境占位区域移除，类型保留供未来设计，本阶段不接入新学习模块。

## 列表外观

设置 → 高级 → 插件列表 → 词汇学习，可选择界面、正文、无衬线、衬线或等宽字体，并调整列表字号（12–28px）、行高（1.2–2.4 倍）和条目最小高度（28–72px）。默认使用界面字体、16px、1.5 倍行高、40px 最小高度；内容较大时条目仍会自然撑开。恢复列表默认只重置这四项，不改变词汇路径与例句折叠设置。

配置仅保存在本机，对桌面及手机列表均生效，中央学习正文仍遵循排版设置。旧配置自动补齐外观默认值；修改外观不会重启插件、重新读取列表或关闭当前词汇。

当前学习词汇或通过查找打开的普通词汇文档，在列表中以强调色和侧边标记高亮。打开或重新显示分栏时自动将当前词汇滚动到可见区域；上方「定位当前词汇」按钮可再次定位，并清除挡住当前词汇的名称筛选。定位仅滚动列表，不改变中央正文的位置；当前文档不在词汇列表中时按钮禁用。
