# 词汇学习插件（第一阶段）

## 启用与使用

1. 在设置 → 高级中开启插件功能，在插件列表中启用「词汇学习」。
2. 点击插件名称配置词汇路径，默认 `references/vocabulary`，包括其子路径。可以改为已有词汇文档的路径；修改后按 Enter 或移出输入框保存。
3. 将手动生成的词汇 `.md` 通过「备份与导入」导入到配置路径。插件自身不运行抓取脚本、不联网。
4. 桌面从左侧「词汇学习」按钮打开；手机划出文档树后从上方书本按钮进入。筛选名称后点击词汇，在中央区域打开学习视图。
5. 「普通文档」打开该词汇原文供编辑、导出；「返回原视图」恢复此前文档。停用插件撤销分栏和学习视图，词汇文档保持不变。

## 内容模型与呈现

词汇继续作为普通 Markdown 文档保存、同步和备份。学习视图从当前权威文档模型序列化 Markdown，通过共享 GFM AST 生成只读投影，不回写正文、不插入专用 fenced block。

当前结构识别手动抓取结果：H1 词汇；H2 剑桥/Cambridge、FreeCollocation 来源；H3 词性条目；H4 各来源自己的词义；H5 搭配分类。FreeCollocation 未提供 H4 时，以「搭配与用法」承接分类。不按编号推断两个词典词义相同，不拆分逗号或 `|` 分隔的搭配组。嵌套例句、译文留在原搭配或释义下。

音标、来源链接和提取时间独立显示；例句默认折叠，可配置。译文独立控制且默认折叠，收起或打开例句保留本次译文的展开状态。例句与译文按紧凑附属文本排版，保留正文行高，取消嵌套卡片的重复背景与内边距。文本可选择复制，折叠控件与布局留白不参与选区。未知格式、不识别的内容可通过「普通文档」查看和编辑；学习视图不再附加完整 Markdown 原文区域。HTML 不作为可执行内容加载，链接只允许 HTTP(S) 和 mailto。

学习视图是当前文档快照。编辑应通过普通文档完成，再从分栏打开更新后的学习视图。其它窗口修改该文档时，旧快照关闭，避免继续展示过期内容。

## 宿主与权限边界

受信任内置插件注册 `vocabulary-library` 分栏及 `vocabulary` 主区域 renderer。渲染、主视图保存门禁、原编辑器保留和焦点布局均由宿主控制；这不开放任意插件 DOM/React 或脚本执行。

内部权限 `documents.vocabulary.read` 仅供受信任内置模块使用，不是已发布的公共 SDK 能力。宿主读服务只允许配置路径；列表仅取摘要、不读取全部正文。选中后在保护写入锁下检查文档身份、路径、加密和保护路径，异步操作后再次核验激活身份。受保护正文拒绝读取；停用/撤销清理贡献及待处理视图。保护或同步事务开始时关闭学习快照。

本阶段预算：列表最多 5000 份文档（达到限制显示提示）；正文最多 250000 字符；解析最多 10000 个顶层 AST 节点。超限可回到普通文档查看。插件配置保存在本机，正文沿用现有文档持久化和备份。

## 后续文章关联

预留 `VocabularyArticleContext` 类型：关联 ID、词汇文档 ID、文章文档 ID、表达、原句、可选文章锚点及来源/词义身份。当前不创建关联数据，不实现复习调度，也不自动扫描相关文章。

UI 的语义散列与重复计数仅用于 React key，不可作为持久引用锚点。后续关系必须使用真实文档和引用锚点身份，支持一篇文章含多个词汇、一个词汇关联多篇文章。抓取刷新应只更新词典资料，个人练习与文章关联应独立保存。
