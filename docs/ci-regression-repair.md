# 继续拆分前的回归修复

基线：`a9254bc`，GitHub Test 工作流 `34123778646`。验证记录：2026-09-08。本批优先处理已有失败，不同时迁移编辑器会话、选区或视口逻辑。

## 原因与处理

1. **剪贴板路径分叉**：近期富文本改动在工具栏粘贴中先采用 HTML，覆盖了代码块的原始文本和 Markdown 源码判断；原生 HTML 粘贴改用 `insertContent` 后绕过剪贴板切片归一化，导致段内粘贴出现额外段落。
   - 代码块仍优先原始文本，包括末尾换行。
   - 简单 div/p/br 包装的 Markdown 按源码解析；真实富文本及 ProseMirror 切片保留格式。
   - 原生与工具栏 HTML 粘贴都使用 ProseMirror 剪贴板解析、边界清理和选区上下文；复制/剪切采用 `serializeForClipboard` 保留切片元数据。
   - 异步读取完成后核对编辑器、文档快照和只读状态，防止权限弹窗期间输入、切换文档或只读后再插入旧内容；保留原 Selection 类型，不把表格选区转为普通文本选区。
2. **PDF 高清缓存提前释放**：命中缓存后，文字层仍未完成就移出并清空缓存；若此时渲染被取消，下一批失去高清副本。现在只在当前渲染成功提交后释放，LRU 与像素预算不变。
3. **旧界面断言**：EPUB 工具面板已替换旧书签弹层，视图切换/关闭改用带可访问名称的 SVG 图标，同步错误改为公共错误组件。主题检查覆盖独立阅读器 CSS，E2E 使用当前可访问名称、alert 和功能状态，不再依赖旧 emoji 或已删除的 class。
4. **新建随笔的测试时序**：模板创建是异步的，仍挂载的旧编辑器不代表新会话就绪。粘贴回归共用前置条件：标题为新随笔、正文为空、可编辑且获得焦点后才派发输入。已确认的局部加粗间距 flaky 用例也采用同一前置条件，原布局与内容断言不放宽。
5. **跨标签迟到读取覆盖编辑**：第一轮全量发现多标签页输入被重载；受控挂起外部快照读取后继续输入，确认旧实现在响应返回时覆盖正文。现在读取前后都检查同步的待保存数据，校验当前文档、请求代次和原快照是否已变化；切换文档/卸载或有更新通知时旧结果失效，有新编辑则保留正文并提示冲突。读取失败也不产生未处理的 Promise rejection。新增用例先在旧实现失败，修复后与原跨标签用例重复五轮全部通过，加入 WebKit 数据安全门禁。
6. **只读状态误报正文修改**：进一步追踪恢复测试中的额外 `nine_rings:notes` 写入，发现 `setEditable` 默认发出无正文变化的 update，挂载编辑器或切换只读也会自动保存并广播，造成虚假修改和跨标签反复重载。改为 `setEditable(..., false)`，正文更新入口也要求 `transaction.docChanged`。独立回归先确认旧实现“打开空白笔记即保存一次”，再验证打开、只读往返不保存，真实输入仍落盘并能重载恢复。保留备份测试“零写入”的严格要求，并增加事务数据表诊断。
7. **异步界面尚未就绪就操作旧节点**：新建外部 Markdown 文档的用例补齐标题、空正文和可编辑状态检查，避免向上一份文档输入。PDF 批注用例在完成绘制、收起工具栏行之后，等待画布签名与当前视口尺寸一致，再选择文字；仅检查旧文字 span 已挂载，不能保证 ResizeObserver 触发的文字层重建已完成。保留高亮、显隐和导出断言，不以固定延时替代就绪条件。

## 239dae2 后续 CI 修复

基线：`239dae2`，GitHub Test 工作流 `34174045784`。远程 Chromium 结果为 357 通过、4 失败、5 跳过，后续 WebKit 步骤未执行；前端、Rust 和三平台构建通过。

- **异步复制的测试前置条件**：原生富文本用例在复制写入尚未完成时，可能读到上一次只有 `text/plain` 的剪贴板对象。轮询函数直接 `getType("text/html")` 抛错并终止，不会继续等待。新增“旧剪贴板为纯文本、真实富文本写入延迟 250ms”的条件后，旧用例稳定报相同的 `NotFoundError`；改为先查找含 HTML 的项目再读取，仍要求真实系统剪贴板包含 `data-pm-slice`，并验证粘贴后的样式、列表、表格及段落边界，没有改成模拟剪贴板或延长超时。
- **EPUB 专注模式重复计时器**：在 React 状态 updater 内创建定时器违反 updater 的纯函数约束，StrictMode 重复调用会留下无法被 ref 清理的旧计时器。改为事件处理函数通过同步可见状态 ref 调用统一 show/hide；只保留最近一次显示的 1 秒计时器。受控时钟回归在旧实现中确认“隐藏后再次显示仍被旧计时器提前隐藏”，修复后验证最新 1 秒期限和连续两轮切换。
- **EPUB Pointer-only WebView 的兼容 click**：原桥接脚本只抑制 touchend 后的 click，pointerup 已上报 tap 后的兼容 click 会再上报一次。两条输入路径统一抑制同次 click，touch 存在时由 touch 负责当前手势；取消粗粒度的“最近 touchstart 后 1200ms 忽略 pointer”规则，避免影响后续手势。新增 pointerdown/up/click 连续点按回归先在旧实现失败，再确认一组事件只切换一次。
- **目录布局夹具与宽度契约**：原用例在复杂示例文档中按中心坐标点击，再用 Ctrl+End 移动，未保证粘贴位于顶层正文，也依赖启动内容与选区恢复时序。改为明确的单标题/单段落文档，在指定顶层段落末尾追加内容，保留精确标题数量、目录数量、窗口化条目数、行高和底部跳转断言。普通模式浮层按正文容器宽度减两侧 8px 且居中验证；专注模式仍按视口宽度验证，不再沿用已失效的固定 370px 下限或要求两种模式同宽。
- **全量暴露的块号用例时序**：首次完整运行额外捕获列表缩进用例在模板新建后立即向仍挂载的旧编辑器粘贴，最终新笔记为空，列表断言失败。同文件的新建前置步骤统一复用 `createBlankNote`，等待标题、空正文、可编辑状态及焦点就绪，原有块号/缩进/列表几何断言均保留。
- **快速确认块号时 DOM 光标回退**：第二轮完整运行捕获输入 30 后实际跳至第 1 块。普通操作连续 10 次未复现；将输入与 Enter 放在同一事件轮次后，旧实现稳定跳至第 1 块。仅读取实时输入框值不能解决；改用 `editor.view.focus()`，由 ProseMirror 暂停观察、聚焦并将模型选区写回 DOM，避免裸 `dom.focus()` 恢复旧光标。保留原有输入校验，新增回归同时检查 DOM 光标和状态栏块号。
- **只读图片重载前等待持久化**：第二轮完整运行捕获只读切换按钮点击后立即重载，异步 IndexedDB 写入尚未完成。补上编辑器已切换到只读的前置断言，再执行原有重载、只读状态及图片手柄断言，不用固定 sleep。
