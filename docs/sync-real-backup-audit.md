## 首批修复：旧列表隐式边界

为旧平面列表补充保守兼容认证：输入与往返结果必须操作数量相同，只允许同一位置列表换行新增 `list-block-start: true`；显式边界不能删除，编号、缩进、文字、其它属性及嵌入对象必须完全一致。新增显式标记的结果还必须再往返一次保持稳定。不修改原始文件或正文投影，不将转换后的正文写回。

同一 SHA-256 文件复审：macOS Tauri 与 Web 的 `unsupported-content` 均从 133 降到 71，排除 62 处等价旧列表差异。原先按“首个差异”统计的 79 份不全是单一原因，因此不能推断应减少 79。剩余 71 处继续拒绝迁移；预算组装和原生验收尚未开始，生产能力仍为 0。

## 第二批：引用嵌入的重复标记

旧引用嵌入对象已有 `insert.blockquote` 类型，但可能缺少外层重复的 `blockquote: true`。认证允许同一操作仅推导该标记，仍要求版本、正文、缩进、折叠、所有其它属性与嵌入边界完全一致，并要求转换结果再次往返稳定。若简单引用嵌入会被转换成平面引用行，仍拒绝其表示变化；冲突标记、未知字段和缺失分隔符同样拒绝。

同一原始文件复审：两端失败数从 71 降至 66（累计排除 67 处等价旧格式差异）。文件 SHA-256 未变化，正式迁移仍未开放。

剩余差异已观察到：分隔线前后换行的增减、含多行的文本操作拆分、脚注引用补充编号、平面引用/列表转嵌入，以及其它形状或资源检查。它们可能同时出现在一份正文中，不能按首个差异直接认定根因，也不能统一忽略换行或编号。下一批需分别建立段落边界及脚注全局编号的兼容规则和反例，保留当前拒绝保护。

### 复现命令

```sh
bash scripts/with-local-tools.sh npx tsx scripts/audit-sync-backup.ts /path/to/backup.json
```

工具仅本机读取 UTF-8 完整 JSON（最大 64 MiB），输出汇总、文件摘要和 Web/Tauri 候选审查，不输出文档名称、正文或设置值，不导入、不联网，也不修改协议能力。退出码 0 表示候选审查通过，2 表示存在认证问题，1 表示输入/测量失败。候选通过不等于实际运行或完整同步验收通过。
