# 阅读器全屏导航统一

## 参考与取舍

- [Adobe Acrobat 阅读与全屏偏好](https://helpx.adobe.com/acrobat/using/viewing-pdfs-viewing-preferences.html)：阅读模式使用浮动导航，隐藏常驻界面以留出正文空间。
- [Zotero 阅读器](https://www.zotero.org/support/pdf_reader)：阅读、标注和笔记相互配合，不必离开阅读器才能操作资料。

Nine Rings 本批采用按需浮出的同一套 PDF/EPUB 导航，不照搬产品外观：目录、书签、搜索和阅读设置留在阅读器全屏根节点中；面板打开时保持按钮可用。背景使用不透明主题色，避免正文穿透影响阅读。

## 修复范围

- 移除遗留的全屏隐藏规则，它们曾把新导航入口、目录、搜索内容一起隐藏。
- PDF 无内嵌目录时自动显示页列表，目录按钮状态覆盖页列表。
- 目录和书签重复点击可收起；搜索、阅读设置与目录互斥，避免面板堆叠。
- 打开面板期间不自动收起工具栏；关闭后恢复原有自动隐藏行为。
- EPUB 使用共享工具栏退出按钮，取消额外的浮动 emoji 按钮；PDF 也使用同组 SVG 全屏图标。
- 浮层避让工具栏的实际高度，旋转屏幕后重新测量；显隐工具栏不挤压 EPUB 正文。

不改动文件存储、渲染缓存或设置页。编辑器仅增加 Ctrl-F 事件的阅读器目标排除，避免并排编辑时拦截阅读器搜索；正文编辑行为不变。浏览器全屏和移动端应用内全屏使用相同的导航布局。

## 验证

`e2e/reader-fullscreen-navigation.spec.ts` 覆盖手机及桌面尺寸的 PDF/EPUB 面板开关、自动隐藏期间的面板保持、目录与工具栏边界、PDF 搜索、EPUB 正文尺寸稳定。

本批验证：Chromium、WebKit 各 12 项阅读器回归通过；Chromium 另通过 2 项 EPUB 连续点按/计时器回归。类型检查、生产构建和修改文件 lint 通过。全仓 lint 仍有既有的 `ReadonlyVirtualNote.tsx` Hook 依赖问题；构建仍有既有 vendor 分包体积提示。

真实 iPhone PWA 和 Windows Tauri 原生窗口仍需设备复核；浏览器自动化不等同于实机验证。

## 后续候选（本批不实现）

- 阅读库更明确的文件来源、最近进度及空状态。
- 阅读与编辑并排时的摘录回链交互。
