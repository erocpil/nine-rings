# Windows 最大化后全屏底部黑条

复现：双击自定义标题栏最大化，再点击标题栏全屏按钮。窗口覆盖整个屏幕，
但底部留下接近任务栏高度的黑条。

当前锁定的 Tao 0.35.3 在 Windows `WM_NCCALCSIZE` 中，对最大化无边框窗口
使用显示器的 `rcWork` 计算客户区；该分支没有排除全屏状态。于是窗口已全屏，
客户区仍被裁剪到不含任务栏的工作区。参见
[Tao 的窗口消息处理](https://github.com/tauri-apps/tao/blob/tao-v0.35.3/src/platform_impl/windows/event_loop.rs)。

`src-tauri/src/fullscreen.rs` 在 Windows 进入全屏前解除最大化，退出后恢复
最大化。整个操作在 UI 线程连续执行，避免 Tauri 的异步窗口消息交错。
标题栏、PDF/EPUB 的原生全屏入口和 F11 共用该逻辑，进入和退出可以混用。
普通窗口不额外最大化，macOS 和 Linux 继续使用原有原生全屏行为。

自动化覆盖切换顺序、重复进入/退出、失败恢复，以及标题栏到原生命令的调用。
浏览器测试通过模拟 IPC 检查按钮行为，不能验证 Windows 客户区像素。

Windows 实机验收：

1. 双击标题栏最大化 → 点击全屏：内容覆盖整个屏幕，底部无黑条。
2. 点击退出全屏：恢复最大化；再双击标题栏：恢复普通窗口尺寸。
3. 按钮进入 → F11 退出、F11 进入 → 按钮退出，均恢复进入前的窗口状态。
4. 从普通窗口直接进入/退出全屏，仍恢复普通窗口尺寸。
5. 在不同缩放比例、第二块显示器和任务栏自动隐藏配置下重复上述操作。
